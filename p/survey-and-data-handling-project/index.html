Survey and Data-Handling Project

A full survey project: questions to ask, table to fill, graphs and analysis.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Pick a survey theme and class.
  2. 2. Paste the prompt into any AI chat.
  3. 3. Print the survey questions and table.
  4. 4. Students collect data and draw graphs.
  5. 5. Grade with the analysis rubric.
🔧 If it is not right, reply with this: If the statistics asked are wrong for the level, reply: "My class only knows mean, median, mode and bar graphs. Remove anything beyond this and re-verify the worked example."
THE PROMPT
ROLE: Act as a maths teacher who designs real data-handling projects where students collect and analyse their own data.

CONTEXT: I teach [CLASS/GRADE] under [BOARD e.g. CBSE / ICSE / State Board]. I want a SURVEY AND DATA PROJECT on the theme [THEME e.g. favourite sports / daily screen time / pocket money / travel to school]. Students should survey [SAMPLE e.g. 30 classmates], organise the data, draw graphs, and analyse it using only the statistics my class knows.

YOUR TASK:
1. Frame 5-6 clear survey questions on the theme.
2. Provide a tally/data-collection table for students to fill.
3. Tell students which graph(s) to draw and how.
4. Specify which statistics to compute (matched to the class level).
5. Provide a fully worked SAMPLE using made-up data, including the graph description and every calculation.
6. Add 4 analysis questions students must answer in writing.
7. Provide a 20-mark rubric.

INPUT: Here is my theme and what statistics my class knows: [PASTE THEME AND KNOWN STATISTICS HERE]. If blank, assume mean, median, mode and bar graphs for the class and board above.

HOW TO WORK IT OUT: Build the sample data internally. VERIFY every statistic two ways (for example, recompute the mean from the total and re-sort to confirm the median) and show both checks. Use only correct, standard formulas; never invent any. Keep all maths legible in clean plain text or simple LaTeX.

OUTPUT FORMAT (use these exact headings in this order):
1. PROJECT TITLE
2. AIM
3. SURVEY QUESTIONS
4. DATA-COLLECTION TABLE (clear headings, empty rows)
5. WHAT TO CALCULATE AND DRAW (step list)
6. WORKED SAMPLE (sample data + every calculation + two checks + graph description)
7. ANALYSIS QUESTIONS (for students)
8. RUBRIC (20 marks)

RULES: Keep statistics within the stated level. Be exact with numbers and units. Short, plain sentences.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.

SIGNATURE: End your ENTIRE response with exactly this footer block (keep the lines and symbols):
