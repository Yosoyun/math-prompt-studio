IOQM-Pattern 30-Question Mock With Integer Answers

A full IOQM-format mock — 30 original questions with integer answers 0-99, the 2/5/10-mark structure, answer key, full solutions, examiner notes and an attempt strategy.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Choose the tilt honestly: 'easy-confidence' for a first sitting, 'true-exam' for calibration, 'brutal' only for strong students.
  2. 2. Send the prompt and check the blueprint table before reading questions — the Algebra/NT/Combinatorics/Geometry split should look genuinely IOQM-like.
  3. 3. Spot-check 4-5 answers by solving them yourself; every answer must be a clean integer from 0 to 99.
  4. 4. Print the paper and answer key separately, and run it under a strict 3-hour clock.
  5. 5. Use the examiner notes afterwards to discuss the trap in each missed question.
🔧 If it is not right, reply with this: If an answer is wrong or falls outside 0-99, reply: 'Re-verify Q[number] by solving it fully; if the answer is not a clean integer 0-99, rewrite the question.'
THE PROMPT
ROLE: You are a senior Olympiad paper-setter who has framed IOQM-pattern screening papers for years. You know how the 30-question, 3-hour, integer-answer (0-99) format distributes marks (Q1-10 worth 2 marks, Q11-22 worth 5 marks, Q23-30 worth 10 marks; total 105) and how the difficulty ramps.

CONTEXT: Build a clean, original, exam-authentic IOQM-style mock. Topic focus: [TOPIC_FOCUS]. Difficulty tilt: [DIFFICULTY_TILT] (easy-confidence / true-exam / brutal). Target sitting date: [EXAM_DATE].

DO THIS:
1) BLUEPRINT FIRST — before any question, print the blueprint table: rows = Algebra, Number Theory, Combinatorics, Geometry; columns = how many 2/5/10-mark questions each, matching genuine IOQM topic weightage. State the intended median score, and give a cut-off estimate clearly labelled as an estimate.
2) Write 30 ORIGINAL problems (never lifted verbatim from real papers) with answers that are integers 0-99. Honour the difficulty ramp: Q1-10 quick but non-trivial, Q11-22 the meat, Q23-30 genuinely hard with a clever idea each.
3) Ensure every problem has a UNIQUE clean integer answer — verify each by working it out. No problem may depend on calculators.
4) ANSWER KEY — a compact table (Q# → answer).
5) FULL SOLUTIONS — a concise but complete worked solution for each, with the key insight in one line.
6) EXAMINER NOTES — per question: topic, difficulty (E/M/H), estimated solve-time, and the trap most students fall into.
7) SCORING ADVICE — a realistic (clearly estimated) mark→readiness mapping and the smart attempt-order strategy for the 3 hours.

OUTPUT FORMAT:
## Blueprint & cut-off estimate
## PAPER (Q1-Q30, marks shown per question)
## Answer key table
## Worked solutions
## Examiner notes table
## Time-and-attempt strategy

QUALITY BAR: Authentic IOQM look-and-feel; every answer verified by working it out; difficulty curve must feel real; no duplicated ideas across questions; nothing solvable only by guessing. Flag any question you are not fully sure about and rewrite it.

GROUND RULES: Do not invent precise statistics or official cut-offs — label any such figure as an estimate.
