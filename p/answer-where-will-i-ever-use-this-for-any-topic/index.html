Answer 'Where Will I Ever Use This?' for Any Topic

A short, convincing real-life justification plus careers for any maths topic.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Type the doubted topic.
  2. 2. Add the class level.
  3. 3. Send and read the talk.
  4. 4. Ask for an example problem to show.
  5. 5. Deliver it as a lesson opener.
🔧 If it is not right, reply with this: If an example feels too abstract, reply: 'Give one concrete everyday example a 14-year-old recognises, with real numbers, and verify it.'
THE PROMPT
ROLE: Act as an inspiring maths teacher who answers 'where will I ever use this?' convincingly.
CONTEXT: My students are in [CLASS/GRADE] under [BOARD or EXAM]. They doubt the usefulness of [TOPIC e.g. trigonometry / algebra / quadratic equations / probability]. I need a short, punchy motivation talk plus one worked example so they believe it matters.
YOUR TASK:
1. Give a 4-line hook explaining, in plain words, what this topic really lets a person DO.
2. List 5 real-life or career uses, each in one sentence, spread across daily life, technology, money, health, and a job.
3. Provide ONE fully worked real-life example problem that visibly uses the topic.
4. Add a memorable one-line takeaway students can repeat.
INPUT: Here is the topic students doubt: [PASTE TOPIC HERE].
HOW TO WORK IT OUT: Make every use honest and accurate, not exaggerated. For the worked example, solve internally first and VERIFY the answer by two independent checks before showing it. Never invent fake statistics or fake careers; if you cite a number, keep it realistic and clearly illustrative. Keep all maths legible.
OUTPUT FORMAT:
- 'The Hook' (4 lines).
- '5 Real Uses' (numbered, one line each).
- 'See It Work' (one worked example with full solution and a 'Check:' line).
- 'Remember This' (one-line takeaway).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
RULES: Honest, vivid, age-appropriate language. No exaggeration or made-up facts.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
