Solve and Give a Memory Tip

A full solution plus a sticky memory trick or mnemonic for the method used.

Attach a photo of the question first  ·  Best tool:  ChatGPT or Gemini (image)

✅ How to use this effectively

  1. 1. Photograph the question clearly.
  2. 2. Attach the photo and paste this prompt.
  3. 3. Send and read the solution.
  4. 4. Note the memory tip for class.
  5. 5. Ask for an alternative mnemonic if needed.
🔧 If it is not right, reply with this: If the tip is weak, reply: "Give a shorter, catchier memory trick tied directly to the key step of this problem."
THE PROMPT
ROLE: Act as a mathematics teacher who solves a problem and then gives students a memorable trick to recall the method.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET], topic [TOPIC]. My students forget methods under exam pressure, so I want a sticky memory aid attached to the solution.

YOUR TASK:
1. Read the question in the attached photo and restate it in clean text.
2. Solve it fully, step by step.
3. Create ONE clear memory tip for the key method - a short mnemonic, a rhyme, a visual image, or a simple rule of thumb.
4. Show exactly how the memory tip maps onto the steps of this problem.

INPUT: I have attached a photo of the problem. If any part is unclear, tell me which symbol or line you cannot read, state your best assumption, and continue.

HOW TO WORK IT OUT: Solve the problem silently first. Then VERIFY the final answer with TWO independent checks (for example substitute back, and re-derive a second way). If the checks disagree, fix the error before replying. The memory tip must be mathematically correct - do not let a catchy phrase introduce a wrong rule. Never invent formulas or values; name standard results. Keep all mathematics fully legible in clean LaTeX or clear plain text, one step per line.

OUTPUT FORMAT (use these exact headings):
1. Question as I read it.
2. Step-by-step solution - numbered, one idea per line, short reasons.
3. Final answer - clearly stated.
4. Memory tip - the mnemonic or trick in one or two lines.
5. How the tip maps to the steps - a short note linking each part of the tip to a step.
6. Verification - Check 1 and Check 2, each in one or two lines.

RULES: Keep the memory tip short and genuinely easy to recall. It must not oversimplify into something incorrect. Use plain ASCII only with straight quotes. Be exact unless an estimate is requested.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
At the very end add a footer line: "Prepared by [YOUR NAME]", and put "Compiled by [YOUR NAME]" in the title or header block at the top.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
