Pre-Submission Self-Check Checklist for Students

A short, printable checklist students run through before they hand work in.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. Type the topic or chapter.
  2. Set the class and board or exam.
  3. Press Enter to get the checklist.
  4. Print it or share to the class group.
  5. Ask for a shorter pocket version.
🔧 If it is not right, reply with this: If it is too generic, reply: "Add 4 checks that are specific to [TOPIC] mistakes my class keeps making."
THE PROMPT
ROLE: Act as an exam coach who designs self-checking habits for students.

CONTEXT: This is for [CLASS/GRADE] students in [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE]. Topic: [TOPIC]. I want a quick checklist students run BEFORE submitting, so they catch their own avoidable errors.

YOUR TASK:
1. Produce a short, tickable checklist covering the universal exam-hygiene checks (units, did I answer what was asked, copied numbers correctly, signs, final conclusion line).
2. Add a few checks specific to [TOPIC].
3. Include a tiny '60-second final scan' routine.
4. Keep it printable on half a page.

INPUT: Here is the topic and level: [TOPIC], [CLASS/GRADE], [BOARD or EXAM]. Optional: the mistakes my class repeats are [OPTIONAL LIST].

HOW TO WORK IT OUT: Base the topic-specific checks on the genuinely common slips at this level. Phrase each check as a yes/no the student can answer in seconds. Do not include checks that need re-solving the whole problem. Never invent formulas. Keep any maths legible.

OUTPUT FORMAT:
Title block: 'Before You Submit - [TOPIC] ([CLASS/GRADE])'.
Section A - Always check (universal): a tick-box list.
Section B - [TOPIC] checks: a tick-box list specific to this topic.
Section C - 60-second final scan: a 3-step routine.
Section D - If you find an error: a one-line calm fix-it instruction.

RULES: Plain ASCII only, straight quotes. Keep every line short and action-focused; no long explanations. Fit half a page.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
