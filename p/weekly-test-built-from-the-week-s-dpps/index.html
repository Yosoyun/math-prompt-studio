Weekly Test Built From the Week's DPPs

A graded weekend test assembled from everything the week's daily sheets covered, with a full key.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. List the week's daily topics.
  2. 2. Set class, board and total marks.
  3. 3. Paste the prompt and send.
  4. 4. Print the question paper.
  5. 5. Grade with the marking scheme.
🔧 If it is not right, reply with this: If it skips a day's topic, reply: "The test missed [topic from Day X]. Add questions so every day of the week is tested."
THE PROMPT
ROLE: Act as a mathematics teacher who builds end-of-week tests that check everything practised that week.

CONTEXT: I want a WEEKLY TEST assembled from the topics my daily DPPs covered this week, for [CLASS/GRADE] students of [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. Total marks = [TOTAL e.g. 30]. Duration = [TIME e.g. 1 hour].

YOUR TASK:
1. Take my list of the week's daily topics and build one balanced test that samples ALL of them.
2. Mix question types and rising marks so it feels like a proper assessment, not just a sheet.
3. Ensure every listed day's topic is represented; tag each question with the day/topic it tests.
4. Provide a marking scheme, answer key and full solutions.

INPUT: This week's daily topics = [LIST EACH DAY'S TOPIC]. Class = [CLASS/GRADE]. Board/Exam = [BOARD or EXAM]. Total marks = [TOTAL]. Duration = [TIME]. If unclear, assume and state it.

HOW TO WORK IT OUT: Solve every question yourself first. Verify each final answer by two independent checks. Balance coverage across all the week's topics. Make marks total exactly. Never invent formulas or values. Keep all maths legible in clean LaTeX or clear plain text.

OUTPUT FORMAT, in this exact order:
1. TITLE BLOCK: 'Weekly Test' with class, board/exam, total marks, duration, and 'Compiled by [YOUR NAME]'.
2. COVERAGE TABLE: which day/topic each question tests.
3. QUESTION PAPER: numbered questions with marks shown, grouped sensibly, printable.
4. MARKING SCHEME: how each mark is awarded.
5. ANSWER KEY AND FULL SOLUTIONS: final answers with clean working.

RULES: Every day's topic must appear. Marks must sum to the total. Difficulty must suit a weekly test, slightly above daily practice.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
