Professional Worksheet Cover Sheet

A neat front page for any worksheet with name, marks and instruction boxes.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Open any free AI chat.
  2. 2. Paste the prompt below.
  3. 3. Fill in topic, class and total marks.
  4. 4. Send and copy the cover sheet.
  5. 5. Paste into Word and print.

THE PROMPT
ROLE: Act as a teacher's assistant who designs neat, professional worksheet cover sheets.

CONTEXT: I need a front/cover sheet to staple on top of a [SUBJECT] worksheet for [CLASS/GRADE] under [BOARD or EXAM]. It should look formal and leave space for students to fill details and for me to enter marks.

YOUR TASK:
1. Create a single-page cover sheet layout in clean text/table form.
2. Include a header block with school name placeholder, subject, class, and date.
3. Add student fields: Name, Roll No., Section.
4. Add a worksheet info block: topic, total questions, total marks, time allowed.
5. Add a clear INSTRUCTIONS list (3 to 5 lines).
6. Add a marks box for the teacher with Marks Obtained / Total and a small remarks line.

INPUT: Worksheet topic: [PASTE TOPIC]. Total marks: [NUMBER]. Time allowed: [NUMBER] minutes. Number of questions: [NUMBER]. School name: [SCHOOL NAME or leave a blank line].

HOW TO WORK IT OUT: Lay this out so it copies cleanly into Microsoft Word or Google Docs as tables, not loose text. Double-check that the fields and numbers I provided appear exactly as given. Do not add subjects, marks, or instructions I did not ask for. Keep everything on one page.

OUTPUT FORMAT (use this exact order):
1. HEADER BLOCK (school, subject, class, date).
2. STUDENT DETAILS table (Name, Roll No., Section).
3. WORKSHEET INFO table (topic, questions, total marks, time).
4. INSTRUCTIONS list.
5. TEACHER MARKS BOX (Marks Obtained / Total + Remarks).

RULES: Formal and tidy. One page only. Use exactly the details I gave. Make it paste-friendly for Word.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
At the very end add a footer line: "Prepared by [YOUR NAME]", and put "Compiled by [YOUR NAME]" in the header block at the top.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
