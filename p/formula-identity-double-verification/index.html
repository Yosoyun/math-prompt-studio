Formula Identity Double Verification

A symbolic identity audit using Symbolab plus independently chosen WolframAlpha test values, with domain exceptions stated explicitly.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste both sides of the proposed formula exactly.
  2. 2. State real, complex, integer, or other variable domains.
  3. 3. Read the algebraic derivation and exception list.
  4. 4. Open the Symbolab identity check and WolframAlpha sample checks.
  5. 5. Treat samples as error detectors, not as a general proof.
🔧 If it is not right, reply with this: If wrong, reply with: "State the first non-equivalent transformation, restore all excluded values, and rebuild the symbolic and sample-value checks."
THE PROMPT
ROLE: Act as a symbolic-algebra reviewer who distinguishes proof, simplification, and finite testing.

CONTEXT: The user wants to verify whether a formula is an identity and needs both a symbolic comparison and carefully chosen numerical counterexample searches.

INPUTS — FILL EVERY PLACEHOLDER:
- [PROPOSED FORMULA]
- [VARIABLE DOMAINS]
- [KNOWN EXCLUSIONS]

DO THIS:
1. Parse both sides and list every implicit denominator, radical, logarithm, inverse-function, and branch restriction.
2. Transform the difference or ratio into a form suitable for symbolic comparison.
3. Provide a Symbolab query for expansion, simplification, or factorisation of the critical expression.
4. Choose at least three WolframAlpha test values including an ordinary value, a boundary-near value, and a sign-changing value when allowed.
5. Search deliberately for excluded values and counterexamples before declaring the identity valid on a domain.
6. Explain why numerical agreement is supporting evidence only and present the algebraic argument separately.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Verify the expansion (x + 1)^3 = x^3 + 3x^2 + 3x + 1.
Expected result or check target: Expanding the left side gives the right side for every real or complex x; no denominator or branch exclusions occur.
check this yourself
CHECK → https://www.symbolab.com/solver?query=expand%20%28x%2B1%29%5E3
(paste-fallback: expand (x+1)^3)
Encoding note: The decoded Symbolab query is exactly the fallback; parentheses, plus, and caret are encoded as %28/%29, %2B, and %5E.

OUTPUT FORMAT:
1. Claim and Domain — formula exactly as supplied with admissible values
2. Symbolic Derivation — equivalent transformations with reasons
3. Symbolab Check — raw link and exact fallback
4. WolframAlpha Test Values — value, both sides, raw link, and fallback
5. Exceptions and Counterexamples — excluded or failing values
6. Verdict — identity domain stated precisely
7. NOT-MACHINE-CHECKABLE — why finite tests alone are not proof

QUALITY AND TOOL GUARDRAILS:
- Do not infer a universal identity from matching numerical samples.
- Use the approved Symbolab solver query endpoint and WolframAlpha input endpoint only.
- Use plain calculator syntax in both query types and percent-encode reserved characters.
- Keep branch choices and domain exclusions visible in the verdict.
- Label links check this yourself and never describe them as proof.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
