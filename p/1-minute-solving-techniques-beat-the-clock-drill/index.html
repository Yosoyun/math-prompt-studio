1-Minute Solving Techniques (Beat the Clock Drill)

A drill of questions each solvable in under a minute, with the fast method spelled out step by step.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. Open any AI chat.
  2. Type the topic for speed practice.
  3. Paste the prompt and send.
  4. Time students on each question.
  5. Compare their route to the fast route.
  6. For a trustworthy answer key: paste the finished paper into a FRESH chat and ask it to solve and grade it as an unseen exam (it catches its own slips).
🔧 If it is not right, reply with this: If a question actually needs more than a minute, reply: "Q4 can't be done in 60 seconds the way shown - either give a faster route or replace it with a true 1-minute question."
THE PROMPT
ROLE: Act as a time-management coach for competitive maths who specialises in sub-60-second solutions.

CONTEXT: My [EXAM e.g. JEE Main / NEET] students must clear MCQs in about a minute each. I want a drill on [TOPIC] where every question is genuinely solvable in under 60 seconds with the right approach.

YOUR TASK:
1. Create EXACTLY [NUMBER e.g. 10] MCQs on [TOPIC] that a trained student can solve in under one minute each.
2. For each, give the FAST route (the smartest path, e.g. elimination, plugging options, symmetry, estimation) step by step, with an estimated solve time.
3. Also note the slow route so students see what to avoid.
4. End with a scoring guide: target time and a self-check on which techniques they still need to drill.

INPUT: Here is the topic and option style: [PASTE DETAILS HERE]. If number is blank, use 10. Stay inside this topic.

HOW TO WORK IT OUT: Solve each question by the fast route AND by the standard route internally, and VERIFY both give the same correct option - that is your check. Confirm the fast route is realistically under a minute; if not, redesign the question. Never invent formulas or values. Keep maths legible in clean LaTeX or clear plain text.

OUTPUT FORMAT, in this exact order:

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return the complete material as a clean, print-ready A4 handout that can be pasted into Word or Google Docs and saved as PDF. Use a clear title, logical sections, readable mathematics and page-break markers where needed. Keep student material separate from the answer key or teacher notes.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
A. Title block: 'Topic: [TOPIC]', '1-Minute Techniques for [EXAM]', 'Compiled by [YOUR NAME]'.
B. SECTION 1 - QUESTIONS: numbered MCQs with four options.
C. SECTION 2 - ANSWER KEY: compact.
D. SECTION 3 - FAST ROUTES: per question, the fast steps with estimated time, plus a one-line 'slow route to avoid'.
E. SECTION 4 - SCORING GUIDE: target total time and a quick self-diagnosis.

RULES: Each question truly solvable under a minute. Fast and slow routes must reach the same answer. No invented values. Verify before printing.

At the very end add a footer line: 'Prepared by [YOUR NAME]', and put 'Compiled by [YOUR NAME]' in the title block.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
