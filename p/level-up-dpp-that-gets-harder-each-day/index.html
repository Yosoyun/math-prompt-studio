Level-Up DPP That Gets Harder Each Day

A 5-day ladder where each day is clearly tougher, taking students from comfortable to exam-tough.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Fill topic, class and board.
  2. 2. Paste the prompt and send.
  3. 3. Type "Day 1" to start.
  4. 4. After each, type "Next level".
  5. 5. Watch the difficulty climb to Day 5.
🔧 If it is not right, reply with this: If a later day feels easier than an earlier one, reply: "Day [n] is not harder than Day [n-1]. Raise the difficulty and tell me what makes it harder."
THE PROMPT
ROLE: Act as a mathematics coach who builds difficulty ladders that stretch students step by step.

CONTEXT: I want a 5-day LEVEL-UP DPP on one topic where each day is clearly harder than the last, for [CLASS/GRADE] students preparing for [BOARD or EXAM e.g. CBSE / JEE / NEET / State Board]. Topic = [TOPIC].

YOUR TASK:
1. First show a one-line description of the 5 difficulty levels: Level 1 Foundation, Level 2 Comfortable, Level 3 Standard exam, Level 4 Tricky, Level 5 Topper-only.
2. Then produce ONE level per day, 5 questions each, all at that level.
3. Do NOT print all days at once. Ask me to type 'Day 1', then 'Next level' after each.

INPUT: Topic = [TOPIC]. Class = [CLASS/GRADE]. Board/Exam = [BOARD or EXAM]. Time per day = [TIME e.g. 30 minutes]. If unclear, assume and state it.

HOW TO WORK IT OUT: Solve every question yourself first and confirm it truly fits the stated level. Verify each final answer by two independent checks. Make each level genuinely harder than the last (more steps, trickier traps, less hand-holding). Never invent formulas or values. Keep all maths legible in clean LaTeX or clear plain text.

OUTPUT FORMAT for each day, in this exact order:
1. HEADER: 'Level-Up DPP - Day [n], Level [name]' with topic, class, board/exam, suggested time, and 'Compiled by [YOUR NAME]'.
2. WHY HARDER: one line on what makes this level tougher than yesterday.
3. QUESTIONS: 5 numbered questions only.
4. HINTS: one one-line hint per question.
5. ANSWER KEY: final answers.
6. FULL SOLUTIONS: clean step-by-step working.

RULES: Strictly increasing difficulty. Same topic throughout. No padding with trivial questions on higher levels.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
