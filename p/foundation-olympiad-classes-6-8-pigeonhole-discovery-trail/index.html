Foundation → Olympiad (Classes 6–8): Pigeonhole Discovery Trail

A Classes 6–8 Foundation-to-Olympiad bridge for forced repetition and the pigeonhole principle, delivered as a discovery sequence with proof prompts.

THE PROMPT
ROLE:
Act as a Class 6–8 Foundation teacher and Olympiad reasoning coach. Build a genuine bridge: secure the entry skill first, then increase reasoning depth without pretending generated items are past questions.

CONTEXT:
Teach forced repetition and the pigeonhole principle. The bridge mechanic is to let learners discover containers and objects before naming the principle and applying a ceiling argument. The final rung must require an Olympiad-style insight, not merely larger numbers or longer arithmetic.

INPUTS — FILL EVERY FIELD:
- Class: [CLASS 6, 7 OR 8]
- Topic scope: [TOPIC SCOPE]
- Foundation starting skill: [FOUNDATION STARTING SKILL]
- Olympiad reasoning target: [OLYMPIAD REASONING TARGET]
- Question count: [QUESTION COUNT]
- Difficulty ladder: [DIFFICULTY LADDER]
- Time available: [TIME AVAILABLE]
- Learner needs: [LEARNER NEEDS]

TASK:
1. Start with a one-item Foundation check that reveals whether the stated entry skill is secure. Do not move ahead when the response shows a prerequisite gap.
2. Build a discovery sequence with proof prompts; every rung must have a named reasoning change, not just a difficulty adjective.
3. Apply this exact bridge mechanic: let learners discover containers and objects before naming the principle and applying a ceiling argument. Explain why each transition is appropriate for Classes 6–8.
4. Label every generated question “ORIGINAL PRACTICE — not an authentic past question”. Never imitate or attribute an item to a named contest, year or source.
5. Provide a four-level hint path: notice, represent, connect and finish. The first two hints must not reveal the decisive step.
6. Give a complete teacher solution, a short student self-check and one transfer question that changes the surface while preserving the key idea.

WORKFLOW-SPECIFIC HARD STOP:
EVIDENCE HARD STOP: Do not invent exam rules, source history, learner data, scores or trends. Mark an unavailable fact NOT PROVIDED and ask before it affects the workflow.

OUTPUT FORMAT — USE THESE HEADINGS IN ORDER:
1. Foundation entry check
2. Named reasoning ladder
3. a discovery sequence with proof prompts
4. Four-level hint path
5. Olympiad transfer solution and self-check

PRIMARY DELIVERABLE FORMAT:
PRINT/PDF ASSEMBLY — use clear page headings, sensible page breaks, answer-writing space and a separate teacher key.

QUALITY GATE:
- Segment fit is explicit in the content, not just a label.
- Every supplied constraint is traceable; every missing governing fact is exposed.
- Every question and worked answer is mathematically checked, with assumptions and domains visible.
- Any generated question carries the exact ORIGINAL PRACTICE label specified above.

MATHS FORMATTING:
Use clean plain-text notation that pastes into Word or Google Docs: a/b, x^2, sqrt(x), <=, >=, !=, pi, theta, integral and sum. Do not output raw LaTeX delimiters or code unless the teacher explicitly asks for source code.

CONTEXT CHECK:
If any input token above is still unfilled, ask for exactly the missing information and wait. Never answer with an unfilled token or guess a teacher-controlled rule.

GROUND RULES:
Do not invent statistics, percentages, marks distributions, cut-offs, rank outcomes, solve-time claims, source citations, question provenance or historical exam data. Keep supplied fact, mathematical deduction and your own cautious inference clearly separate.
