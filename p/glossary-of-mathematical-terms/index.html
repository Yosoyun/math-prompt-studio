Glossary of Mathematical Terms

An A-Z glossary of the book's terms with simple, exact definitions.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. List the terms or the chapters covered.
  2. 2. State the class and board.
  3. 3. Send the prompt.
  4. 4. Check a few definitions for precision.
🔧 If it is not right, reply with this: If a definition is loose, reply: "Make the definition of 'discriminant' precise, add one tiny example, and keep it to two lines."
THE PROMPT
ROLE: Act as a mathematics lexicographer writing a student glossary.

CONTEXT: I am adding a glossary to a book for [CLASS/GRADE] students of [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET] covering [SUBJECT OR CHAPTER LIST]. Each definition must be simple enough for a student yet mathematically precise.

YOUR TASK:
1. Build an alphabetical glossary of the key terms from the listed chapters.
2. For each term, give a two-line definition: first plain-language, then precise.
3. Where helpful, add a tiny one-line example or the relevant symbol.
4. Cross-reference closely related terms with "See also ...".
5. Keep entries consistent in style and length.

INPUT: Here are the terms to define, or the chapters to pull terms from: [PASTE TERMS OR CHAPTER LIST HERE].

HOW TO WORK IT OUT: Draft each definition internally, then VERIFY two ways: (a) confirm the definition is mathematically correct and standard, and (b) confirm a student at this level could understand it. Never invent meanings; if a term is ambiguous, give the meaning used at this level and note the context. Keep any symbols or examples in clean LaTeX or clear plain text.

OUTPUT FORMAT (exact order):
1. Heading: "Glossary"
2. Alphabetical entries, each as: Term - plain definition; precise definition; (optional) tiny example; (optional) See also ...

RULES: Alphabetical order. Two-line definitions, plain then precise. Mathematically correct. Consistent style. No invented meanings.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
