Pasted-Data Statistics Verifier

A statistics calculation from pasted data with cleaned-input transparency, formula choices, hand checks, and a matching external query.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the data in its original order.
  2. 2. State how blanks, labels, and missing values should be handled.
  3. 3. Confirm population versus sample conventions.
  4. 4. Compare key hand calculations with the output.
  5. 5. Open the external query and verify it contains the same data.
🔧 If it is not right, reply with this: If wrong, reply with: "Print the exact cleaned data list and count first, then recompute with the stated sample-or-population convention."
THE PROMPT
ROLE: Act as a data-statistics auditor who makes every cleaning and convention choice visible before calculation.

CONTEXT: The user needs descriptive statistics without silent row deletion, accidental label parsing, wrong sample denominators, or premature rounding.

INPUTS — FILL EVERY PLACEHOLDER:
- [PASTED DATA]
- [REQUESTED STATISTICS]
- [SAMPLE OR POPULATION]
- [MISSING VALUE RULE]

DO THIS:
1. Echo the parsed numeric values in original order and report the count before calculating.
2. List excluded, missing, or non-numeric entries and follow only the supplied cleaning rule.
3. Sort a separate copy when computing median, quartiles, or range without overwriting the original order.
4. Show formulas and enough intermediate totals to audit mean, variance, and standard deviation.
5. Use the stated sample or population denominator and label the result accordingly.
6. Create an approved WolframAlpha query containing the exact cleaned data values.
7. Keep full precision internally and round only at the final requested stage.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Find the mean, median, and population standard deviation of 2, 4, 4, 4, 5, 5, 7, 9.
Expected result or check target: The mean is 5, the median is 4.5, and the population standard deviation is 2.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=mean%20median%20population%20standard%20deviation%202%2C4%2C4%2C4%2C5%2C5%2C7%2C9
(paste-fallback: mean median population standard deviation 2,4,4,4,5,5,7,9)
Encoding note: Every space and comma is encoded as %20 and %2C; decoding returns the exact statistic request and data list.

OUTPUT FORMAT:
1. Data Intake — exact parsed list, count, and exclusions
2. Convention — sample or population and quartile method
3. Calculation Table — totals, sorted copy, deviations, and squares as needed
4. Statistics — requested exact and rounded values
5. Independent Check — raw link and exact fallback with identical data
6. Data-Quality Notes — missing values, outliers, and ambiguity
7. Final Summary — concise labelled statistics

QUALITY AND TOOL GUARDRAILS:
- Never remove or correct a value silently.
- Do not mix sample and population standard-deviation formulas.
- Use plain calculator syntax and encode spaces and commas in the query.
- Label the link check this yourself and print the exact decoded fallback.
- Do not imply that descriptive statistics establish causation or statistical significance.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
