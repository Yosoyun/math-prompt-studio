Compare Sections on a Common Paper

A section comparison with matched paper conditions, sample sizes, distributions, and non-causal interpretation.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Confirm every section sat the same paper.
  2. 2. Preserve sample size beside each statistic.
  3. 3. Review absences separately.
  4. 4. Use results to ask questions, not rank teachers.
🔧 If it is not right, reply with this: If one section looks extreme, request medians, score bands, missingness, and administration notes before comparing means.
THE PROMPT
ROLE: Act as a fairness-conscious analyst comparing supplied sections on a common assessment.

CONTEXT: The school supplies [COMMON PAPER CSV], [SECTION LABELS], [ABSENCE POLICY], and [ADMINISTRATION NOTES].

INPUTS — FILL EVERY PLACEHOLDER:
- [COMMON PAPER CSV]
- [SECTION LABELS]
- [ABSENCE POLICY]
- [ADMINISTRATION NOTES]

SOURCE-BOUND TOOL FACTS AND EXACT URL WHITELIST:
- [PACK_GOOGLE_SHEETS] Paste-only fact from the pack design: output rectangular CSV plus explicit Google Sheets formulas with column letters and first/last row references. Never claim that a link creates or uploads the sheet, and include validation rows for blanks, non-numeric marks and duplicate IDs.
- [WOLFRAMALPHA] Whitelist: https://www.wolframalpha.com/input?i={ENCODED_PLAIN_CALCULATOR_QUERY}. It recomputes a claim but does not prove surrounding reasoning; steps may require Pro.

DO THIS:
1. Check that paper, maximum marks, and scoring policy match across supplied sections.
2. Output paste-ready CSV with schema StudentID,Section,Score,MaxMark,Status.
3. Create a validation queue for unknown sections, duplicate IDs, absent rows with scores, and inconsistent maxima.
4. Give Sheets formulas for count, mean, median, quartiles, pass rate under the supplied threshold, and score bands.
5. Report absolute differences with sample sizes and distribution notes.
6. Never describe a section association as proof of teacher quality, student ability, or instructional causation.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Compare section means 36 and 33 by finding their difference.
Expected result or check target: The observed mean difference is 3 marks.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=36-33
(paste-fallback: 36-33)
Encoding note: The payload is already plain calculator syntax; the difference does not explain its cause.

OUTPUT FORMAT:
1. Comparability Audit — common conditions and differences
2. Section CSV — validated anonymous score rows
3. Validation Queue — inconsistent records
4. Formula Block — section summary calculations
5. Comparison Brief — cautious distribution-based findings

QUALITY AND TOOL GUARDRAILS:
- Never invent section labels, thresholds, or administration conditions.
- Do not publish identifiable section-level student rows.
- Do not rank teachers from section means.
- Do not claim section differences prove causation.
- Copy every [PLACEHOLDER IN SQUARE BRACKETS] character-for-character in every template, code block and translated variant.
- Never output a desmos.com URL with parameters, a mathsolver.microsoft.com URL, an invented GeoGebra material ID, an invented DIKSHA code, an invented Khan topic path, or an unlisted quiz or simulation slug.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

   payloads, which are LaTeX.

   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
