Pre-Board Paper at Final-Exam Difficulty

A full pre-board paper pitched at real board difficulty, with blueprint and detailed key.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Paste the prompt into a chat.
  2. 2. List the full board syllabus.
  3. 3. Set total marks and time.
  4. 4. Send and read the harder items.
  5. 5. Check the detailed key carefully.
  6. For a trustworthy answer key: paste the finished paper into a FRESH chat and ask it to solve and grade it as an unseen exam (it catches its own slips).
🔧 If it is not right, reply with this: If it feels too easy for a pre-board, reply: 'Raise the difficulty to true board level, especially the long-answer section, while keeping the same marks and pattern, then re-verify the key.'
THE PROMPT
ROLE: Act as a mathematics examiner who sets challenging pre-board papers to prepare students for the real exam.

CONTEXT: This is a PRE-BOARD paper for Class [CLASS/GRADE], [BOARD or EXAM e.g. CBSE / ICSE / State Board]. It must match the final board pattern AND be slightly more demanding than average so students are well prepared. Total marks [TOTAL MARKS], time [TIME e.g. 3 hours].

YOUR TASK:
1. Follow the latest board section structure exactly (state it in 2 to 3 lines first).
2. Cover the FULL syllabus I list, with a blueprint table that totals [TOTAL MARKS].
3. Pitch difficulty at true board level, with a few high-effort questions in the long-answer section.
4. Provide a complete, detailed answer key.

INPUT: Full syllabus / chapters: [LIST CHAPTERS]. Use only these. If pattern detail is blank, assume the latest board pattern and state it.

HOW TO WORK IT OUT: Solve every question internally before printing. Verify each final answer twice by independent methods. Confirm difficulty is appropriate for a pre-board (not trivial, not impossible). Never invent formulas or values. Keep mathematics legible in clean LaTeX or plain text. Confirm marks total exactly [TOTAL MARKS].

OUTPUT FORMAT, in this order:
1. PATTERN NOTE: the board structure being followed.
2. HEADER BLOCK: 'Pre-Board Examination - Mathematics', class, board, time, maximum marks, 'Compiled by [YOUR NAME]'.
3. GENERAL INSTRUCTIONS: numbered.
4. BLUEPRINT TABLE with TOTAL equal to [TOTAL MARKS].
5. THE PAPER: sections labelled, internal choices shown with 'OR', marks beside every question.
6. ANSWER KEY: final answers plus working outlines for long questions.

RULES: True board difficulty. Full-syllabus coverage. Stay inside the listed syllabus. Number every question. Marks total exactly.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
