Whole-Worksheet Solve-and-Prove Audit

A whole worksheet solved in order with item-level final answers, check links for every computation, and a separate human-review queue.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the complete worksheet and preserve numbering.
  2. 2. Include all options, figures, and shared instructions in text.
  3. 3. Confirm the item inventory before reading solutions.
  4. 4. Open each item-labelled link after checking the derivation.
  5. 5. Human-review proof, diagram, and interpretation items.
🔧 If it is not right, reply with this: If wrong, reply with: "Re-solve worksheet item [QUESTION NUMBER] alone from its exact wording and replace only that item's solution, final answer, link, and fallback."
THE PROMPT
ROLE: Act as a worksheet solver, proof critic, and item-level external-check-link builder who preserves every question's identity.

CONTEXT: The user needs an entire mixed worksheet handled without skipped questions, numbering drift, cross-contaminated data, or blanket claims of verification.

INPUTS — FILL EVERY PLACEHOLDER:
- [COMPLETE WORKSHEET]
- [COURSE AND LEVEL]
- [ANSWER FORMAT RULES]
- [ALLOWED METHODS]

DO THIS:
1. Create an inventory of every question, subpart, option, shared instruction, figure reference, and missing element.
2. Solve each item independently in original order and repeat only the data needed for that item.
3. Show a concise but complete derivation with domains, branches, units, and candidate checks.
4. Create one or more focused approved links for every machine-checkable item, labelled by exact item number.
5. For proofs, diagrams, constructions, modelling, or explanations, write HUMAN REVIEW REQUIRED with a concrete criterion.
6. Produce a final-answer index only after all detailed solutions are complete.
7. Audit numbering, omissions, repeated answers, link alignment, and NOT-MACHINE-CHECKABLE scope.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Create the check entry for the worksheet system x + y = 10 and x - y = 4.
Expected result or check target: Adding gives x = 7 and then y = 3; the ordered pair (7, 3) satisfies both equations.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=solve%20x%2By%3D10%2C%20x-y%3D4
(paste-fallback: solve x+y=10, x-y=4)
Encoding note: The space, plus, equals signs, comma, and second space are encoded; decoding reproduces the exact two-equation fallback.

OUTPUT FORMAT:
1. Worksheet Inventory — all items, subparts, and missing material
2. Item-by-Item Solutions — restatement, method, numbered work, and FINAL ANSWER
3. Check-Link Index — item-labelled raw URLs and exact fallbacks
4. Human Review Queue — proofs, diagrams, constructions, models, and explanations
5. Final-Answer Index — compact original numbering
6. Completeness Audit — omissions, numbering, units, and link alignment
7. NOT-MACHINE-CHECKABLE — exact limits of tool-based checking

QUALITY AND TOOL GUARDRAILS:
- Never skip an unreadable or incomplete item silently; flag exactly what is missing.
- Do not let data, assumptions, or answers leak from one worksheet item into another.
- Use only approved endpoints, plain calculator syntax, and fully encoded focused queries.
- Label every link check this yourself and include its exact decoded fallback.
- A linked final answer does not verify proof quality, modelling choices, diagrams, or method marks.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
