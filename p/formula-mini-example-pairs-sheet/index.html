Formula + Mini-Example Pairs Sheet

Each formula paired with one tiny solved example so students see it in action.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Paste the prompt into the chat.
  2. 2. Enter your chapter and class.
  3. 3. Send and check the examples.
  4. 4. Ask it to redo any example you dislike.
  5. 5. Copy into a document and print.
🔧 If it is not right, reply with this: If an example is wrong, reply: "The example for formula [number] gives the wrong answer. Redo it and verify the arithmetic twice."
THE PROMPT
ROLE: Act as a patient mathematics teacher who teaches formulas through tiny worked examples.

CONTEXT: I teach [CLASS/GRADE] for the [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. My students remember formulas better when they see them used once. I need a formula sheet for the chapter [CHAPTER NAME] where EACH formula is followed by ONE very short solved example.

YOUR TASK:
1. List every key formula in the chapter, in textbook order.
2. After each formula, give one short worked example (one or two lines) that uses exactly that formula.
3. Show the example with the substitution and the final answer.
4. Keep examples small with easy numbers so the focus stays on the formula.
5. Group formulas under sub-headings if the chapter is large.

INPUT: Here is the chapter and class. Chapter: [PASTE HERE]. Class/Board: [PASTE HERE].

HOW TO WORK IT OUT: For each example, solve it internally first, then VERIFY the answer two ways: (a) recompute the arithmetic a second time; (b) sanity-check the answer is reasonable for the formula. Never invent a formula or a result. If you are unsure of a value, choose simpler numbers you can verify. Keep all maths fully legible in clean plain text or simple LaTeX.

OUTPUT FORMAT (use this exact order):
1. TITLE: '[Chapter] - Formulas with Mini-Examples (Class [X], [Board])'.
2. 'Compiled by [YOUR NAME]'.
3. For each item, in a numbered list: 'Formula:' on one line, then 'Example:' on the next line with the answer in bold or marked clearly.
4. A short 'Tip' line at the end of each sub-heading group if useful.
5. Footer line.

RULES: Every example must be correct and must use the stated formula. Keep examples tiny. No long derivations. Consistent notation throughout.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
