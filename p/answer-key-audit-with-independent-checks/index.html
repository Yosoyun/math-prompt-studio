Answer-Key Audit With Independent Checks

A question-by-question answer-key audit with corrected answers, confidence labels, and independent computation links where appropriate.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste numbered questions and the proposed key in matching order.
  2. 2. Include options, units, and marking conventions.
  3. 3. Review every item marked mismatch or ambiguous.
  4. 4. Open the independent links for computational items.
  5. 5. Correct the source key only after checking the original question text.
🔧 If it is not right, reply with this: If wrong, reply with: "Audit only the disputed item from the original wording, show a fresh derivation, and replace its URL and fallback together."
THE PROMPT
ROLE: Act as an answer-key auditor who treats every proposed answer as untrusted until independently derived.

CONTEXT: A teacher has a pasted answer key that may contain transcription, option, unit, or calculation errors and needs an evidence-backed correction table.

INPUTS — FILL EVERY PLACEHOLDER:
- [NUMBERED QUESTIONS]
- [PASTED ANSWER KEY]
- [MARKING RULES]

DO THIS:
1. Match each key entry to the exact corresponding question and flag missing or duplicate numbering.
2. Solve every item independently without reasoning backward from the proposed key.
3. Compare the derived result, option, units, and required form with the proposed entry.
4. Assign MATCH, MISMATCH, AMBIGUOUS, or NOT CHECKABLE FROM PROVIDED TEXT.
5. Add an approved check link for each machine-checkable answer using only that item's expression.
6. Explain every correction in one concise sentence and preserve alternate equivalent forms.
7. List non-computational proof or wording issues for human review instead of fabricating certainty.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Audit the proposed answer x = 5 for 2x + 3 = 11.
Expected result or check target: MISMATCH: solving gives x = 4, and substitution gives 2(4) + 3 = 11.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=solve%202x%2B3%3D11
(paste-fallback: solve 2x+3=11)
Encoding note: The query decodes exactly to the fallback; %20 is the space, %2B is the literal plus sign, and %3D is the equals sign.

OUTPUT FORMAT:
1. Intake Check — numbering, missing data, and legibility issues
2. Audit Table — item, proposed answer, independent answer, verdict, and reason
3. Check Links — item-labelled raw links with exact paste-fallbacks
4. Corrected Key — clean final key in original numbering
5. Human Review Queue — ambiguous wording, diagrams, and non-computational claims
6. Change Log — only the entries that differ from the pasted key

QUALITY AND TOOL GUARDRAILS:
- Never treat agreement with the pasted key as independent verification.
- Use WolframAlpha or Symbolab only for computations those tools can actually evaluate.
- Keep one query focused on one item so links cannot silently mix questions.
- Label every link check this yourself and include its exact decoded fallback.
- Do not invent missing question text, figures, answer choices, or marking rules.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
