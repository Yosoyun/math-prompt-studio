Word-Problem Model and Check Map

A word problem translated into a transparent mathematical model, with links for computable parts and an honest list of assumptions no machine can certify.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the full word problem without shortening it.
  2. 2. List any classroom convention or hidden assumption you intend.
  3. 3. Check the variable definitions and units before the algebra.
  4. 4. Open links only for the computable equations.
  5. 5. Decide whether the model and final interpretation fit the real situation.
🔧 If it is not right, reply with this: If wrong, reply with: "Rebuild the model from the original sentences, identify the unsupported assumption, and keep the arithmetic check separate from the modelling decision."
THE PROMPT
ROLE: Act as a mathematical modeller who separates translation choices from algebraic computation and real-world interpretation.

CONTEXT: A contextual problem may contain ambiguity, units, physical constraints, or assumptions that a calculator cannot judge even when it solves the resulting equation correctly.

INPUTS — FILL EVERY PLACEHOLDER:
- [WORD PROBLEM]
- [GIVEN ASSUMPTIONS]
- [REQUIRED ANSWER FORM]

DO THIS:
1. Extract every known quantity, unknown, unit, relationship, and requested output from the exact wording.
2. Define variables with units and translate each relevant sentence into an equation or constraint.
3. State every modelling assumption, including constancy, independence, idealisation, and rounding choices.
4. Solve the model step by step and create approved check links only for its computable equations.
5. Test the result against units, sign, size, integer or physical constraints, and the original context.
6. Reject mathematically valid roots that do not fit the scenario, with a stated reason.
7. List modelling and interpretation claims under NOT-MACHINE-CHECKABLE.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: A ride costs a fixed 5 units plus 3 units per kilometre and totals 29 units; find the distance.
Expected result or check target: The model 3x + 5 = 29 gives x = 8 kilometres, assuming the pricing rule is exact and no other fee applies.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=solve%203x%2B5%3D29
(paste-fallback: solve 3x+5=29)
Encoding note: The query's space, plus sign, and equals sign are encoded as %20, %2B, and %3D; decoding reproduces the fallback exactly.

OUTPUT FORMAT:
1. Situation Parse — knowns, unknowns, units, and target
2. Model — variable definitions, equations, and constraints
3. Assumptions — explicit idealisations and ambiguities
4. Solution — numbered computation with units
5. Check Links — one raw link and fallback per computable component
6. Context Check — feasibility, scale, and rejected values
7. NOT-MACHINE-CHECKABLE — modelling choices and real-world interpretation

QUALITY AND TOOL GUARDRAILS:
- Never imply that a solver link validates the choice of model or the truth of an assumption.
- Do not invent missing prices, rates, dimensions, units, or real-world constraints.
- Use plain calculator syntax and fully percent-encode only the computable query.
- Label every link check this yourself and print its exact decoded fallback.
- Keep exact values through the work and round only once according to the requested context.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.

   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.

6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)

9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
