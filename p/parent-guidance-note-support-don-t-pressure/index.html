Parent Guidance Note (Support, Don't Pressure)

A calm note to parents on how to support a child during exams without adding pressure.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Name the class and exam.
  2. 2. Note the parent behaviours you want to address.
  3. 3. Paste the whole block into the chat.
  4. 4. Send the note home with students.
  5. 5. Ask for a Hindi or regional-language version.
🔧 If it is not right, reply with this: If it sounds preachy to parents, reply: "Make it respectful and supportive, not lecturing. Keep it under one page and add 5 simple do's and don'ts for exam week."
THE PROMPT
ROLE: Act as a wise class teacher writing a respectful guidance note to parents during exam season.

CONTEXT: This is for parents of [CLASS/GRADE] students facing [BOARD or EXAM e.g. CBSE / State Board / JEE / NEET] in [DAYS] days. Common issues I see at home: [e.g. parents over-pressuring, comparing siblings, too much screen-time worry, last-minute panic, not enough sleep or food routine]. School name/teacher name for the header: [NAME].

YOUR TASK:
1. Write a short, warm note (about one page) explaining how parents can genuinely help during exams.
2. Gently address the specific home issues I listed, without blaming parents.
3. Give 5 clear 'do's' (calm routine, good sleep, healthy meals, listen, encourage) and 5 'don'ts' (don't compare, don't over-question, don't panic, etc.).
4. Add 3 simple things to say to a stressed child, and 3 things NOT to say.
5. End with a reassuring line and an invitation to contact the school with concerns.

INPUT: My class, exam and home issues are in the CONTEXT above. If issues are missing, use the most common exam-season home problems and say so.

HOW TO WORK IT OUT: Group advice into routine, emotion and communication first. VERIFY twice: (a) the tone is respectful and supportive, never lecturing, and (b) every point is practical for a busy parent. Keep it honest and culturally sensitive.

OUTPUT FORMAT (use these exact headings):
1) Header Block - school/teacher name and a one-line title.
2) Dear Parents - 2 short warm paragraphs.
3) 5 Things That Truly Help - bullets.
4) 5 Things To Avoid - bullets.
5) Say This / Not That - 3 each.
6) Closing & Contact - 2 lines.

RULES: Respectful, supportive, never blaming. One page maximum. Simple language any parent can read.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return the complete material as a clean, print-ready A4 handout that can be pasted into Word or Google Docs and saved as PDF. Use a clear title, logical sections, readable mathematics and page-break markers where needed. Keep student material separate from the answer key or teacher notes.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
