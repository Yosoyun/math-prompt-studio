Solve a Geometry Figure From a Photo

The figure described in words, then a full geometry solution with the theorems named.

Attach a photo of the question first  ·  Best tool:  ChatGPT or Gemini (image)

✅ How to use this effectively

  1. 1. Photograph the figure and the question together.
  2. 2. Make sure all labels and marks are sharp.
  3. 3. Attach the photo and paste this prompt.
  4. 4. Check the figure description it wrote.
  5. 5. Correct any mislabelled point, then re-solve.
🔧 If it is not right, reply with this: If it misreads the diagram, reply: "Re-describe the figure first. Point [X] is actually [where]. The right angle is at [vertex]. Now re-solve."
THE PROMPT
ROLE: Act as a geometry teacher who reads a figure carefully, describes it precisely, and solves it with the correct theorems.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET], topic [TOPIC]. The photo shows a GEOMETRY FIGURE with a question. Misreading the figure is the biggest danger, so describe it before solving.

YOUR TASK:
1. Read the attached photo and write a precise description of the figure: name every point, line, angle, given measurement, and any marks (right-angle squares, equal-length ticks, parallel arrows).
2. State clearly what the question asks to find or prove.
3. Solve using named theorems and properties, step by step.

INPUT: I have attached a photo of the figure and the question. If a label, measurement, or mark is unclear, tell me which one, state your best assumption, and continue. Do not assume a figure is to scale unless it says so.

HOW TO WORK IT OUT: Solve the problem silently first. Then VERIFY the result with TWO independent checks, for example: (a) check angle sums or side relations are consistent, and (b) re-derive using a different theorem or by coordinates. If the checks disagree, fix the error before replying. Never invent measurements or assume values not given; never rely on "it looks like" from the drawing. Name every theorem you use correctly. Keep all mathematics fully legible in clean LaTeX or clear plain text, one step per line.

OUTPUT FORMAT (use these exact headings):
1. Figure description - points, lines, angles, given values, and all marks.
2. To find or prove - one line.
3. Theorems and properties used - a short named list.
4. Step-by-step solution - numbered, one idea per line, with the reason (theorem) for each step.
5. Final answer - clearly stated with units or the completed proof.
6. Verification - Check 1 and Check 2, each in one or two lines.

RULES: Do not use anything that is not given or properly derived. Distinguish given facts from deduced facts. Use plain ASCII only with straight quotes. Be exact unless an estimate is requested.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
At the very end add a footer line: "Prepared by [YOUR NAME]", and put "Compiled by [YOUR NAME]" in the title or header block at the top.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
