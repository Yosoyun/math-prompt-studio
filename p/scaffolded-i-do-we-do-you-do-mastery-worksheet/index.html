Scaffolded I-Do We-Do You-Do Mastery Worksheet

A gradual-release worksheet: a worked model, guided fill-in-the-blank practice, then independent questions with a key.

Works on any free AI  ·  Best tool:  ChatGPT (free) or Claude (free)

✅ How to use this effectively

  1. 1. Name the single skill to teach.
  2. 2. Set the class and board.
  3. 3. Read the I-Do model aloud first.
  4. 4. Hand out the We-Do part together.
  5. 5. Release the You-Do part solo.
🔧 If it is not right, reply with this: If the guided 'We Do' gives away too much, type: 'Fade the scaffolding faster: blank out the key decision steps in We-Do, not just the arithmetic.'
THE PROMPT
Act as an instructional-design expert and mathematics teacher building a gradual-release (I do / we do / you do) mastery worksheet for one skill.

CONTEXT: Class [CLASS/GRADE], board/exam [BOARD or EXAM]. The single target skill is [SKILL, e.g. solving linear equations with brackets]. I want one focused worksheet that moves from a fully worked teacher model, through guided fill-in-the-blank practice, to independent practice, with the scaffolding fading as students progress.

YOUR TASK:
1. I DO (model): one fully worked example, every step shown with a short 'why' note beside each line. This is the teacher's think-aloud script.
2. WE DO (guided): three questions presented as partially worked solutions with strategic blanks. Blank out the decision steps and key moves, not just the final arithmetic, so students supply the thinking.
3. YOU DO (independent): six clean questions, no scaffolding, rising gently in difficulty.
4. CHALLENGE: one stretch question that applies the skill in a slightly new context.
5. Keep everything on the one skill; do not broaden the topic.

INPUT: Skill, class and board are above. If I paste my preferred worked example here: [PASTE or leave blank], mirror its layout and notation in the I DO section.

HOW TO WORK IT OUT: Solve all items yourself first. VERIFY every final answer by two independent checks (substitute back and/or re-solve differently). Never invent rules or values; keep answers clean and age-appropriate. Keep mathematics fully legible in plain text (^ for powers, sqrt(), / for fractions, aligned steps).

OUTPUT FORMAT (exact order):
- Title block with 'Compiled by [YOUR NAME]', skill name, Name / Class / Date lines.
- Learning target: one line, 'By the end I can ...'.
- Section I DO (worked model with why-notes).
- Section WE DO (3 guided items with blanks).
- Section YOU DO (6 independent items).
- CHALLENGE (1 item).
- '--- ANSWER KEY ---' with completed We-Do blanks and all final answers.

RULES: Scaffolding must genuinely fade. Blanks must target reasoning, not just numbers. A4-friendly, spaced for handwriting. No invented mathematics. State one assumption if unclear and continue.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
