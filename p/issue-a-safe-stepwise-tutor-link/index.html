Issue a Safe Stepwise Tutor Link

A short student-facing tutor prompt encoded into a browser link that asks one diagnostic question, gives graduated hints, and checks understanding before showing a worked solution.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Use one narrow skill per link.
  2. 2. Remove names, marks, and account details.
  3. 3. Open the link in a browser and review the prefilled text.
  4. 4. Tell students to press Send only after reading it.
  5. 5. Test the independent maths check yourself.
🔧 If it is not right, reply with this: If the tutor reveals answers too early, ask it to require one student attempt before each next hint and to reserve the complete solution for the final section.
THE PROMPT
ROLE: Act as a teacher creating a privacy-safe, hint-first AI tutor link for students.

CONTEXT: Students in [CLASS] need guided practice on [TOPIC] using [REPRESENTATIVE PROBLEM] without having their personal data encoded in a URL.

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [TOPIC]
- [REPRESENTATIVE PROBLEM]
- [LANGUAGE]

SOURCE-BOUND TOOL FACTS AND EXACT URL WHITELIST:
- [CHATGPT] Whitelist template: https://chatgpt.com/?q={ENCODED_PROMPT}. It prefills but does not auto-submit, can lose the query in a phone app, and should stay under 1,800 characters; tell students to open it in a browser and never include personal data.
- [CLAUDE] Whitelist template: https://claude.ai/new?q={ENCODED_PROMPT}. It prefills for review and does not auto-submit; login is normally required, so provide the exact prompt as a paste fallback and never encode personal data.

DO THIS:
1. Write a compact tutor prompt that asks the student to attempt the problem first.
2. Build three graduated hints and reveal only one after each student reply.
3. Require the tutor to check the student's step, explain the exact misconception, and ask a follow-up.
4. Create a ChatGPT or Claude source-bound prefill URL from the final prompt and keep the full encoded URL under 1,800 characters.
5. State that the prefill does not auto-submit, must be opened in a browser, and requires the student to review and press Send.
6. Add one approved computational check link when the example has a machine-checkable answer.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Guide a Class 7 student through solving 3x+2=14 without giving the answer first.
Expected result or check target: The tutor asks for a first step, offers inverse-operation hints, and checks the final value only after the student responds.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=solve%203x%2B2%3D14
(paste-fallback: solve 3x+2=14)
Encoding note: Decoding %20, %2B, and %3D reproduces the fallback exactly; this approved link checks the worked example, not the tutor's pedagogy.

OUTPUT FORMAT:
1. Teacher Review Copy — the exact tutor prompt
2. Student Link — one raw source-bound prefill URL
3. Student Directions — open in browser, review, then press Send
4. Privacy Check — data removed and encoded-length result
5. Maths Check — labelled check this yourself with fallback

QUALITY AND TOOL GUARDRAILS:
- ChatGPT ?q= and Claude /new?q= are source-bound prefill templates only; never claim they auto-submit.
- Never encode student names, email addresses, marks, school IDs, health data, or private work records.
- Keep the encoded prompt URL under 1,800 characters and provide plain prompt text as fallback.
- Never use gemini.google.com as a prefill target; Google AI Mode is a separate auto-running route.
- Do not let the tutor describe its own answer as verified.
- Copy every [PLACEHOLDER IN SQUARE BRACKETS] character-for-character in every template, code block and translated variant.
- Never output a desmos.com URL with parameters, a mathsolver.microsoft.com URL, an invented GeoGebra material ID, an invented DIKSHA code, an invented Khan topic path, or an unlisted quiz or simulation slug.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
