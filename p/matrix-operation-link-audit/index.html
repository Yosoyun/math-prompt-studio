Matrix Operation Link Audit

A determinant, inverse, and rank audit with separate links, hand calculations, and consistency checks for the same pasted matrix.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the matrix with unambiguous rows and columns.
  2. 2. State the number system and requested operations.
  3. 3. Follow the determinant and row-reduction work.
  4. 4. Open separate links for determinant, inverse, and rank.
  5. 5. Multiply the proposed inverse back by the original matrix.
🔧 If it is not right, reply with this: If wrong, reply with: "Copy the original matrix into all three queries again, identify the first row-operation error, and rerun the determinant-inverse-rank consistency checks."
THE PROMPT
ROLE: Act as a linear-algebra checker who verifies each matrix operation independently while preserving the exact matrix entries.

CONTEXT: The user needs determinant, inverse, and rank results protected against transcription errors, illegal row operations, and inconsistency between singularity claims.

INPUTS — FILL EVERY PLACEHOLDER:
- [MATRIX]
- [NUMBER SYSTEM]
- [REQUESTED OPERATIONS]

DO THIS:
1. Restate the matrix with dimensions and row boundaries before computing.
2. Compute the determinant with a transparent expansion or row-reduction method.
3. Determine invertibility from the determinant and compute the inverse only when it exists.
4. Find rank by justified elementary row operations and display the echelon form.
5. Create separate approved links for determinant, inverse, and rank, each repeating the exact matrix.
6. Check A times A inverse equals the identity when an inverse exists.
7. Explain consistency among determinant, rank, and invertibility.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Find the determinant, inverse, and rank of the matrix with rows (1, 2) and (3, 4).
Expected result or check target: The determinant is -2, the inverse is [[-2,1],[3/2,-1/2]], and the rank is 2.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=det%20%7B%7B1%2C2%7D%2C%7B3%2C4%7D%7D
(paste-fallback: det {{1,2},{3,4}})
Encoding note: Spaces, braces, and commas are percent-encoded; decoding the input value gives the exact matrix fallback character-for-character.

OUTPUT FORMAT:
1. Matrix Intake — exact matrix, dimensions, and number system
2. Determinant — hand calculation, result, raw link, and fallback
3. Inverse — existence test, calculation, raw link, and fallback
4. Rank — row reduction, result, raw link, and fallback
5. Consistency Checks — singularity and identity-product checks
6. Final Summary — determinant, inverse status, and rank

QUALITY AND TOOL GUARDRAILS:
- Never claim an inverse exists when the determinant is zero or rank is deficient.
- Do not use an unannounced row swap, scaling, or row addition in the written determinant work.
- Use plain calculator matrix syntax and fully encode brackets, braces, commas, and spaces.
- Label every link check this yourself and include its exact decoded fallback.
- Ensure all operation links contain the same matrix entries in the same order.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
