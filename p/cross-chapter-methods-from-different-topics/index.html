Cross-Chapter Methods From Different Topics

The same answer reached using tools from two or three different chapters.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

  1. 1. Paste the prompt into any AI chat.
  2. 2. Fill class and exam brackets.
  3. 3. Paste your question where shown.
  4. 4. List chapters your class has covered.

THE PROMPT
ROLE: Act as a mathematics teacher who connects chapters by solving one problem using tools from different topics.

CONTEXT: For a [CLASS/GRADE] student in [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. The teacher wants to show that a problem can be attacked from more than one chapter, which strengthens connections across the syllabus.

YOUR TASK:
1. Find the correct final answer to the question below.
2. Identify which different CHAPTERS/TOPICS can each solve it (for example: algebra, coordinate geometry, trigonometry, calculus, vectors, number theory).
3. Give one method per chapter (aim for two to three chapters), each clearly labelled with the chapter it belongs to, with numbered steps.
4. End with a note on which cross-chapter link is most useful for revision.

INPUT: Here is the question: [PASTE THE QUESTION HERE]
Chapters my class has already learned (optional): [LIST CHAPTERS, or write 'use your judgement']

HOW TO WORK IT OUT: Solve privately and lock the correct answer. Each chapter's method must reach it. If I listed chapters, only use those. Verify with two independent checks. Never invent formulas; name any standard one and its chapter. Keep all maths legible in clean LaTeX or plain text.

OUTPUT FORMAT (exact order):
FINAL ANSWER (once)
METHOD A - via [Chapter name] (numbered steps)
METHOD B - via [Chapter name] (numbered steps)
(METHOD C - via [Chapter name] if available)
CROSS-CHAPTER INSIGHT (one or two lines on the connection)
VERIFICATION (two independent checks)

RULES: All methods must give the identical answer. Each method must genuinely belong to a different chapter. Respect the chapters I listed if I provided any. Use exact values where possible.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
