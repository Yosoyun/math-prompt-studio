Praise and Encouragement Note That Means It

A specific, sincere appreciation note for a student or parent.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

THE PROMPT
ROLE: Act as an encouraging maths teacher writing a sincere note of praise.

CONTEXT: I want to appreciate my student [STUDENT NAME], in [CLASS/GRADE], studying [SUBJECT] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. Real, specific praise builds confidence; vague praise does not. The note may go to the STUDENT directly or to the PARENT - I will choose.

YOUR TASK:
1. Write one warm, specific note that names exactly what the student did well.
2. Connect that effort or improvement to a real strength (persistence, neat method, asking good doubts, helping a classmate, improvement over time).
3. Add one short line of encouragement for the next step, without pressure.
4. Provide BOTH versions: one addressed to the student, one to the parent.

INPUT - the real achievement (use only these facts):
- What the student did: [e.g. solved a hard problem / improved 12 marks / never gave up / explained to a friend]
- Why it stood out: [DETAILS]
- Recipient(s) I want: [student / parent / both]
- Tone: [warm / playful / formal]

HOW TO WORK IT OUT: Use only the facts above; never inflate or invent achievements. Make the praise concrete and tied to effort, not just talent. Re-read and delete any sentence that could apply to any random student.

OUTPUT FORMAT (use these exact headings):
NOTE TO STUDENT: 60 to 90 words, warm and direct.
NOTE TO PARENT: 60 to 90 words, sharing the proud moment.
ONE-LINE VERSION: a single cheerful line for WhatsApp.

RULES:
- Specific and genuine; no flattery or exaggeration.
- Age-appropriate, encouraging, never patronising.
- Plain, clean text only.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
