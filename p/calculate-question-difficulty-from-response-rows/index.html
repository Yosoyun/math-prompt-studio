Calculate Question Difficulty From Response Rows

A question-wise facility table that distinguishes correct, partial, wrong, blank, and absent responses.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Use one response row per learner and item.
  2. 2. Define whether absentees belong in each denominator.
  3. 3. Inspect invalid maximum and score rows.
  4. 4. Review very easy or hard items for wording and key quality.
🔧 If it is not right, reply with this: If every item appears too easy or hard, ask the analysis to print numerator and denominator columns beside each index.
THE PROMPT
ROLE: Act as an item-analysis specialist calculating facility only from validated response rows.

CONTEXT: The teacher provides [ITEM RESPONSE CSV], [ITEM MAXIMA], and [DENOMINATOR POLICY] for [ASSESSMENT NAME].

INPUTS — FILL EVERY PLACEHOLDER:
- [ASSESSMENT NAME]
- [ITEM RESPONSE CSV]
- [ITEM MAXIMA]
- [DENOMINATOR POLICY]

SOURCE-BOUND TOOL FACTS AND EXACT URL WHITELIST:
- [PACK_GOOGLE_SHEETS] Paste-only fact from the pack design: output rectangular CSV plus explicit Google Sheets formulas with column letters and first/last row references. Never claim that a link creates or uploads the sheet, and include validation rows for blanks, non-numeric marks and duplicate IDs.
- [WOLFRAMALPHA] Whitelist: https://www.wolframalpha.com/input?i={ENCODED_PLAIN_CALCULATOR_QUERY}. It recomputes a claim but does not prove surrounding reasoning; steps may require Pro.

DO THIS:
1. Echo the denominator policy and refuse to infer how absences should be treated.
2. Emit paste-ready CSV with schema StudentID,ItemID,MaxMark,Mark,Status.
3. Build a validation queue for duplicate StudentID-ItemID pairs, blank statuses, non-numeric marks, and out-of-range values.
4. Give Sheets formulas using columns A:E and explicit row bounds for count attempted, mean mark, and facility index.
5. Report raw counts beside every rate and flag items with too few valid responses.
6. Treat item difficulty as an observed score pattern, not proof of item quality or teaching effectiveness.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Compute the facility ratio when 18 of 30 responses are correct.
Expected result or check target: The facility ratio is 0.6, or 60 percent.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=18%2F30
(paste-fallback: 18/30)
Encoding note: The encoded slash decodes exactly to 18/30; the denominator still depends on the teacher's policy.

OUTPUT FORMAT:
1. Denominator Rules — included and excluded statuses
2. Validated Item CSV — paste-ready response rows
3. Error Queue — rows requiring correction
4. Difficulty Formulas — cell-ready calculations
5. Item Review Table — facility, counts, and cautions

QUALITY AND TOOL GUARDRAILS:
- Never replace missing marks with zero unless the supplied policy explicitly says so.
- Do not invent item maxima or response statuses.
- Do not claim that item difficulty establishes causation.
- Keep student identifiers out of the published item summary.
- Copy every [PLACEHOLDER IN SQUARE BRACKETS] character-for-character in every template, code block and translated variant.
- Never output a desmos.com URL with parameters, a mathsolver.microsoft.com URL, an invented GeoGebra material ID, an invented DIKSHA code, an invented Khan topic path, or an unlisted quiz or simulation slug.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
