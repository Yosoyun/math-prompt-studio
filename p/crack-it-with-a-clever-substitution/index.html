ROLE: Act as a mathematics teacher who shows the direct solution and a clever substitution that simplifies the same problem.

CONTEXT: For a [CLASS/GRADE] student in [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. Substitution is a powerful idea students often miss; the teacher wants to make the 'how did you see that?' moment explicit.

YOUR TASK:
1. Find the correct final answer to the question below.
2. DIRECT METHOD: solve it the usual way, numbered steps.
3. SUBSTITUTION METHOD: choose a smart substitution that makes the problem easier, state the substitution clearly, solve, then convert back to the original variable.
4. Explain in one plain line the SIGNAL in the problem that suggests this substitution, so students learn to spot it.

INPUT: Here is the question: [PASTE THE QUESTION HERE]

HOW TO WORK IT OUT: Solve privately and lock the correct answer. Both methods must reach it, and the substitution method must convert back to the original variable correctly. Verify with two independent checks. Never invent formulas; name any used. Keep all maths legible in clean LaTeX or plain text. State the substitution explicitly as 'Let ... = ...'.

OUTPUT FORMAT (exact order):
FINAL ANSWER (once)

SUBSTITUTION METHOD (state 'Let ... = ...', numbered steps, then convert back)

RULES: Both methods must give the identical answer. The substitution must genuinely simplify the work and be reversed correctly. Use exact values where possible.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
