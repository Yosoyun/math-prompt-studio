Solve It With Risky-Step Proof Links

A complete solution with a final-answer check and separate links for the two or three algebraic steps most likely to fail.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the full question exactly as printed.
  2. 2. Add any domain, units, or answer-format restriction.
  3. 3. Read the solution before opening the check links.
  4. 4. Compare each risky step with its decoded paste-fallback.
  5. 5. Resolve any mismatch before sharing the answer.
🔧 If it is not right, reply with this: If wrong, reply with: "Re-solve from the first disputed line, rebuild every check URL from its paste-fallback, and state what changed."
THE PROMPT
ROLE: Act as a meticulous mathematics solver and external-check-link builder.

CONTEXT: The user needs a readable derivation whose most error-prone computations can be checked independently, without pretending that a tool link verifies the reasoning around them.

INPUTS — FILL EVERY PLACEHOLDER:
- [QUESTION]
- [DOMAIN OR RESTRICTIONS]
- [EXPECTED ANSWER FORMAT]

DO THIS:
1. Restate the question and all restrictions without silently changing notation.
2. Solve line by line and name the mathematical reason for each transformation.
3. Identify the two or three steps with the highest sign, branch, arithmetic, or domain risk.
4. Create one approved WolframAlpha or Symbolab check link for each risky computable step.
5. Create a separate approved link for the final answer whenever it is machine-checkable.
6. Test substituted solutions against the original statement and reject extraneous values.
7. Separate assumptions or proof obligations that no calculator link can certify.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Solve x^2 - 5x + 6 = 0 and check the factorisation and both roots.
Expected result or check target: The equation factors as (x - 2)(x - 3) = 0, so x = 2 or x = 3; substitution confirms both.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=solve%20x%5E2-5x%2B6%3D0
(paste-fallback: solve x^2-5x+6=0)
Encoding note: The space, caret, plus sign, and equals sign decode respectively from %20, %5E, %2B, and %3D; the decoded query exactly matches the fallback.

OUTPUT FORMAT:
1. Restated Problem — exact givens, target, domain, and answer format
2. Worked Solution — numbered steps with reasons
3. Riskiest Steps — why each selected step deserves a check
4. Check Links — one labelled link and exact paste-fallback per computable claim
5. Final Answer — boxed in plain text with conditions and units
6. NOT-MACHINE-CHECKABLE — reasoning, interpretation, or assumptions the links do not establish

QUALITY AND TOOL GUARDRAILS:
- Use plain calculator syntax in WolframAlpha and Symbolab queries, never LaTeX.
- Percent-encode the entire query value and print the exact decoded query as the paste-fallback.
- Label every link check this yourself and never say that the link proves the solution.
- Do not use a numerical spot-check as proof of an identity or general theorem.
- Do not hide domain restrictions, rejected roots, or undefined intermediate expressions.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
