Build an Olympiad Problem-Solving Reading Trail

A reading-and-solving trail that moves from topic vocabulary to human solution discussions, strategy comparison, source checking, and a teacher teach-back.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Choose one strategy theme.
  2. 2. Solve before reading discussions.
  3. 3. Compare at least two human solutions.
  4. 4. Record only sourced contest details.
  5. 5. Teach back the strategy.
🔧 If it is not right, reply with this: If the trail becomes a list of links, add a pre-solve task, a solution-comparison table, and a final transfer problem for each stage.
THE PROMPT
ROLE: Act as an olympiad professional-learning curator using search links rather than invented problem provenance.

CONTEXT: A teacher wants to study [STRATEGY THEME] at [LEVEL] through [TIME AVAILABLE].

INPUTS — FILL EVERY PLACEHOLDER:
- [STRATEGY THEME]
- [LEVEL]
- [TIME AVAILABLE]
- [KNOWN PREREQUISITES]

SOURCE-BOUND TOOL FACTS AND EXACT URL WHITELIST:
- [AOPS] Whitelist: https://artofproblemsolving.com/community/q1_{ENCODED_KEYWORDS}. The q1_ pattern is an undocumented search route, so also print the exact keywords as a paste fallback and never claim a search result proves contest provenance.
- [MATH_STACKEXCHANGE] Whitelist: https://math.stackexchange.com/search?q={ENCODED_KEYWORDS}. Search with one real tag plus 3–6 keywords; do not paste a full equation and do not present votes or acceptance as mathematical proof.

DO THIS:
1. Define the strategy and its prerequisites without assigning an invented historical source.
2. Create an AoPS q1_ keyword search and a Math StackExchange tag-keyword search.
3. Require a genuine pre-solve attempt before reading results.
4. Build a comparison table for assumptions, key insight, proof structure, and generalisation.
5. Record contest provenance only from an opened source and mark unresolved attribution.
6. End with a transfer problem labelled teacher-created unless a source is confirmed.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Create a reading trail for parity invariants.
Expected result or check target: The teacher pre-solves, compares human discussions, records sources carefully, and teaches back a transfer task.
check this yourself
CHECK → https://artofproblemsolving.com/community/q1_parity%20invariant
(paste-fallback: parity invariant)
Encoding note: The %20 sequence decodes to the exact single space in the AoPS search fallback.

OUTPUT FORMAT:
1. Strategy Primer — concept and prerequisites
2. Search Trail — AoPS and Math StackExchange links
3. Pre-Solve Task — independent attempt
4. Solution Comparison — human approaches and limits
5. Source Ledger — confirmed and unresolved provenance
6. Teach-Back — transfer problem and explanation

QUALITY AND TOOL GUARDRAILS:
- Never present an AI-generated problem as an authentic past olympiad or invent contest provenance.
- Use AoPS q1_ and Math StackExchange search patterns only; inspect actual results before citing them.
- Do not invent PhET, Demonstration, or GeoGebra material slugs when adding visuals.
- Check current competition rules or syllabus claims at official dated sources.
- Label every external search check this yourself.
- Copy every [PLACEHOLDER IN SQUARE BRACKETS] character-for-character in every template, code block and translated variant.
- Never output a desmos.com URL with parameters, a mathsolver.microsoft.com URL, an invented GeoGebra material ID, an invented DIKSHA code, an invented Khan topic path, or an unlisted quiz or simulation slug.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
