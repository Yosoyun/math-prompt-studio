Blueprint / Weightage Table Only (No Questions)

A clean blueprint table mapping chapters to marks and question types, ready to set a paper from.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Paste the prompt into a chat.
  2. 2. List all chapters in the syllabus.
  3. 3. Set the total marks and sections.
  4. 4. Send and read the table.
  5. 5. Confirm the TOTAL row matches your marks.
  6. For a trustworthy answer key: paste the finished paper into a FRESH chat and ask it to solve and grade it as an unseen exam (it catches its own slips).

THE PROMPT
ROLE: Act as a mathematics curriculum planner who designs exam blueprints.

CONTEXT: Before I set a paper I need a BLUEPRINT (weightage table) only - NO questions yet - for Class [CLASS/GRADE], [BOARD or EXAM e.g. CBSE / ICSE / State Board]. Total marks [TOTAL MARKS]. The sections to plan for are [LIST SECTIONS e.g. MCQ, Short, Long, Case-Study].

YOUR TASK:
1. Allocate marks across the chapters in proportion to their importance and typical exam weight.
2. For each chapter, show how many questions fall in each section and the marks.
3. Add a TOTAL row that must equal [TOTAL MARKS] exactly.
4. Add a short note (3 to 4 lines) explaining the difficulty spread you recommend.

INPUT: The chapters and their relative importance (if known) are: [LIST CHAPTERS, optionally with high/medium/low priority]. If priority is not given, use the standard typical weightage for this class and say so.

HOW TO WORK IT OUT: Compute the marks per chapter and per section so every row and column adds up consistently. Verify the grand total equals [TOTAL MARKS] by adding rows and adding columns independently - both must match. Never invent syllabus chapters. Keep numbers clean and round.

OUTPUT FORMAT, in this order:
1. HEADER: 'Exam Blueprint - Mathematics', class, board, total marks, 'Compiled by [YOUR NAME]'.
2. BLUEPRINT TABLE: rows are chapters, columns are the sections (questions and marks), with a TOTAL row and a TOTAL column.
3. DIFFICULTY NOTE: recommended easy/moderate/hard split.
4. A one-line check confirming rows and columns both sum to [TOTAL MARKS].

RULES: TOTAL must equal [TOTAL MARKS] exactly. No questions in this output. Use only real syllabus chapters.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
