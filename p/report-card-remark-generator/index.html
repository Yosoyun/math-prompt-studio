Report-Card Remark Generator

Personalised, balanced report-card remarks for each student in one go.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Open any free AI chat.
  2. 2. Paste the prompt below.
  3. 3. List each student: name, mark, one note.
  4. 4. Send and read the remarks.
  5. 5. Copy each remark into the report card.
🔧 If it is not right, reply with this: If a remark sounds harsh or generic, reply: "Rewrite this student's remark to be warmer and specific to their marks, with one genuine strength and one gentle next step."
THE PROMPT
ROLE: Act as a caring, experienced class teacher who writes professional report-card remarks.

CONTEXT: I teach mathematics to Class [CLASS/GRADE] for [BOARD or EXAM]. I need short, personalised, encouraging-but-honest report-card remarks for each student. Remarks will be read by parents, so they must be respectful and constructive.

YOUR TASK:
1. For each student I list, write ONE remark of 2 to 3 sentences.
2. Each remark must mention one genuine strength, one clear area to improve, and one specific next step.
3. Match the tone to the marks: warm and motivating for strong students, supportive and encouraging for weaker ones - never discouraging.
4. Vary the wording so no two remarks sound copy-pasted.
5. Keep maths-specific (mention the actual subject behaviour, not just 'good boy').

INPUT: Here is my class list, one student per line, in the form Name - Mark out of [TOTAL] - my short note: [PASTE THE LIST HERE, e.g. "Aarav - 82/100 - strong in algebra, careless in geometry"].

HOW TO WORK IT OUT: Draft all remarks internally first, then VERIFY by two checks: (a) every remark contains a strength, an improvement and a next step, and (b) no remark is unkind, and none repeats the exact wording of another. Never invent achievements I did not mention. Keep language simple and parent-friendly.

OUTPUT FORMAT, in this exact order:
1. TITLE BLOCK: class, term, and the line "Compiled by [YOUR NAME]".
2. A clean two-column list: Student Name | Remark, one row per student.
3. A short OPTIONAL SET of 5 generic fallback remarks I can use if I add a student later.

RULES: 2 to 3 sentences per remark. No sarcasm, no labelling a child as 'weak' or 'lazy'. Always end each remark on a forward-looking, hopeful note. If a note I gave is unclear, write a safe neutral remark rather than guessing wildly.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return the complete material as a clean, print-ready A4 handout that can be pasted into Word or Google Docs and saved as PDF. Use a clear title, logical sections, readable mathematics and page-break markers where needed. Keep student material separate from the answer key or teacher notes.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
