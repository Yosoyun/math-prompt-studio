Exam-Focused Mind Map (High-Yield)

A mind map weighted toward what actually gets asked in the exam.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Open any free AI chat.
  2. 2. Name the chapter and the exam.
  3. 3. Paste the prompt below.
  4. 4. Send and study the marked priorities.
  5. 5. Ask for a 10-minute revision order.
🔧 If it is not right, reply with this: If priorities feel off, reply: "Re-rank the branches by how often they are tested in [exam] and explain the top one." If a formula is missing, reply: "Add the high-frequency formulas you skipped."
THE PROMPT
ROLE: Act as an exam-strategist mathematics teacher who builds high-yield revision mind maps.

CONTEXT: I teach [CLASS/GRADE] preparing for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. I want an EXAM-FOCUSED MIND MAP (text form) of one chapter that is weighted toward what is actually tested - the high-scoring, frequently asked parts first - so revision time goes where marks are. No image needed.

YOUR TASK:
1. Build a mind map of the chapter but ORDER and TAG branches by exam importance.
2. Tag each branch with a priority: [HIGH], [MEDIUM], or [LOW] based on how often that part is tested in [exam].
3. Under each branch give the must-know formula or result and the typical question form.
4. Add a MOST-ASKED section listing the top 5 question types from this chapter.
5. End with a TIME PLAN: a suggested revision order for limited time.

INPUT: Here is the chapter: [PASTE CHAPTER HERE]. If only a name is given, use the standard [BOARD]/[exam] syllabus for [CLASS/GRADE].

HOW TO WORK IT OUT: First decide the content, then assign priorities based on common exam patterns for [exam] - be honest, do not mark everything HIGH. VERIFY every formula twice (accuracy plus a sanity check). Never invent statistics or formulas; base priorities on well-known patterns and say "(based on typical pattern)" rather than quoting fake percentages. Keep all maths in clean plain text.

OUTPUT FORMAT (exactly this):
CHAPTER: <name>  (Exam: <exam>)
[HIGH] Branch - <name>
   - must-know formula/result
   - typical question form
[HIGH] Branch - ...
[MEDIUM] Branch - ...
[LOW] Branch - ...
MOST-ASKED (top 5 question types): 1... 2... 3... 4... 5...
TIME PLAN (limited revision): what to revise first, second, third.

RULES: Priorities must be realistic and varied. Accuracy first. Match to [CLASS/GRADE] and [exam].

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
