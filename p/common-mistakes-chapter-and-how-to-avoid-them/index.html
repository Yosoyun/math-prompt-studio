Common Mistakes Chapter (And How To Avoid Them)

A focused chapter cataloguing the real errors students make on a topic, each with the wrong work, the fix, and a check-yourself drill.

Works on any free AI  ·  Best tool:  Claude (free) or ChatGPT (free)

  1. 1. Enter topic, class and exam.
  2. 2. Paste real student errors if you have them.
  3. 3. Ask for 12-15 mistakes.
  4. 4. Request the self-check drill at the end.
  5. 5. Export to Word for handouts.

THE PROMPT
Act as an experienced examiner and remedial-teaching specialist who has graded thousands of scripts.

CONTEXT: Write a 'Common Mistakes and How to Avoid Them' chapter for [CLASS/GRADE] students on the topic [TOPIC], pitched at [BOARD or EXAM]. The goal is to permanently fix the errors that cost students marks.

YOUR TASK:
1. Write a short intro on why mistakes on this topic are so costly.
2. Present 12-15 DISTINCT COMMON MISTAKES. For each, give: (a) a clear NAME for the error; (b) the WRONG WORKING exactly as a student would write it, with the precise faulty line marked; (c) WHY it is wrong (the misconception underneath); (d) the CORRECT WORKING in full; (e) a 'NEVER-AGAIN RULE' (a one-line guardrail); (f) a quick SELF-CHECK the student can apply under exam pressure.
3. Group the mistakes into logical clusters (e.g. conceptual, algebraic, notational, careless).
4. End with a DIAGNOSTIC DRILL: 10 short items where the student must spot/correct the error, plus an answer key explaining each.

INPUT: Real student mistakes I have observed (optional): [PASTE OR LEAVE BLANK]. If blank, draw on the genuinely most frequent errors for this topic and level.

HOW TO WORK IT OUT: For every wrong-vs-right pair, solve the problem correctly internally first and VERIFY the correct answer two independent ways. Ensure each 'mistake' is one real students actually make - not a contrived error. Never invent formulas; keep all maths in clean ASCII (^, sqrt(), a/b, brackets) and clearly legible so the wrong and right lines are easy to compare.

OUTPUT FORMAT (exact order): TITLE BLOCK ('Common Mistakes in [TOPIC]', 'Compiled by [YOUR NAME]'); 1. Why These Errors Cost Marks; 2. Mistake Catalogue (Mistake 1...15, each with the six labelled parts a-f); 3. Quick-Reference 'Never-Again' Rules (bulleted list of all guardrails); 4. Diagnostic Drill (10 items); 5. Drill Answer Key with explanations.

RULES: Plain ASCII maths, straight quotes, normal hyphens. No duplicate mistakes, no fabricated examples. Keep wrong-working realistic and the corrections airtight.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
