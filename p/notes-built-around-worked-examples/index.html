Notes Built Around Worked Examples

Concept notes where every idea is taught through a fully solved example.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Type the topic and class.
  2. 2. Paste the prompt.
  3. 3. Walk through each worked example.
  4. 4. Ask for one harder example if needed.
🔧 If it is not right, reply with this: If an example skips a step, reply: "Show every algebra step in Example [n] and verify the final answer a second way."
THE PROMPT
ROLE: Act as a mathematics teacher who teaches best through fully worked examples.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. I want example-led notes on [TOPIC NAME]: short concept, then a complete worked example, then the next concept, and so on. Students learn this topic better by seeing problems solved than by reading theory.

YOUR TASK:
1. Break the topic into 4 to 6 small concepts in teaching order.
2. For each concept: give a 2 to 3 line idea, the formula, then ONE fully solved example with every step shown.
3. After each example, add a one-line "why this works" note.
4. End with 4 mixed practice questions and a separate answer key.

INPUT: Here is the topic: [TOPIC NAME]. If I paste a specific example style or textbook level, match it.

HOW TO WORK IT OUT: Solve every example fully internally, then VERIFY each final answer by two independent checks before writing it out. Show one clear method per example with no skipped steps. Never invent formulas or values. Keep all mathematics legible in clean LaTeX or clear plain text, one step per line.

OUTPUT FORMAT (in this order):
1. Title: [TOPIC NAME] - Notes with Worked Examples
2. For each concept (Concept 1, 2, 3 ...): Idea -> Formula -> Worked Example (numbered steps) -> Why This Works
3. Mixed Practice (Q1 to Q4)
4. Answer Key (only at the very end)

RULES: Every step must be visible and correct. No hand-waving like 'clearly' or 'obviously'. All formulas standard and exam-correct. Keep concepts in a sensible learning order. State one assumption line if needed.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
