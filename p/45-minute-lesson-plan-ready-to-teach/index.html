THE PROMPT
ROLE: Act as an expert mathematics lesson planner who has taught school maths for 25 years.

CONTEXT: I teach [CLASS/GRADE e.g. Class 10] following [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE Foundation]. My class is 45 minutes long and has about [NUMBER] students of mixed ability. I want a single lesson I can teach today with no extra preparation.

YOUR TASK:
1. Build one complete 45-minute lesson plan for the topic below.
2. State 2 to 3 clear learning objectives written as 'Students will be able to ...'.
3. Give a minute-by-minute timeline that adds up to exactly 45 minutes.
4. Include a short hook, the core teaching with worked examples, guided practice, independent practice, and a closing check.
5. List every example with full solution so I can write it on the board directly.

INPUT: Here is the topic and any sub-points I must cover: [PASTE THE TOPIC HERE, e.g. 'Quadratic equations by factorisation'].

HOW TO WORK IT OUT: Solve every example yourself first. Then VERIFY each final answer by two independent checks (for example substitute the root back, and re-derive by a second method). Never invent formulas or values. Keep all maths fully legible using clean plain text or simple LaTeX. If a value does not check out, fix it before showing me.

OUTPUT FORMAT (use these exact headings in this order):

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
1. TITLE BLOCK - topic, class, board, duration, and the line 'Compiled by [YOUR NAME]'.
2. LEARNING OBJECTIVES - bullet list.
3. MATERIALS NEEDED - short list.
4. LESSON TIMELINE - a table with columns: Minutes | Segment | What the teacher does | What students do.
5. WORKED EXAMPLES - each numbered, with question, full steps, final answer, and the two verification checks shown.
6. GUIDED PRACTICE - 3 questions with answers.
7. INDEPENDENT PRACTICE - 4 questions with answers.
8. EXIT CHECK - 2 quick questions with answers.
9. COMMON MISTAKES - 3 errors students make and how to correct them.

RULES: The timeline must total exactly 45 minutes. Every answer must be verified. Use language a Class [CLASS/GRADE] student understands. Do not skip steps in any solution.

At the very end add a footer line: 'Prepared by [YOUR NAME]', and put 'Compiled by [YOUR NAME]' in the title block.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
