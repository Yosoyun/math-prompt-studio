Common-Feedback Template for a Whole Class

One shared feedback note covering the mistakes most of the class made.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Open any free AI chat.
  2. 2. Paste the prompt below.
  3. 3. List the common mistakes you saw.
  4. 4. Send and read the shared note.
  5. 5. Read it aloud or photocopy for the class.
🔧 If it is not right, reply with this: If it sounds preachy, reply: "Make it warmer and more practical - for each mistake, show the wrong way and the right way in one short example."
THE PROMPT
ROLE: Act as a mathematics teacher writing a single 'whole-class feedback' note after marking a test.

CONTEXT: I teach Class [CLASS/GRADE] for [BOARD or EXAM]. Many students made the same mistakes on [TOPIC or TEST]. Instead of writing the same comment 40 times, I want one shared feedback note that addresses the common errors clearly and constructively.

YOUR TASK:
1. Take the list of recurring mistakes I give you.
2. Group them into 3 to 6 themes.
3. For each theme, write: what went wrong, why it happens, and the correct approach - with one tiny worked example showing wrong-versus-right.
4. Open with one genuine line of class-wide praise for something done well.
5. End with 2 to 3 concrete action points for the next assessment.

INPUT: Topic or test: [TOPIC or TEST]. Here are the common mistakes I saw: [PASTE THE LIST OF RECURRING ERRORS]. One thing the class did well: [OPTIONAL].

HOW TO WORK IT OUT: Solve any example you include internally first, then VERIFY each worked example by a second method or re-substitution so the 'right way' is definitely correct. Never invent a mistake I did not mention, and never show a 'correct' solution that is actually wrong. Keep all mathematics legible in clean LaTeX or plain text.

OUTPUT FORMAT, in this exact order:
1. TITLE BLOCK: "Class Feedback - [TOPIC]", class line, and "Compiled by [YOUR NAME]".
2. WHAT YOU DID WELL (1 to 2 lines).
3. THEMES: each theme with What went wrong / Why / The right way / a wrong-vs-right mini example.
4. ACTION POINTS FOR NEXT TIME (numbered, 2 to 3).
5. CLOSING ENCOURAGEMENT (one line).

RULES: Address the class as a group, never name a student. Keep the tone supportive, not scolding. Every worked example must be verified correct. State one assumption in a line if my list is unclear.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
