Kahoot Spreadsheet Quiz Without Truncation

A checked Kahoot XLSX-ready table whose questions and answers stay inside the platform’s strict character limits.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Ask for short, screen-readable questions with one unambiguous answer.
  2. 2. Open each verification link and approve the key.
  3. 3. Paste the rows into the official Kahoot XLSX template without changing the headers.
  4. 4. Import the XLSX, preview truncation and test one player view before class.
🔧 If it is not right, reply with this: If wrong, reply with: "Rewrite every row so each question is at most 95 characters and each answer is at most 60, then recount and reprint the XLSX table."
THE PROMPT
ROLE: Act as a concise maths quiz writer and exact Kahoot spreadsheet-import formatter.

CONTEXT: A teacher wants a lively Kahoot round on [TOPIC] but must avoid silent truncation in the spreadsheet importer.

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [TOPIC]
- [QUESTION COUNT]
- [DIFFICULTY MIX]
- [TIME PER QUESTION]
- [LANGUAGE]

DO THIS:
1. Draft four-option quiz questions that fit a phone and use plain ASCII maths.
2. Verify every computational correct answer with a check-this-yourself link in a separate review table.
3. Output rows matching the Kahoot XLSX columns: Question, Answer 1, Answer 2, Answer 3, Answer 4, Time limit and Correct answer number.
4. Keep every question at 95 characters or fewer and every answer at 60 characters or fewer.
5. Print measured character counts for each question and its longest answer.
6. Explain the manual XLSX import route without claiming URL import.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Make a five-question mental-arithmetic Kahoot for Class 6.
Expected result or check target: For 17*6-25, the checked correct answer is 77 and the row fits both character limits.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=17%2A6-25
(paste-fallback: 17*6-25)
Encoding note: The multiplication asterisk is URL-safe here; the whole query contains no spaces or reserved plus sign.

OUTPUT FORMAT:
1. LINK-VERIFIED ANSWER REVIEW
2. KAHOOT XLSX-READY ROWS
3. 95/60 CHARACTER AUDIT
4. XLSX IMPORT STEPS
5. PHONE PREVIEW CHECK

QUALITY AND TOOL GUARDRAILS:
- Kahoot accepts spreadsheet import through XLSX rows, not a URL or a quiz-bearing link.
- Every question must be no longer than 95 characters and every answer no longer than 60 characters.
- Use the correct-answer number required by the Kahoot template and preserve the same key as the review table.
- Use plain ASCII maths and do not claim that generating a table automatically uploads it.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
