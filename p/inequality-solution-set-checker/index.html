Inequality Solution-Set Checker

A sign-safe inequality solution with interval endpoints, boundary tests, and an independently checkable solution-set link.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the inequality without changing its symbols.
  2. 2. State the variable domain and desired interval notation.
  3. 3. Mark every zero and undefined critical point.
  4. 4. Check one test value in each interval.
  5. 5. Open the independent solver link and compare endpoints.
🔧 If it is not right, reply with this: If wrong, reply with: "Rebuild the sign chart from all zeros and undefined points, then re-test endpoint inclusion one condition at a time."
THE PROMPT
ROLE: Act as an inequality specialist who preserves direction changes, excluded points, and exact set notation.

CONTEXT: The user needs a polynomial, rational, radical, logarithmic, or absolute-value inequality checked for sign errors and domain exclusions.

INPUTS — FILL EVERY PLACEHOLDER:
- [INEQUALITY]
- [VARIABLE DOMAIN]
- [REQUIRED SET NOTATION]

DO THIS:
1. State the natural domain before manipulating the inequality.
2. Move all terms to one side only when that preserves a transparent equivalent condition.
3. Find all zeros and undefined points and order them on a number line.
4. Build a sign chart or equivalent case split with one explicit test value per region.
5. Reverse the inequality whenever multiplying or dividing by a known negative quantity.
6. Check strict versus inclusive endpoints against the original expression.
7. Create an approved Symbolab or WolframAlpha link for the exact inequality.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Solve x^2 - 5x + 6 <= 0 over the reals.
Expected result or check target: The factors change sign at 2 and 3, and equality is allowed, so the solution set is [2, 3].
check this yourself
CHECK → https://www.symbolab.com/solver?query=solve%20x%5E2-5x%2B6%3C%3D0
(paste-fallback: solve x^2-5x+6<=0)
Encoding note: The caret, plus, less-than sign, equals sign, and spaces are percent-encoded; decoding yields the exact fallback.

OUTPUT FORMAT:
1. Domain — allowed values and exclusions
2. Equivalent Form — justified transformation
3. Critical Points — zeros and undefined points
4. Sign Chart or Cases — interval-by-interval evidence
5. Endpoint Audit — included or excluded with reason
6. Independent Check — raw link and exact fallback
7. Final Solution Set — interval, set-builder, or requested notation

QUALITY AND TOOL GUARDRAILS:
- Never cross-multiply by an expression of unknown sign without splitting cases.
- Do not include denominator zeros or other domain exclusions as solutions.
- Use plain calculator syntax and fully encode comparison symbols in the query.
- Label the link check this yourself and print the exact decoded fallback.
- A graph or solver result does not replace the sign and endpoint reasoning.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
