Solve With Three Levels of Explanation

One answer explained three ways: quick, standard, and deep - for mixed-ability classes.

Attach a photo of the question first  ·  Best tool:  ChatGPT or Gemini (image)

✅ How to use this effectively

  1. 1. Photograph the question clearly.
  2. 2. Attach the photo and paste this prompt.
  3. 3. Send and read all three levels.
  4. 4. Pick the level that fits your class.
  5. 5. Ask to expand any single level further.
🔧 If it is not right, reply with this: If a level is too thin, reply: "Expand the [Beginner/Standard/Advanced] level with more steps and one worked sub-example."
THE PROMPT
ROLE: Act as a mathematics teacher who can explain the same solution at three depths for a mixed-ability classroom.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET], topic [TOPIC]. My class has weak, average, and strong students, so I need one question explained at three levels.

YOUR TASK:
1. Read the question in the attached photo and restate it in clean text.
2. Solve it once correctly (internally), then present the SAME correct answer in three explanation levels:
   - Beginner: very simple, every tiny step spelled out, plain words.
   - Standard: a clean exam-style solution with the usual steps.
   - Advanced: concise, with the underlying idea and any shortcut or generalisation.
3. The final answer must be identical across all three levels.

INPUT: I have attached a photo of the problem. If any part is unclear, tell me which symbol or line you cannot read, state your best assumption, and continue.

HOW TO WORK IT OUT: Solve the problem silently first. Then VERIFY the final answer with TWO independent checks (for example substitute back, and re-derive a second way). If the checks disagree, fix the error before writing any level. Never invent formulas or values; name standard results. Keep all mathematics fully legible in clean LaTeX or clear plain text, one step per line, in every level.

OUTPUT FORMAT (use these exact headings):
1. Question as I read it.
2. Level 1 - Beginner - the simplest full explanation.
3. Level 2 - Standard - the exam-style solution.
4. Level 3 - Advanced - concise with the deeper idea or shortcut.
5. Final answer - stated once, the same for all levels.
6. Verification - Check 1 and Check 2, each in one or two lines.

RULES: All three levels must reach the identical final answer; if they differ, you made an error - fix it. Keep each level genuinely distinct in depth, not just reworded. Use plain ASCII only with straight quotes. Be exact unless an estimate is requested.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
At the very end add a footer line: "Prepared by [YOUR NAME]", and put "Compiled by [YOUR NAME]" in the title or header block at the top.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
