Do / Don't Card for a Tricky Topic

A clean two-column Do vs Don't card students can pin up and glance at while practising.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. Type the topic or chapter name.
  2. Set the class and board or exam.
  3. Press Enter to get the card.
  4. Print it or share it digitally.
  5. Ask to add a worked mini-example.
🔧 If it is not right, reply with this: If a 'Don't' is unclear, reply: "Pair each Don't with the matching Do and a one-line example so students see the contrast."
THE PROMPT
ROLE: Act as a study-skills designer making a crisp Do / Don't reference card.

CONTEXT: This is for [CLASS/GRADE] students in [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE]. Topic: [TOPIC]. Students keep making avoidable errors, and I want a glanceable card of what TO do and what NOT to do.

YOUR TASK:
1. Produce a two-column card: 'Do' on the left, 'Don't' on the right, matched row by row.
2. Cover method choices, notation, common shortcuts, and the classic traps in this topic.
3. Add one tiny worked example showing a Do and a Don't side by side.
4. Keep it printable and scannable.

INPUT: Here is the topic and level: [TOPIC], [CLASS/GRADE], [BOARD or EXAM]. Optional focus: [OPTIONAL SUB-TOPIC].

HOW TO WORK IT OUT: Ensure each Don't is paired with the correct Do, so the contrast is clear. For the worked example, solve internally and VERIFY it two independent ways and state them. Choose advice that targets real, common slips at this level. Never invent formulas. Keep maths legible.

OUTPUT FORMAT:
Title block: 'Do and Don't - [TOPIC] ([CLASS/GRADE])'.
A two-column matched table: Do | Don't, with 8 to 12 rows.
Then 'Side-by-Side Example' - one short problem solved the Do way and the Don't way, with the verification of the Do version.
Then 'Golden Rule' - one memorable line.

RULES: Plain ASCII only, straight quotes. Keep each cell short enough to read at a glance. Every Don't must have its matching Do.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return one complete, editable document ready to paste into Word or Google Docs. Use a descriptive title, short section headings, readable paragraphs, numbered actions and tables only where they make the material easier to use. Include every requested section; do not return formatting advice instead of the document.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
