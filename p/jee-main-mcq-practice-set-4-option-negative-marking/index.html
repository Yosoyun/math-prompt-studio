THE PROMPT
ROLE: Act as a JEE Main question paper-setter and answer-key verifier for mathematics.

CONTEXT: My students are preparing for [EXAM e.g. JEE Main] at [CLASS/GRADE e.g. Class 11 / Class 12] level. I need single-correct MCQs that match the real JEE Main pattern (four options A-D, exactly one correct, +4 correct / -1 wrong).

YOUR TASK:
1. Create EXACTLY [NUMBER e.g. 15] single-correct MCQs from the chapter: [CHAPTER e.g. Sequences and Series].
2. Keep difficulty realistic for JEE Main: mostly moderate, a few easy, a few tough - roughly 30% easy, 50% moderate, 20% tough.
3. Make the three wrong options 'distractors' that match real student mistakes (sign errors, off-by-one, formula confusion), not random numbers.
4. Provide a separate answer key and full solutions.

INPUT: Here is the chapter and any sub-topics: [PASTE CHAPTER AND SUB-TOPICS HERE]. If number is blank, use 15. Do not go outside this chapter.

HOW TO WORK IT OUT: Solve each MCQ internally first. Then VERIFY the correct option by two independent methods AND confirm that each of the other three options is genuinely wrong (state the mistake that would lead a student to pick it). Never invent formulas or values. If more than one option could be correct, redesign the question. Keep all maths legible in clean LaTeX or clear plain text.

OUTPUT FORMAT, in this exact order:

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return the complete material as a clean, print-ready A4 handout that can be pasted into Word or Google Docs and saved as PDF. Use a clear title, logical sections, readable mathematics and page-break markers where needed. Keep student material separate from the answer key or teacher notes.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
A. Title block: 'Chapter: [CHAPTER]', 'Exam: JEE Main (single-correct)', 'Marking: +4 / -1', 'Compiled by [YOUR NAME]'.
B. SECTION 1 - QUESTIONS: Q1...Q[NUMBER], each with four options labelled (A)(B)(C)(D).
C. SECTION 2 - ANSWER KEY: a single compact line per question, e.g. '1-(C) 2-(A) ...'.
D. SECTION 3 - SOLUTIONS: for each question, the correct working, the two verification checks, and a one-line note on which wrong option traps students and why.
E. SECTION 4 - DIFFICULTY TAGS: Easy / Moderate / Tough per question.

RULES: Exactly one correct option per question. No duplicate question ideas. Distractors must be believable mistakes. Every answer survives two checks before printing.

At the very end add a footer line: 'Prepared by [YOUR NAME]', and put 'Compiled by [YOUR NAME]' in the title block.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
