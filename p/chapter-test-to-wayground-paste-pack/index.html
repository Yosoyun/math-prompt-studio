Chapter Test to Wayground Paste Pack

A checked chapter-test review copy and a sub-10,000-character Wayground paste-import block ready for a live phone quiz.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Give the exact chapter, class and difficulty mix instead of only a broad subject name.
  2. 2. Review the answer key and open the check links in a browser.
  3. 3. Copy only the labelled Wayground import block.
  4. 4. In Wayground choose Create, Import and Paste questions, then preview every parsed item.

THE PROMPT
ROLE: Act as a chapter-test writer, answer-key auditor and Wayground paste-import formatter.

CONTEXT: A teacher wants a phone-based chapter test for [CLASS] and [CHAPTER] without retyping the questions in Wayground.

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [BOARD OR EXAM]
- [CHAPTER]
- [QUESTION COUNT]
- [DIFFICULTY MIX]
- [TIME LIMIT]
- [LEARNING OUTCOMES]

DO THIS:
1. Build a balanced multiple-choice chapter test aligned only to the supplied outcomes.
2. Write a teacher review copy with options, correct answer, one-line solution and marks.
3. Create an independent check-this-yourself link for each computational answer.
4. Repeat the same questions in a clean Wayground paste block using plain ASCII maths such as x^2 and sqrt(x).
5. Keep the entire paste block under 10,000 characters and report its character count.
6. Give only the manual import path and a preview checklist for answer parsing.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Build a six-question Class 10 chapter test on quadratic equations.
Expected result or check target: The review copy shows x^2-5x+6=(x-2)(x-3) and marks the roots 2 and 3 before the same item appears in the paste block.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=factor%20x%5E2-5x%2B6
(paste-fallback: factor x^2-5x+6)
Encoding note: The space is %20, ^ is %5E and + is %2B.

OUTPUT FORMAT:
1. TEST BLUEPRINT
2. LINK-VERIFIED REVIEW COPY
3. WAYGROUND PASTE BLOCK
4. CHARACTER COUNT
5. IMPORT — Create → Import → Paste questions
6. PREVIEW CHECKLIST

QUALITY AND TOOL GUARDRAILS:
- Wayground receives questions only through Create → Import → Paste questions; never claim URL import or embed the quiz in a Wayground URL.
- The paste block must be under 10,000 characters and use plain ASCII maths because importer handling of LaTeX is unreliable.
- Mark exactly one correct option in every standard MCQ and keep the review-copy key identical to the import block.
- Verification links must use an allowed solver and be labelled check this yourself.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
