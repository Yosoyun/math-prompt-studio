Shift a Function Two Different Ways

An interactive family showing f(x), f(x)+k, and f(x+k) together so students can distinguish vertical and horizontal shifts.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste a base function students already recognise.
  2. 2. Open the link and identify the base, vertical-shift, and horizontal-shift curves by their definitions.
  3. 3. Ask for a direction prediction before changing k.
  4. 4. Drag k through positive, zero, and negative values.
  5. 5. Have students state the transformation rule in words and symbols.
🔧 If it is not right, reply with this: If wrong, reply with: “Keep f(x)+k and f(x+k) separate, correct every raw plus sign to %2B in the URL, and state the direction for positive k.”
THE PROMPT
ROLE: You are a function-transformation demonstrator who makes horizontal and vertical shifts visually unambiguous.

CONTEXT: The class will compare [BASE FUNCTION], [VERTICAL TRANSFORMATION], and [HORIZONTAL TRANSFORMATION] using parameter [PARAMETER].

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [BOARD OR EXAM]
- [BASE FUNCTION]
- [PARAMETER]
- [STARTING VALUE]
- [VERTICAL TRANSFORMATION]
- [HORIZONTAL TRANSFORMATION]

DO THIS:
1. Restate the three function definitions and predict their movement for positive and negative parameter values.
2. Build one slider assignment and define the base curve before both transformed curves.
3. Choose a starting value that makes both shifts clearly visible.
4. Build a /graphing?command= link with no more than 12 commands.
5. Give the same definitions as manually typed Desmos lines, never as a Desmos URL.
6. Create two quick checks that expose the common sign error in f(x+k).

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Compare f(x)=x^2, f(x)+2, and f(x+2).
Expected result or check target: The base parabola, a copy shifted up 2, and a copy shifted left 2 open together.
check this yourself
CHECK → https://www.geogebra.org/graphing?command=f(x)=x^2;k=2;g(x)=f(x)%2Bk;h(x)=f(x%2Bk)
(paste-fallback: f(x)=x^2;k=2;g(x)=f(x)+k;h(x)=f(x+k))
Encoding note: Both addition signs are encoded as %2B; parentheses, equals signs, carets, and semicolons remain literal exactly as GeoGebra requires.

OUTPUT FORMAT:
1. TRANSFORMATION MAP — formula, direction, and invariant features
2. WHAT THE CLASS WILL SEE — expected positions at the starting value
3. ONE-CLICK GEOGEBRA LINK — labelled check this yourself
4. DESMOS TYPED-LINES FALLBACK — slider and three curves
5. PREDICT-DRAG-EXPLAIN ROUTINE — teacher script
6. MISCONCEPTION CHECK — two oral questions

QUALITY AND TOOL GUARDRAILS:
- Use only https://www.geogebra.org/graphing?command= and no geogebra.org/m/ links.
- Use at most 12 commands; every + inside the command payload must be %2B, while ()=^; stay literal.
- Never output any Desmos URL; provide only typed expressions and slider values.
- Never use mathsolver.microsoft.com or reverse the direction of the horizontal transformation.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.

6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
