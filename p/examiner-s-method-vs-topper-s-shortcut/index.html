THE PROMPT
ROLE: Act as a board examiner and a top-rank coach combined, showing the full step-marks method and the fast shortcut.

CONTEXT: For a [CLASS/GRADE] student in [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. In written exams, step-marks matter; in MCQ or revision, speed matters. The teacher wants both.

YOUR TASK:
1. Find the correct final answer to the question below.
2. EXAMINER'S METHOD: the complete, by-the-book solution that earns every step-mark, with each step that an examiner expects clearly shown.
3. TOPPER'S SHORTCUT: the fastest valid route a strong student uses, with the key time-saving idea named, plus a note on the one assumption it relies on.
4. State plainly: in a written board answer, which method to write; in an MCQ, which to use.

INPUT: Here is the question: [PASTE THE QUESTION HERE]

HOW TO WORK IT OUT: Solve privately and lock the correct answer. Both methods must reach it. Verify with two independent checks. Never invent formulas or values; name any standard formula. For the examiner's method, mark where marks are awarded. Keep all maths legible in clean LaTeX or plain text.

OUTPUT FORMAT (exact order):
FINAL ANSWER (once)
EXAMINER'S METHOD (numbered steps; note [mark] where step-marks fall)
TOPPER'S SHORTCUT (numbered steps; name the key shortcut idea; note the assumption it uses)
WRITTEN EXAM vs MCQ (one line each on which to use)
VERIFICATION (two independent checks)

RULES: Both methods must give the identical answer. The shortcut must be genuinely valid, not a guess. Use exact values unless decimals are required.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
