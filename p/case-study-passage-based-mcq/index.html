Case-Study / Passage-Based MCQ

A real-life case-study passage followed by linked MCQs in the new board pattern, with a verified key.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Fill class, board and chapter.
  2. 2. Suggest a real-life context (optional).
  3. 3. Choose how many sub-questions.
  4. 4. Send the prompt.
  5. 5. Verify the numbers in the passage match the key.
🔧 If it is not right, reply with this: If the data in the passage does not give a clean answer, reply: 'Adjust the numbers in the passage so every sub-question has a clean correct option, then re-verify all answers.'
THE PROMPT
ROLE: Act as a CBSE-style mathematics paper setter who writes case-study (passage-based) MCQs.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board]. The chapter is [CHAPTER NAME]. I want one case-study with [NUMBER, e.g. 5] linked single-correct MCQs.

YOUR TASK:
1. Write a short real-life scenario (4 to 6 sentences) that naturally uses the maths of the named chapter - for example a shopkeeper, a cricket score, a water tank, travel, or a building. Include all the numbers/data needed.
2. Then write [NUMBER] MCQs that all draw on that same passage, increasing in difficulty.
3. Each MCQ has four options A to D with exactly one correct answer and three smart distractors based on likely errors.

INPUT: Here is a real-life context I want (optional): [PASTE CONTEXT IDEA OR LEAVE BLANK and you choose].

HOW TO WORK IT OUT: Solve every sub-question using only the data in the passage. VERIFY each answer twice and confirm the passage actually contains enough information for a clean answer; if not, adjust the passage numbers. Do not invent extra data mid-question. Keep all maths legible.

OUTPUT FORMAT:
CASE STUDY: the passage, with a small data summary line.
QUESTIONS: Q1 to Q[NUMBER], each with options A to D.
ANSWER KEY: table with Q No | Correct option | Worked one-line reason | Mistake behind each distractor.

RULES: All sub-questions must be solvable from the passage alone. Numbers must be realistic and clean. Difficulty suited to the class above.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return the complete material as a clean, print-ready A4 handout that can be pasted into Word or Google Docs and saved as PDF. Use a clear title, logical sections, readable mathematics and page-break markers where needed. Keep student material separate from the answer key or teacher notes.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
At the very end add a footer line: 'Prepared by [YOUR NAME]', and put 'Compiled by [YOUR NAME]' in the title block at the top.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
