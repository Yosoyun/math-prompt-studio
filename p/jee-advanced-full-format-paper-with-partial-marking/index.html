JEE Advanced Full-Format Paper With Partial Marking

A JEE Advanced-style paper spanning all five question formats (single correct, multiple correct, integer, matrix-match, paragraph) with the exact partial-marking rules, full solutions, and a concept-fusion map.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Replace [CHAPTERS] with the chapters you want covered (e.g. 'Definite Integration, Conics, Complex Numbers').
  2. 2. Replace [NUM_QUESTIONS] with the total questions you want (e.g. 18).
  3. 3. Paste the prompt and let it generate the paper, key, and solutions.
  4. 4. Check the multiple-correct items yourself — verify every option marked true really is true.

THE PROMPT
ROLE: You are a JEE Advanced Mathematics paper-setter and reviewer in the IIT mould — you prize multi-concept linkage, no plug-and-chug, and the kind of multiple-correct items where partial marks separate the top 500 from the top 5000.

CONTEXT: Build a JEE Advanced-style Maths paper across the full spectrum of Advanced question formats.

DO THIS — use the authentic Advanced format library:
1. Section A — Single correct (+3 / -1).
2. Section B — Multiple correct, one or more of four options right. Marking: +4 all-correct, with partial credit (+3/+2/+1) for choosing only correct options per the current IIT scheme, -2 if any wrong option is chosen, 0 if blank. State the exact partial rule above the section, with a note that the student should verify against the current year's official brochure.
3. Section C — Integer / non-negative numerical answer (+4 / 0, no negative).
4. Section D — Matrix-match or List-I/List-II matching (+3 per correct full match per item).
5. Section E — One comprehension/paragraph with 2 linked questions.
6. Distribute [NUM_QUESTIONS] questions across these sections, drawing from [CHAPTERS]; favour problems that fuse two chapters (e.g. conics with calculus, complex numbers with vectors, probability with sequences).
7. Each item must demand a genuine idea, not memorised formula substitution. Multiple-correct items must have a non-trivial number of true options (vary it — not always exactly two).

OUTPUT FORMAT: Marking rules box → PAPER (clean mathematical notation) → ANSWER KEY → STEP-BY-STEP SOLUTIONS (for multiple-correct items, justify why each option is true or false) → CONCEPT-FUSION MAP (which chapters each question combines) → a short 'where students bleed partial marks' note.

QUALITY BAR: No item solvable by option-elimination alone. Every multiple-correct option independently justified. Show the partial-marks arithmetic for a plausible partly-right student so they understand the risk mathematics.

GROUND RULES: Do not invent statistics, cut-offs, or citations. If unsure of a marking-scheme detail, say so and label it as needing verification against the official brochure. Work only from what I provide or well-established facts.
