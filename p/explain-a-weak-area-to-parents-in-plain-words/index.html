Explain a Weak Area to Parents in Plain Words

A jargon-free explanation of where the child struggles and how to help.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Open any free AI chat.
  2. 2. Paste the prompt; name the weak topic.
  3. 3. Add what you have already tried.
  4. 4. Read the plain-English version.
  5. 5. Send or use it in a call.
🔧 If it is not right, reply with this: If it gets technical, reply: "Explain it as if to a parent who never liked maths. No symbols, use one everyday example."
THE PROMPT
ROLE: Act as a patient maths teacher who can explain a child's weak area to a non-maths parent in everyday language.

CONTEXT: My student [STUDENT NAME], in [CLASS/GRADE], studying [SUBJECT] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET], is struggling with a specific topic. The parent wants to understand WHAT the problem is and HOW to help, but does not know maths terminology.

YOUR TASK:
1. Explain the weak area in plain, friendly words a non-maths parent will understand.
2. Use ONE simple everyday analogy (shopping, cooking, distance, money) to make it click.
3. Say clearly why this topic matters for later chapters or the exam.
4. Give 2 to 3 easy, no-cost ways the parent can support practice at home.
5. Reassure that this is fixable with steady practice.

INPUT - the real situation (use only these facts):
- The weak topic: [e.g. fractions / negative numbers / word problems / algebra basics]
- How it shows up: [e.g. wrong signs / does not know where to start / forgets steps]
- What I have already tried: [DETAILS, optional]
- Tone: [warm and simple]

HOW TO WORK IT OUT: Use only the facts above; never invent test scores or causes. Avoid all maths jargon and symbols in the parent-facing text; if a term is unavoidable, define it in plain words. Keep the analogy accurate. Re-read and remove anything a non-maths parent could not follow.

OUTPUT FORMAT (use these exact headings):
WHAT IS HAPPENING (in simple words): 2 to 3 sentences.
A SIMPLE EXAMPLE: one everyday analogy.
WHY IT MATTERS: 1 to 2 sentences.
HOW YOU CAN HELP AT HOME: 2 to 3 easy steps.
REASSURANCE: 1 encouraging line.

RULES:
- Zero jargon; nothing that needs maths knowledge to follow.
- Honest, calm, and solution-focused.
- Plain, clean text only.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return one complete, editable document ready to paste into Word or Google Docs. Use a descriptive title, short section headings, readable paragraphs, numbered actions and tables only where they make the material easier to use. Include every requested section; do not return formatting advice instead of the document.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
