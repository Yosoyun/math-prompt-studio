Morning Warm-Up: 5 Quick Questions

A tiny 5-question wake-up sheet to start class or the day with confidence.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Pick today's topic and class.
  2. 2. Paste the prompt and send.
  3. 3. Read the 5 questions aloud.
  4. 4. Give the quick answers after.
  5. 5. Re-run tomorrow for a new set.
🔧 If it is not right, reply with this: If a question is too long for a warm-up, reply: "Replace question [number] with something a student can do in under one minute."
THE PROMPT
ROLE: Act as a mathematics teacher who opens every class with a short confidence-building warm-up.

CONTEXT: I want a quick MORNING WARM-UP of 5 short questions to start the day or lesson for [CLASS/GRADE] students of [BOARD or EXAM e.g. CBSE / ICSE / State Board]. Topic = [TOPIC or 'mixed easy revision']. Total time = about 5 minutes.

YOUR TASK:
1. Create exactly 5 short, mostly mental or one-line questions that a student can finish in about a minute each.
2. Keep them encouraging: easy enough to build momentum, with maybe one slightly thoughtful one at the end.
3. Provide instant one-line answers and a single 'thought for the day' style maths fact.

INPUT: Topic = [TOPIC]. Class = [CLASS/GRADE]. Board/Exam = [BOARD or EXAM]. If unclear, assume and state it.

HOW TO WORK IT OUT: Solve each question yourself first and confirm it is truly quick. Verify each final answer by two independent checks. Avoid heavy calculation. Never invent formulas or values. Keep all maths legible in clean LaTeX or clear plain text.

OUTPUT FORMAT, in this exact order:
1. TITLE LINE: 'Morning Warm-Up - [TOPIC]' with class and 'Compiled by [YOUR NAME]'.
2. QUESTIONS: 5 short numbered questions, printable.
3. QUICK ANSWERS: the 5 final answers in one tidy list.
4. MATHS SPARK: one short, interesting one-line maths fact tied to the topic to spark curiosity.

RULES: Keep it short and uplifting. Nothing here should take more than a minute. No multi-page problems.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
