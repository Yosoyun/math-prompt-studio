Textbook Photo to Phone Quiz

A faithful transcription audit, checked phone quiz, complete Google Forms script and Wayground paste block made from an attached textbook page.

Attach a photo of the question first  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Attach a sharp, straight photo with every symbol, option and diagram label visible.
  2. 2. Compare the transcription with the page and correct it before using any generated item.
  3. 3. Open the answer-check links and review adaptations that differ from the source exercises.
  4. 4. Run the Forms script or paste the separate block through Wayground’s import path, then preview on a phone.
🔧 If it is not right, reply with this: If wrong, reply with: "Stop, retranscribe the attached page symbol-for-symbol, mark every unreadable fragment as unclear and rebuild nothing until I confirm the transcription."
THE PROMPT
ROLE: Act as a meticulous textbook transcriber, maths quiz adapter and cross-platform phone-assessment developer.

CONTEXT: A teacher has attached a photo of one [TEXTBOOK PAGE] and wants a quiz for [CLASS] without changing the mathematical meaning.

INPUTS — FILL EVERY PLACEHOLDER:
- [TEXTBOOK PAGE]
- [CLASS]
- [BOARD OR COURSE]
- [QUESTION COUNT]
- [DIFFICULTY MIX]
- [MARKS PER QUESTION]
- [LANGUAGE]

DO THIS:
1. First transcribe every relevant heading, question, option, symbol, unit and diagram label from the attached image.
2. Flag blurred or cropped content as unclear instead of guessing, and stop for confirmation if any unclear detail affects an answer.
3. After a reliable transcription, adapt the material into original quiz items while distinguishing copied source items from new variants.
4. Give a review key with short solutions and check-this-yourself links for each computational result.
5. Generate one complete executable FormApp script with quiz mode, correct choices, points and logged URLs.
6. Also provide a plain-ASCII Wayground paste block under 10,000 characters with the same key.
7. Finish with a source-to-quiz trace table so the teacher can spot transcription drift.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Turn a photographed Class 7 page containing 2x+7=19 into a four-question quiz.
Expected result or check target: The transcription preserves 2x+7=19 exactly, and the verified solution used in the key is x=6.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=solve%202x%2B7%3D19
(paste-fallback: solve 2x+7=19)
Encoding note: The space is %20, + is %2B and = is %3D.

OUTPUT FORMAT:
1. PHOTO TRANSCRIPTION AND UNCLEAR AREAS
2. SOURCE-TO-QUIZ TRACE TABLE
3. LINK-VERIFIED REVIEW COPY
4. COMPLETE GOOGLE APPS SCRIPT
5. RUN IT — script.google.com → New project → paste → Run → View → Logs
6. WAYGROUND PASTE BLOCK UNDER 10,000 CHARACTERS
7. IMPORT — Create → Import → Paste questions

QUALITY AND TOOL GUARDRAILS:
- Never guess an obscured symbol, exponent, sign, unit, option or diagram label from the photo.
- Output one COMPLETE executable FormApp code block and print exactly: script.google.com → New project → paste → Run → View → Logs.
- Wayground is paste-import only through Create → Import → Paste questions; keep its block below 10,000 characters and do not claim URL import.
- Never claim a URL creates a Google Form; the script is the creation route.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
