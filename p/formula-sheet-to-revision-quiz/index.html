Formula Sheet to Revision Quiz

A formula-coverage audit, checked revision quiz and Wayground paste block derived only from the formula sheet you provide.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the complete formula sheet and identify any formulas students may derive rather than memorise.
  2. 2. Check the formula-to-question coverage table for omissions and over-testing.
  3. 3. Open the solver links and approve the review-copy key.
  4. 4. Paste the final block using Wayground’s Create, Import and Paste questions path, then preview every item.
🔧 If it is not right, reply with this: If wrong, reply with: "Use only formulas present in my sheet, restore any omitted formula and rebuild the Wayground block below 10,000 characters."
THE PROMPT
ROLE: Act as a formula-sheet auditor, retrieval-practice writer and Wayground paste formatter.

CONTEXT: A teacher has pasted [FORMULA SHEET] for [CHAPTER] and wants a phone revision quiz that tests meaning, selection and use.

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [BOARD OR EXAM]
- [CHAPTER]
- [FORMULA SHEET]
- [QUESTION COUNT]
- [DIFFICULTY MIX]

DO THIS:
1. Extract and list every formula exactly as supplied before writing questions.
2. Map each formula to recall, when-to-use and one application item as appropriate.
3. Do not introduce a formula absent from the sheet unless it is clearly labelled as a teacher-review suggestion.
4. Give a review copy with answers, brief solutions and check-this-yourself links for computational items.
5. Create a plain-ASCII Wayground paste block under 10,000 characters with clearly marked correct choices.
6. Print the block’s character count and the manual import path.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Turn a formula sheet containing sin(x)^2+cos(x)^2=1 into a revision item.
Expected result or check target: The review key simplifies sin(x)^2+cos(x)^2 to 1 and tests when the identity is useful.
check this yourself
CHECK → https://www.symbolab.com/solver?query=simplify%20sin%28x%29%5E2%2Bcos%28x%29%5E2
(paste-fallback: simplify sin(x)^2+cos(x)^2)
Encoding note: The space is %20, parentheses are %28 and %29, ^ is %5E and + is %2B.

OUTPUT FORMAT:
1. FORMULA INVENTORY
2. FORMULA-TO-QUESTION COVERAGE
3. LINK-VERIFIED REVIEW COPY
4. WAYGROUND PASTE BLOCK
5. CHARACTER COUNT
6. IMPORT — Create → Import → Paste questions

QUALITY AND TOOL GUARDRAILS:
- Wayground is paste-import only through Create → Import → Paste questions; never claim URL import.
- Keep the complete paste block below 10,000 characters and use plain ASCII maths.
- Do not invent content that is not in the pasted formula sheet or silently alter a supplied formula.
- Verification links must use allowed domains and be labelled check this yourself.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
