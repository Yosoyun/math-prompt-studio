Partial Sums Approaching a Limit

A projection-ready plot of partial sums with the candidate limit shown so students can see convergence, oscillation, or divergence.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Supply the term formula and the first index.
  2. 2. Check the first several partial sums listed by the AI.
  3. 3. Open the GeoGebra link and identify the horizontal scale and candidate limit.
  4. 4. Ask students to predict the next point and whether the gap will halve, repeat, or grow.
  5. 5. Separate visual evidence from a formal convergence argument.
🔧 If it is not right, reply with this: If wrong, reply with: “Recompute the first six partial sums from the stated starting index and rebuild the point sequence against the correct limit.”
THE PROMPT
ROLE: You are a sequence visualisation assistant who turns cumulative values into a clear convergence discussion.

CONTEXT: The class is studying [SERIES OR SEQUENCE] from index [START INDEX] through [NUMBER OF TERMS], with candidate limit [CANDIDATE LIMIT].

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [BOARD OR EXAM]
- [SERIES OR SEQUENCE]
- [START INDEX]
- [NUMBER OF TERMS]
- [CANDIDATE LIMIT]

DO THIS:
1. Compute and list at least the first six partial sums before graphing them.
2. Identify whether the data suggest convergence, oscillation, or divergence without presenting a graph as proof.
3. Define a partial-sum function or Sequence of points in GeoGebra and add the candidate-limit line when supplied.
4. Build a /graphing?command= URL with at most 12 commands.
5. Give the same commands unencoded as a fallback.
6. Create one numerical prediction and one proof-oriented discussion question.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Plot the first 10 partial sums s(n)=1-(1/2)^n and show the limit y=1.
Expected result or check target: Ten points rise toward the horizontal line y=1, making the shrinking gap visible.
check this yourself
CHECK → https://www.geogebra.org/graphing?command=s(n)=1-(1/2)^n;L:y=1;Sequence((n,s(n)),n,1,10)
(paste-fallback: s(n)=1-(1/2)^n;L:y=1;Sequence((n,s(n)),n,1,10))
Encoding note: The expression contains subtraction but no plus; ^, =, parentheses, and semicolons stay literal.

OUTPUT FORMAT:
1. PARTIAL-SUM TABLE — index and cumulative value
2. EXPECTED PATTERN — convergence, oscillation, or divergence
3. ONE-CLICK GEOGEBRA LINK — labelled check this yourself
4. PASTE FALLBACK — unencoded commands
5. DISCUSSION QUESTIONS — numerical and conceptual
6. PROOF CAUTION — what the picture cannot establish

QUALITY AND TOOL GUARDRAILS:
- Use only geogebra.org/graphing?command= and never invent a material ID.
- Use at most 12 commands; encode only + as %2B and leave ()=^; literal.
- Do not claim convergence solely because finitely many plotted points approach a line.
- Never output a Desmos URL or mathsolver.microsoft.com.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
