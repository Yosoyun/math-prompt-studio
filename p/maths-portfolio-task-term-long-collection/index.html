Maths Portfolio Task (Term-Long Collection)

A portfolio brief listing required pieces, a reflection prompt and a grading guide.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Fill in term length, class and topics.
  2. 2. Paste the prompt into any AI chat.
  3. 3. Read the list of required pieces.
  4. 4. Share the checklist and reflection prompt.
  5. 5. Grade with the portfolio rubric.
🔧 If it is not right, reply with this: If there are too many required pieces, reply: "Reduce to [number] pieces that fit one term, keep the reflection, and rebalance the rubric to 25 marks."
THE PROMPT
ROLE: Act as a maths teacher who sets a term-long portfolio that shows each student's growth and best work.

CONTEXT: I teach [CLASS/GRADE] under [BOARD e.g. CBSE / ICSE / State Board]. I want a MATHS PORTFOLIO TASK over [TERM LENGTH e.g. one term] covering the topics [TOPICS e.g. algebra, geometry, data]. The portfolio should be a collection of pieces plus a reflection, not a single test.

YOUR TASK:
1. Define what a finished portfolio must contain (a clear list of required pieces, e.g. a corrected hard problem, a real-life application, an investigation, a self-made question).
2. For each required piece, say exactly what good work looks like.
3. Provide a reflection prompt students answer about their learning.
4. Give a clear submission and presentation guideline.
5. Provide a portfolio rubric (25 marks).
6. Add 2 ideas to help weaker students complete it.

INPUT: Here is my term length and topics: [PASTE TERM AND TOPICS HERE]. If blank, assume one term and choose suitable topics for the class and board above.

HOW TO WORK IT OUT: Plan internally. Ensure each required piece is achievable in the term and clearly described. If you include any sample maths, VERIFY it two ways and show the check. Confirm the rubric totals exactly 25 by listing each criterion's marks and the total. Never invent formulas. Keep all maths legible in clean plain text or simple LaTeX.

OUTPUT FORMAT (use these exact headings in this order):
1. PORTFOLIO TITLE AND PURPOSE
2. REQUIRED PIECES (numbered; each with 'what good work looks like')
3. REFLECTION PROMPT (for students)
4. SUBMISSION AND PRESENTATION GUIDELINES
5. RUBRIC (25 marks; criteria + marks + Total)
6. SUPPORT FOR WEAKER STUDENTS (2 ideas)
7. TEACHER TIPS

RULES: Make expectations concrete so students know exactly what to produce. Short, plain sentences.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
