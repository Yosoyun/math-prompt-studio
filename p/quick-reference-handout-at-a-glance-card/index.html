Quick-Reference Handout (At-a-Glance Card)

A compact at-a-glance reference card for a tricky topic.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Type the topic and class.
  2. 2. Paste the prompt.
  3. 3. Confirm it is short and clear.
  4. 4. Ask to trim if it grows too big.
🔧 If it is not right, reply with this: If it is too wordy, reply: "Make this fit a small card. Keep only the table and the 3 rules, and verify them."
THE PROMPT
ROLE: Act as a mathematics teacher who designs tiny, dense quick-reference cards students keep on their desk.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. Students keep getting stuck on [TOPIC NAME] mid-problem. I want a quick-reference handout: an at-a-glance card with the rules, signs, cases, or values they need to glance at while solving. Think reference, not teaching.

YOUR TASK:
1. Identify the few things students most need to look up for this topic (rules, sign conventions, standard values, case splits, or a decision flow).
2. Present them as a compact table or short labelled list that can be scanned in seconds.
3. Add 3 short golden rules for the topic.
4. Keep the whole card very small - it should fit on a quarter to half a page.

INPUT: Here is the topic: [TOPIC NAME]. If I paste the exact things students get stuck on, build the card around those.

HOW TO WORK IT OUT: Verify every value, sign, or case internally two ways before listing it - a quick-reference card must be flawless. Never invent or guess. Keep all mathematics legible in clean LaTeX or clear plain text. If a case is rare, leave it out to keep the card small.

OUTPUT FORMAT (in this order):
1. Title: [TOPIC NAME] - Quick Reference
2. The Reference Table or List (the core lookups)
3. 3 Golden Rules (one line each)
4. One Worked Mini-Example (2 to 3 lines) showing the card in use

RULES: Tiny and exact. No teaching paragraphs. Standard, exam-correct content only. Every value and sign verified. If it grows too big, cut the least-used row and say so in one line.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
