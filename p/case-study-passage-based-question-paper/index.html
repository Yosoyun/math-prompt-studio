Case-Study / Passage-Based Question Paper

A paper of case-study passages, each followed by linked sub-questions, with a full key.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Paste the prompt into a chat.
  2. 2. Set the number of case studies.
  3. 3. List the chapters to cover.
  4. 4. Send and read each passage.
  5. 5. Check the key answers every sub-question.
  6. For a trustworthy answer key: paste the finished paper into a FRESH chat and ask it to solve and grade it as an unseen exam (it catches its own slips).
🔧 If it is not right, reply with this: If a passage lacks the data needed, reply: 'Case study [number] does not give enough information to answer all its sub-questions. Add the missing data into the passage, then re-verify the key.'
THE PROMPT
ROLE: Act as a mathematics paper-setter who writes engaging case-study (passage-based) questions.

CONTEXT: I need a CASE-STUDY paper for Class [CLASS/GRADE], [BOARD or EXAM e.g. CBSE / ICSE / State Board]. It must contain [NUMBER e.g. 4] case studies, each a short real-life passage followed by [SUB-QUESTIONS e.g. 3 to 4] linked sub-questions. Total marks [TOTAL MARKS], time [TIME].

YOUR TASK:
1. Write [NUMBER] original passages set in relatable contexts (shopping, travel, farming, sports, construction, etc.).
2. Follow each passage with sub-questions of rising difficulty that all use the passage data.
3. Show marks beside every sub-question.
4. Provide a complete answer key for every sub-question.

INPUT: Chapters or topics to cover: [LIST CHAPTERS or TOPICS]. Use only these.

HOW TO WORK IT OUT: Solve every sub-question internally first. Confirm each passage gives all the data its sub-questions need, with no contradictions. Verify each final answer twice. Never invent formulas or values. Keep mathematics legible in clean LaTeX or plain text. Confirm marks total exactly [TOTAL MARKS].

OUTPUT FORMAT, in this order:
1. HEADER BLOCK: 'Case-Study Paper - Mathematics', class, board, time, maximum marks, 'Compiled by [YOUR NAME]'.
2. INSTRUCTIONS: numbered, noting that each set is based on its own passage.
3. THE CASE STUDIES: 'Case Study 1' passage, then its numbered sub-questions with marks; repeat for each.
4. ANSWER KEY: organised by case study, final answer and a short reasoning line per sub-question.

RULES: Passages must be self-sufficient. Original contexts only. Stay inside the listed syllabus. Number every sub-question. Marks total exactly.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
