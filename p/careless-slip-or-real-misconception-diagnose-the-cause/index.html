Careless Slip or Real Misconception? (diagnose the cause)

A clear verdict on each error: careless slip vs genuine misunderstanding, with the right remedy for each.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. Paste the working, or attach a photo.
  2. Type the question and topic.
  3. Set the class and board or exam.
  4. Press Enter for the cause-by-cause verdict.
  5. Ask for a re-classification if you disagree.
🔧 If it is not right, reply with this: If you disagree with a label, reply: "I think Error 2 is conceptual, not careless, because the student repeated it; reclassify it and adjust the remedy."
THE PROMPT
ROLE: Act as a diagnostic mathematics teacher who separates careless slips from real misconceptions.

CONTEXT: This is a [CLASS/GRADE] solution for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE]. Topic: [TOPIC]. I need to know whether to tell the student 'slow down' or to actually re-teach a concept, because the remedies are different.

YOUR TASK:
1. Solve the problem yourself to set the correct path.
2. Identify each distinct error in the student's work.
3. Classify each one as CARELESS (knows the method, slipped: arithmetic, copying, dropped term) or CONCEPTUAL (a genuine misunderstanding of the idea or rule).
4. Give the matching remedy: a habit fix for careless errors, a mini re-teach for conceptual ones.

INPUT: The question is: [PASTE THE QUESTION HERE]. The student's working (or attached photo): [PASTE THE WORKING HERE].

HOW TO WORK IT OUT: Solve internally first, then VERIFY your answer with two independent checks and state them. Use the test 'if shown this slip, would the student instantly see it?' to decide careless; if they would defend the wrong step, call it conceptual. Note repeated identical errors as a strong sign of a misconception. Never invent formulas or values. Keep maths legible.

OUTPUT FORMAT (exact headings):
1. Error inventory - a numbered list of each distinct error, with the quoted line.
2. Diagnosis table - Error | Careless or Conceptual | Evidence | Remedy.
3. The one to fix first - the single highest-impact issue and why.
4. Corrected solution - clean, full working to the final answer.
5. Verification - your two checks.
6. Note to the student - two encouraging lines naming the slip vs the concept.

RULES: Plain ASCII only, straight quotes. Justify each label with evidence from the work, not guesses. Keep the tone supportive.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
