Surprise Mixed Mock (No Topic Hints)

A jumbled cumulative mock with no topic labels, to test true readiness.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. List every chapter taught so far.
  2. 2. Set total marks and time.
  3. 3. Send the prompt.
  4. 4. Keep the hidden topic key for yourself.
  5. For a trustworthy answer key: paste the finished paper into a FRESH chat and ask it to solve and grade it as an unseen exam (it catches its own slips).
🔧 If it is not right, reply with this: If questions are grouped by topic, reply: "Shuffle the question order so consecutive questions come from different chapters, and keep topics hidden from students."
THE PROMPT
ROLE: Act as a paper-setter who designs surprise cumulative tests that mimic the real exam's unpredictability.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / JEE / NEET]. In the real exam, questions jump between topics with no warning. I want a surprise mock that mixes all chapters covered so far, with NO topic labels on the question paper, so students must recognise the method themselves.

YOUR TASK:
1. Build a cumulative mock from ALL these chapters: [LIST CHAPTERS COVERED SO FAR]. Total marks: [TOTAL MARKS]. Time: [TIME].
2. SHUFFLE the questions so consecutive questions come from different chapters - no topic clustering, no labels on the student's paper.
3. Keep a HIDDEN topic key (for me only) showing which chapter each question is from.
4. Provide full solutions and an answer key.

INPUT: Here are the chapters covered and marks: [PASTE DETAILS HERE].

HOW TO WORK IT OUT: Solve everything internally first. VERIFY each answer two independent ways. Never invent formulas or values. Confirm the order is genuinely shuffled across topics. Keep all maths legible in clean plain text or LaTeX.

OUTPUT FORMAT (exact order):
STUDENT PAPER: header, then numbered questions with NO topic labels, in shuffled order.
--- TEACHER ONLY ---
HIDDEN TOPIC KEY: Q. No. | Chapter it is from.
SOLUTIONS: full steps.
ANSWER KEY: compact list.
VERIFICATION NOTE: confirm answers checked and order shuffled.

RULES: No topic labels on the student paper. Consecutive questions must differ in chapter. Marks total [TOTAL MARKS]. Original questions. Difficulty true to [BOARD or EXAM].

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.

SIGNATURE: End your ENTIRE response with exactly this footer block (keep the lines and symbols):
