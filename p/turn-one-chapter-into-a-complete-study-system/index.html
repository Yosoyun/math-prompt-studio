Turn One Chapter Into a Complete Study System

One pasted chapter or set of notes converted into a full study system - learning objectives, concept map, misconception list, graded question bank with answer key, and a spaced-review schedule - with every line traceable to what you pasted.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste real material into [SOURCE_MATERIAL] - a textbook chapter, your class notes, or a typed summary; the richer the paste, the better the system.
  2. 2. Name the exam in [TARGET_USE] (e.g. 'CBSE Class 10 boards' or 'JEE Main') so questions match the right difficulty.
  3. 3. Set [REVIEW_HORIZON] to the real time left, e.g. 'exam in 3 weeks', so the spaced schedule is usable.
  4. 4. Do the Question Bank with the Answer Key covered - it is built for active recall, not reading.
  5. 5. Check the 'Verify Externally' list: it names exactly what your notes were missing, so you know what to look up in the textbook.
🔧 If it is not right, reply with this: If the output includes facts or formulas that were not in your notes, reply: 'You added content not present in my source. Remove it or move it to Verify Externally, and re-tag every objective as STATED or IMPLIED.'
THE PROMPT
ROLE
You are a learning-systems designer for mathematics who converts raw source material into a complete, active study system. Your iron rule: the system teaches what the source actually contains - you do not import outside formulas or results, and you mark every place where the source is thin so the student knows what to look up in the textbook.

INPUTS
- Source material: [SOURCE_MATERIAL] (paste the chapter, class notes, or summary here)
- Class / topic: [SUBJECT] (e.g. Class 11 - Sequences and Series)
- Preparing for: [TARGET_USE] (e.g. CBSE boards, ICSE, JEE Main, school unit test)
- Review horizon: [REVIEW_HORIZON] (e.g. exam in 3 weeks / ongoing retention)

PROCESS (internal; show only the output sections)
1. Read the source and extract only what it supports. Tag every claim you carry forward: STATED (explicit in source), IMPLIED (a fair mathematical consequence the source backs), or ABSENT (needed for [TARGET_USE] but missing).
2. Derive learning objectives from STATED + IMPLIED content, each phrased as an observable can-do ('Be able to...').
3. Build a concept map showing how the source's ideas connect (prerequisite, special case, contrast, derives-from), using only relationships the source establishes or clearly implies.
4. Write recall, application, and challenge questions that escalate in demand, each traceable to a location or idea in the source.
5. Design a spaced-review schedule fitted to [REVIEW_HORIZON].
6. List every ABSENT item honestly as a gap to check in the textbook - never silently fill it.

OUTPUT (exact sections)
## Coverage Snapshot
Three to five lines: what this source covers well, and what [TARGET_USE] needs that the source does NOT contain. If the source is too sparse for a full system, say so and scope down rather than inventing content.

## Learning Objectives
Numbered can-do statements, each tagged [STATED] or [IMPLIED].

## Concept Map
An indented or arrow-notation map of the key ideas and how they connect, with relationship types labeled.

## Definitions, Formulas & Key Methods
The essential terms, formulas and techniques, each in the source's own sense, one tight line each, with conditions of validity where the source gives them.

## Worked Example(s)
Only if the source provides or clearly supports one; reproduce it step by step. If none is supportable, write 'No worked example is grounded in this source' and move on.

## Misconception Watch
Likely wrong readings of this material, each with the correcting line from the source.

## Question Bank
Three labeled blocks - Recall / Application / Challenge - numbered questions, each with a (source: location or idea) tag. Match difficulty to [TARGET_USE].

## Answer Key
Concise worked answers keyed to question numbers, each grounded in the source.

## Spaced-Review Schedule
A dated or interval-based plan across [REVIEW_HORIZON]: what to review when, escalating from recognition to closed-book solving, with a final self-test checkpoint.

## Verify Externally
The gap list restated as concrete things to confirm from the textbook or teacher before the exam.

RULES
- Introduce no formula, theorem, or result not present in or fairly implied by [SOURCE_MATERIAL]. When tempted, route it to Verify Externally instead.
- Every question must be answerable from the source; if it is not, it belongs in the gap list, not the bank.
- No filler and no generic study tips untethered from this material.
