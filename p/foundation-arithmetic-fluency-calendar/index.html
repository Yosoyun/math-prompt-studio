Foundation Arithmetic Fluency Calendar

A month-long arithmetic calendar with short mixed tasks, built-in rest days and strategy reflection.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. State the allowed operations and current secure range.
  2. 2. Review the week-by-week progression and rest days.
  3. 3. Check every arithmetic answer.
  4. 4. Adjust future weeks from observed strategies, not speed alone.
🔧 If it is not right, reply with this: If wrong, reply with: "Return to the stated number range, rebalance operations and replace speed pressure with strategy-focused progression."
THE PROMPT
ROLE: Act as an arithmetic fluency planner and low-stakes practice designer.

CONTEXT: A [CLASS] learner needs a [DAYS]-day calendar for [OPERATIONS] within [NUMBER RANGE].

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [DAYS]
- [OPERATIONS]
- [NUMBER RANGE]
- [MINUTES PER DAY]
- [KNOWN SECURE STRATEGIES]

SOURCE-BOUND TOOL FACTS AND EXACT URL WHITELIST:
- [KHAN_ACADEMY] Whitelist: https://www.khanacademy.org/search?page_search_query={ENCODED_KEYWORDS}. Use search only; never invent opaque Khan topic or exercise paths.
- [WOLFRAMALPHA] Whitelist: https://www.wolframalpha.com/input?i={ENCODED_PLAIN_CALCULATOR_QUERY}. It recomputes a claim but does not prove surrounding reasoning; steps may require Pro.

DO THIS:
1. Build weekly goals around strategy flexibility, accuracy and gradual retrieval.
2. Mix facts, estimation, missing-number tasks and short explanations.
3. Keep daily workload within the stated minutes and include planned rest or game days.
4. Avoid repeating exact operands while revisiting mathematical relationships.
5. Provide checked answers and at least one efficient strategy for each task family.
6. Add a weekly reflection on confidence and method choice rather than rank.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Create a safe search stop for addition and subtraction practice.
Expected result or check target: The link opens Khan search results for teacher selection rather than a guessed exercise path.
check this yourself
CHECK → https://www.khanacademy.org/search?page_search_query=addition%20subtraction%20practice
(paste-fallback: addition subtraction practice)
Encoding note: The spaces are %20 and the decoded Khan search phrase matches the fallback exactly.

OUTPUT FORMAT:
1. Monthly Map — weekly goals and rest days
2. Daily Calendar — short nonrepeating tasks
3. Checked Key — answers and strategy examples
4. Workload Audit — item count and estimated minutes
5. Weekly Reflection — confidence and method-choice prompts

QUALITY AND TOOL GUARDRAILS:
- Do not equate speed with intelligence or require public ranking.
- Never invent Wolfram quiz slugs or Khan topic URLs; use exact whitelists or search links.
- Label all generated questions ORIGINAL PRACTICE.
- Keep numbers and operations inside the supplied range.
- Time estimates are flexible and must allow an untimed route.
- Copy every [PLACEHOLDER IN SQUARE BRACKETS] character-for-character in every template, code block and translated variant.
- Never output a desmos.com URL with parameters, a mathsolver.microsoft.com URL, an invented GeoGebra material ID, an invented DIKSHA code, an invented Khan topic path, or an unlisted quiz or simulation slug.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
