Game-Style Timed Quiz (with Points and Rounds)

A ready-to-run classroom quiz game with rounds, timers, point values and a verified answer key.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Fill class, board and chapter.
  2. 2. Say total time and number of teams.
  3. 3. Send the prompt.
  4. 4. Read out each round and start the timer.
  5. 5. Award points using the key.
🔧 If it is not right, reply with this: If a round is too long for the time, reply: 'Round 2 has too many questions for 5 minutes - cut it to fit and keep the points balanced, then re-verify answers.'
THE PROMPT
ROLE: Act as a mathematics teacher and quiz-master designing a fun, fast classroom quiz game.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board]. The chapter is [CHAPTER NAME]. The class will play in [NUMBER, e.g. 4] teams. Total game time is about [MINUTES, e.g. 20] minutes.

YOUR TASK:
1. Design a quiz game with 3 to 4 named rounds, for example: Round 1 Warm-Up (1 point each), Round 2 Formula Flash (2 points), Round 3 Brain-Buster (3 points), and an optional Lightning Round.
2. Give each round a clear instruction, a suggested time, and 4 to 6 short questions.
3. Match point values to difficulty.
4. Keep most questions answerable quickly so the game flows.

INPUT: Here is the sub-topic and any specific skills to feature: [PASTE TOPIC OR LEAVE BLANK].

HOW TO WORK IT OUT: Solve every question and VERIFY each answer twice so scoring is never disputed. Do not invent values or formulas. Keep maths clearly readable for reading aloud or projecting.

OUTPUT FORMAT:
GAME TITLE and short how-to-play box (teams, timing, scoring).
For each round: round name, instruction, time, points, then the numbered questions.
FINAL SECTION - ANSWER KEY: organised by round, each answer on one line.
TIE-BREAKER: one extra hard question with its answer.

RULES: Keep it fast and fun, no question needing long calculation in a timed round. Balanced difficulty across rounds. Suited to the class above.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
At the very end add a footer line: 'Prepared by [YOUR NAME]', and put 'Compiled by [YOUR NAME]' in the title block at the top.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
