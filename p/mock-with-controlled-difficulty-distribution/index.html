Mock with Controlled Difficulty Distribution

A mock where you set the easy/medium/hard mix, with a labelled breakdown.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Set your easy/medium/hard percentages.
  2. 2. List chapters and total marks.
  3. 3. Send the prompt.
  4. 4. Check the difficulty table matches.
  5. For a trustworthy answer key: paste the finished paper into a FRESH chat and ask it to solve and grade it as an unseen exam (it catches its own slips).
🔧 If it is not right, reply with this: If the mix is off, reply: "Recount the difficulty table - I asked for 40 percent easy, 40 medium, 20 hard. Adjust questions to hit that exactly."
THE PROMPT
ROLE: Act as a psychometrically-aware paper-setter who controls difficulty distribution.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / JEE / NEET]. A good paper has a deliberate mix of easy, medium and hard questions so weak and strong students are both tested fairly. I want to set that mix exactly.

YOUR TASK:
1. Build a full mock for these chapters: [LIST CHAPTERS]. Total marks: [TOTAL MARKS]. Time: [TIME].
2. Match this difficulty mix as closely as possible: Easy [X%], Medium [Y%], Hard [Z%]. (These must add to 100.)
3. Tag each question silently as Easy / Medium / Hard while building, then report the final counts.
4. Provide solutions and an answer key.

INPUT: Here are the chapters, marks and difficulty mix: [PASTE DETAILS HERE].

HOW TO WORK IT OUT: Solve every question internally first and judge its true difficulty for an average [CLASS/GRADE] student. VERIFY each answer two independent ways. Never invent formulas or values. Count the easy/medium/hard questions and confirm the mix matches my request before showing me. Keep all maths legible in clean plain text or LaTeX.

OUTPUT FORMAT (exact order):
HEADER: Subject, Class, Board/Exam, Marks, Time, Instructions.
PAPER: sections, numbered questions, with a small [E]/[M]/[H] tag after each question.
DIFFICULTY TABLE: Level | Number of questions | Marks | Percent of paper, with a final row confirming it matches the target mix.
SOLUTIONS: full steps.
ANSWER KEY: compact list.
VERIFICATION NOTE: confirm answers checked and mix verified.

RULES: The difficulty percentages must add to 100 and match the target within reason. Marks total [TOTAL MARKS]. Original questions. Difficulty true to [BOARD or EXAM].

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
