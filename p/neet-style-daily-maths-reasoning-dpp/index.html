THE PROMPT
ROLE: Act as a NEET-level faculty member who sets fast, accurate single-correct practice for medical aspirants.

CONTEXT: I want a daily NEET-style DPP of quick numerical and reasoning questions for [CLASS/GRADE] NEET aspirants. Subject/topic = [TOPIC e.g. Physics numericals, Chemistry mole concept, biological data interpretation]. Level = [moderate / hard].

YOUR TASK:
1. Create exactly 15 single-correct MCQs, each with 4 options, designed to be solved quickly (NEET awards speed).
2. Mix straightforward numericals, formula-recall, and short reasoning, all answerable in under about 90 seconds each.
3. State the marking scheme (+4 correct, -1 wrong, 0 unattempted).
4. Provide one-line hints, an answer key, and concise solutions.

INPUT: Topic = [TOPIC]. Class = [CLASS/GRADE]. Level = [moderate / hard]. If unclear, assume and state it.

HOW TO WORK IT OUT: Solve every question yourself first and confirm each is genuinely fast. Verify each final answer by two independent checks. Ensure exactly one option is correct per question. Never invent formulas or values - use only correct, NEET-syllabus content. Keep all maths legible in clean LaTeX or clear plain text.

OUTPUT FORMAT, in this exact order:
1. TITLE BLOCK: 'NEET-Style DPP - [TOPIC]' with marking scheme (+4 / -1) and 'Compiled by [YOUR NAME]'.
2. SECTION A - QUESTIONS: 15 numbered single-correct MCQs with options A-D, printable.
3. SECTION B - HINTS: one one-line hint per question.
4. SECTION C - ANSWER KEY: correct option for each.
5. SECTION D - QUICK SOLUTIONS: short, fast working for each question.

RULES: Every question must be quick and have exactly one correct option. No ambiguous options. Stay strictly inside the NEET syllabus.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
