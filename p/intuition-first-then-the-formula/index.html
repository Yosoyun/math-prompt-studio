Intuition First, Then the Formula

The gut feeling for a concept built before any symbol appears.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Open any free AI chat.
  2. 2. Paste the prompt.
  3. 3. Type your concept and class level.
  4. 4. Send and read the intuition first.
  5. 5. Only then show the formula.
🔧 If it is not right, reply with this: If it jumps to the formula too fast, reply: "Spend more time on the intuition. Do not show any formula until the gut feeling is fully built."
THE PROMPT
ROLE: Act as a mathematics teacher who always builds intuition before introducing any formula.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. Students memorise this formula without understanding it: [WRITE THE CONCEPT OR FORMULA HERE]. I want the intuition built first, so the formula feels obvious by the time it appears.

YOUR TASK:
1. Build the intuition step by step using pictures-in-words, simple numbers, and everyday reasoning.
2. Let the student almost predict the formula before you reveal it.
3. THEN state the formula and show that it matches the intuition you built.
4. Show one worked example that uses both the intuition and the formula.
5. Add one line a teacher can say to connect the feeling to the symbols.

INPUT: Here is the concept or formula: [PASTE OR TYPE IT HERE]. Class level: [CLASS/GRADE].

HOW TO WORK IT OUT: Before writing, solve the example fully. VERIFY the final answer two independent ways (for example, plug numbers into the intuition AND into the formula and confirm they agree). Never invent formulas; reveal only the correct standard one. Keep all maths legible in clear plain text.

OUTPUT FORMAT (use these exact headings in order):
- CONCEPT
- BUILD THE FEELING (3 to 5 numbered intuition steps, NO formula yet)
- CAN YOU GUESS THE RULE? (1 line nudging the prediction)
- NOW THE FORMULA (state it; show how it matches the feeling)
- WORKED EXAMPLE (full steps, with VERIFICATION labelled)
- TEACHER'S BRIDGE LINE (one sentence)

RULES: Absolutely no formula in the BUILD THE FEELING section. Keep numbers small and friendly. Every symbol must be defined when it first appears.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return one complete, editable document ready to paste into Word or Google Docs. Use a descriptive title, short section headings, readable paragraphs, numbered actions and tables only where they make the material easier to use. Include every requested section; do not return formatting advice instead of the document.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
