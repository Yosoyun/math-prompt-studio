Jeopardy Board for Exam Revision

A full 5x5 Jeopardy board across 5 topics with 25 clues, Daily Doubles, Final Jeopardy and host rules.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. Pick and type your 5 revision topics.
  2. Add your class and board.
  3. Paste the prompt and send.
  4. Copy the 5x5 grid onto the board.
  5. Run teams; keep the answer key hidden.
🔧 If it is not right, reply with this: If two cells test the same idea or a value looks wrong, reply: "Replace any duplicate cells, re-verify all answers, and make the 500-point clues clearly harder than the 100-point ones."
THE PROMPT
ROLE: Act as a quiz-show host and mathematics teacher who builds a Jeopardy-style board that runs itself.

CONTEXT: My students are in [CLASS/GRADE] studying for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. I want a Jeopardy board covering [LIST 5 TOPICS, e.g. Algebra, Geometry, Trigonometry, Probability, Mensuration] for a revision class with teams.

YOUR TASK:
1. Build a 5-column by 5-row Jeopardy board: 5 topic columns, point values 100, 200, 300, 400, 500 down each column.
2. Write one clue (the answer-style prompt) and the correct response for all 25 cells.
3. Make difficulty rise with point value inside each column.
4. Add 2 Daily Double cells (mark them) and one Final Jeopardy question with a wager rule.
5. Give simple host rules: how teams buzz, points for wrong answers, and timing.

INPUT: Here are my 5 topics: [PASTE 5 TOPICS HERE]. Class, board and team setup are above.

HOW TO WORK IT OUT: Solve each clue internally first. Verify every final answer by two independent checks and confirm they match. Never invent formulas or data. Keep all maths in clean LaTeX or clear plain text.

OUTPUT FORMAT (use these exact headings):
HOW TO RUN THIS BOARD (host rules, numbered)
THE BOARD (a 5x5 table: columns are the 5 topics, rows are 100 to 500, each cell shows the clue)
ANSWER KEY (list every cell as Topic-Value then the correct response in a box [Answer: ...])
DAILY DOUBLE CELLS (name the 2 cells)
FINAL JEOPARDY (category, question, answer, and wager rule)
SCORING SUMMARY

RULES: All 25 clues must be distinct and verified. Difficulty must clearly increase with points. Keep clues short enough to read aloud in 15 seconds. Do not repeat a concept across two cells unless the angle is genuinely different.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
