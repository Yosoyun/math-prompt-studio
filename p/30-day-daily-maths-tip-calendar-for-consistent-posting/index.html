30-Day Daily Maths Tip Calendar for Consistent Posting

A full month of short, postable daily tips in a clean table.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Open any free AI chat.
  2. 2. Paste the prompt below.
  3. 3. Add your subject, class and exam.
  4. 4. Send and get a 30-row table.
  5. 5. Post one row each day.
🔧 If it is not right, reply with this: If tips repeat, reply: "Days 12 to 20 feel similar. Replace them with tips on new sub-topics and keep variety."
THE PROMPT
ROLE: Act as a content planner who builds simple, sustainable posting calendars for teachers.

CONTEXT: I want to post one short maths tip every day to stay consistent and grow my page. I teach [SUBJECT/TOPIC e.g. Algebra] to [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / JEE / NEET]. Each tip will become a quick story or post, so it must be tiny and self-contained.

YOUR TASK:
1. Create a 30-day calendar of daily tips.
2. Each day gives ONE bite-sized, genuinely useful tip a student can apply immediately.
3. Spread tips across different sub-topics so the month feels varied.
4. Mix tip types: a shortcut, a common-mistake warning, a memory trick, a concept clarifier, and a confidence booster.
5. Keep each tip under 25 words so it fits a single phone screen.

INPUT: My focus for the month is: [PASTE TOPIC AREAS, e.g. quadratic equations, sequences, basic calculus]. Anything to avoid: [PASTE, or write none].

HOW TO WORK IT OUT: Solve or check any maths internally first. Before listing a tip that contains a formula or shortcut, VERIFY it is correct with a quick mental test. Never invent rules that are not true. Use plain text maths (^ for powers, sqrt() for roots, / for fractions) that reads cleanly on a phone.

OUTPUT FORMAT: Give a table with these columns and 30 rows.
Day | Tip Type | The Tip (post-ready text) | One-word hashtag idea
After the table add: WEEKLY THEME LINE - one short line naming the theme of each of the 4 weeks.

RULES: No tip may be wrong or misleading. No two tips may be the same. Friendly, encouraging tone. Plain ASCII only, straight quotes only.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return one complete, editable document ready to paste into Word or Google Docs. Use a descriptive title, short section headings, readable paragraphs, numbered actions and tables only where they make the material easier to use. Include every requested section; do not return formatting advice instead of the document.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.

SIGNATURE: End your ENTIRE response with exactly this footer block (keep the lines and symbols):
