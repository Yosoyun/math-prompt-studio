Maths Poster / Infographic Brief

A poster brief telling students exactly what content and layout to put on the page.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Type the poster topic and class.
  2. 2. Paste the prompt into any AI chat.
  3. 3. Print the content list and layout map.
  4. 4. Students design the poster by hand.
  5. 5. Grade with the included checklist.
🔧 If it is not right, reply with this: If the content is too thin, reply: "Add two more sections of real mathematical content with a worked example each, and re-verify the maths."
THE PROMPT
ROLE: Act as a maths teacher who sets clear, content-rich poster projects (the AI writes the brief; students draw the poster).

CONTEXT: I teach [CLASS/GRADE] under [BOARD e.g. CBSE / ICSE / State Board]. I want a POSTER / INFOGRAPHIC BRIEF on the topic [TOPIC e.g. the real-life uses of trigonometry / famous mathematicians / types of triangles]. Note: you will NOT generate an image; you will write a precise brief so students can create the poster by hand or in any drawing app.

YOUR TASK:
1. Define the poster's title and one-line message.
2. List the exact sections/boxes the poster must contain.
3. For each section, give the precise text and any maths the student should include (with a short worked example where relevant).
4. Provide a simple layout map (where each box sits on the page).
5. Suggest colours and headings for clarity (described in words).
6. Provide a 15-mark grading checklist.

INPUT: Here is my topic and paper size: [PASTE TOPIC AND PAPER SIZE e.g. A3 HERE]. If blank, choose a strong topic for the class and board above and assume A3.

HOW TO WORK IT OUT: Plan the content internally. Ensure every fact and formula is correct; VERIFY any worked example a second way and show the check. Never invent formulas, dates or facts you are unsure of; if unsure, say so. Keep all maths legible in clean plain text or simple LaTeX.

OUTPUT FORMAT (use these exact headings in this order):
1. POSTER TITLE AND MESSAGE
2. SECTIONS / BOXES (numbered)
3. EXACT CONTENT PER SECTION (text + maths + worked example with check)
4. LAYOUT MAP (describe top/middle/bottom and left/right placement)
5. DESIGN NOTES (colours, headings, fonts described in words)
6. GRADING CHECKLIST (15 marks)

RULES: This is a text brief, not an image. Be exact about what goes where. Short, plain sentences.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return the complete material as a clean, print-ready A4 handout that can be pasted into Word or Google Docs and saved as PDF. Use a clear title, logical sections, readable mathematics and page-break markers where needed. Keep student material separate from the answer key or teacher notes.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
