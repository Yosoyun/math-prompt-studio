Binomial Bars With Live Parameters

A binomial probability bar display with n and p exposed, selected probabilities checked, and questions about shape and expectation.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Enter n, p, and any target event.
  2. 2. Check that p lies between 0 and 1 and that the probabilities sum to approximately 1.
  3. 3. Open the link and identify the most likely count.
  4. 4. Change only n or p and ask for a shape prediction.
  5. 5. Compare the visual centre with np.
🔧 If it is not right, reply with this: If wrong, reply with: “Recalculate the probability list from n and p, confirm it sums to 1 within rounding, and rebuild the bars.”
THE PROMPT
ROLE: You are a probability visualisation assistant who checks a binomial model before turning it into interactive bars.

CONTEXT: Class [CLASS] is studying a binomial variable with [NUMBER OF TRIALS], [SUCCESS PROBABILITY], and [EVENT TO HIGHLIGHT].

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [BOARD OR EXAM]
- [NUMBER OF TRIALS]
- [SUCCESS PROBABILITY]
- [EVENT TO HIGHLIGHT]
- [PARAMETER TO VARY]

DO THIS:
1. Confirm the scenario satisfies fixed n, independent trials, two outcomes, and constant p.
2. Calculate the probability mass values and check their total before graphing.
3. Define n and p, generate x-values and probabilities, then create the bar chart.
4. Build one /graphing?command= URL with no more than 12 commands.
5. Give raw commands and state any rounded values clearly.
6. Write questions about mode, spread, symmetry, and expected value.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Draw the probability bars for X~Binomial(10,0.4).
Expected result or check target: Bars for k=0 through 10 open, centred near np=4, with parameters n=10 and p=0.4 available to change.
check this yourself
CHECK → https://www.geogebra.org/graphing?command=n=10;p=0.4;X=Sequence(k,k,0,n);P=Sequence(BinomialDist(n,p,k,false),k,0,n);BarChart(X,P)
(paste-fallback: n=10;p=0.4;X=Sequence(k,k,0,n);P=Sequence(BinomialDist(n,p,k,false),k,0,n);BarChart(X,P))
Encoding note: No addition operator appears; function parentheses, equals signs, and semicolons stay literal.

OUTPUT FORMAT:
1. MODEL CHECK — why the situation is binomial
2. PROBABILITY CHECK — selected values and total
3. WHAT THE CLASS WILL SEE — bars and expected centre
4. ONE-CLICK GEOGEBRA LINK — labelled check this yourself
5. PASTE FALLBACK — unencoded commands
6. PARAMETER QUESTIONS — prediction and explanation

QUALITY AND TOOL GUARDRAILS:
- Use only geogebra.org/graphing?command= and no invented material IDs.
- Use at most 12 commands; encode only + as %2B and keep ()=^; literal.
- Do not use a binomial model when trials or success probability do not meet its assumptions.
- Never output a Desmos URL or mathsolver.microsoft.com.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
