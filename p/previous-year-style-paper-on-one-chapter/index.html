Previous-Year-Style Paper on One Chapter

A fresh paper that imitates the flavour and difficulty of past exam questions on one chapter.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Paste the prompt into a chat.
  2. 2. Name the single chapter.
  3. 3. Name the exam style to imitate.
  4. 4. Send and review the question feel.
  5. 5. Check the key for correctness.
  6. For a trustworthy answer key: paste the finished paper into a FRESH chat and ask it to solve and grade it as an unseen exam (it catches its own slips).
🔧 If it is not right, reply with this: If questions feel off-style, reply: 'These feel too [easy/hard/unusual] for [EXAM]. Match the typical phrasing and difficulty of past [EXAM] questions on this chapter, then re-verify.'
THE PROMPT
ROLE: Act as a mathematics teacher who knows past examination patterns intimately and can write original questions in that style.

CONTEXT: I want a PREVIOUS-YEAR-STYLE practice paper for Class [CLASS/GRADE], imitating the typical style and difficulty of [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET], on ONE chapter only: [CHAPTER NAME]. These must be NEW, original questions in that style, not copied from any real paper. Total marks [TOTAL MARKS], time [TIME].

YOUR TASK:
1. Write original questions that capture how this exam usually frames this chapter (phrasing, twists, typical traps).
2. Match the usual distribution of easy, moderate and hard questions for that exam.
3. Include the common question types this exam favours for this chapter.
4. Provide a complete answer key.

INPUT: The chapter is: [CHAPTER NAME]. If you are unsure of the exact past style, state your best understanding in one line and proceed.

HOW TO WORK IT OUT: Solve every question internally before printing. Verify each final answer twice by independent methods. Do NOT reproduce any real exam question verbatim; create fresh ones. Never invent formulas or values. Keep mathematics legible in clean LaTeX or plain text. Confirm marks total exactly [TOTAL MARKS].

OUTPUT FORMAT, in this order:
1. HEADER: 'Past-Paper-Style Practice - [CHAPTER NAME]', class, exam style, time, maximum marks, 'Compiled by [YOUR NAME]'.
2. INSTRUCTIONS: 3 to 5 numbered lines.
3. THE PAPER: numbered questions, marks beside each.
4. ANSWER KEY: final answers plus short working outline for long questions.

RULES: Original questions only. Stay inside [CHAPTER NAME]. Number every question. Marks total exactly.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
