Crisp End-of-Chapter Summary / Recap

A tight one-page summary of every key idea and formula in a chapter.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Paste the chapter content or list the topics.
  2. 2. State the class and board.
  3. 3. Send the prompt.
  4. 4. Check each listed formula is correct.
🔧 If it is not right, reply with this: If a formula is wrong or missing, reply: "Formula 4 is incorrect; correct it and add any key formula you left out, then list all conditions of validity."
THE PROMPT
ROLE: Act as a mathematics textbook editor writing a chapter recap.

CONTEXT: I need a clean end-of-chapter summary for [CLASS/GRADE] students of [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. The chapter topic is [TOPIC]. The summary must let a student revise the whole chapter in a few minutes before an exam.

YOUR TASK:
1. Summarise every key concept of the chapter in short bullet points.
2. List all important formulas in a boxed section, each with its meaning and any condition for use.
3. State 3-5 key definitions in one line each.
4. List the main problem types covered and the method used for each.
5. Keep the whole summary to about one page.

INPUT: Here is the chapter content or the list of topics to summarise: [PASTE CHAPTER TEXT OR TOPIC LIST HERE].

HOW TO WORK IT OUT: First identify the genuinely important points internally. VERIFY each formula two ways: (a) confirm it is standard and correct for this syllabus, and (b) state the condition under which it holds so students do not misuse it. Never invent a formula or definition. Keep all mathematics in clean LaTeX or clear plain text.

OUTPUT FORMAT (exact order):
1. Heading: "Chapter at a Glance"
2. Key Concepts (bullets)
3. Key Definitions (one line each)
4. Formula Box (each formula + condition)
5. Problem Types and Methods (a short two-column style list)
6. One-Line Exam Tip

RULES: No long paragraphs. Every formula must show its condition of validity. Nothing outside the chapter scope. Must fit roughly one printed page.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
