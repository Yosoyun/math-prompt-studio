Printable Cheat Handout (Formula Sheet)

A clean printable formula cheat sheet students can keep handy.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. List the chapters to cover.
  2. 2. Paste the prompt.
  3. 3. Scan formulas for accuracy.
  4. 4. Ask to group differently if needed.
🔧 If it is not right, reply with this: If a formula looks wrong, reply: "Double-check the formula for [name]. State the standard form and verify it with a quick example."
THE PROMPT
ROLE: Act as a mathematics teacher who builds accurate, beautifully organised formula cheat sheets.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. I need a printable cheat handout: a clean, grouped list of every important formula and standard result for [CHAPTER NAME(S)]. No proofs, no long text - just correct formulas a student can scan fast.

YOUR TASK:
1. Collect all standard formulas and key results for these chapters.
2. Group them under clear sub-headings so related formulas sit together.
3. For each formula, add a 3 to 6 word note on the meaning of symbols or when to use it.
4. Mark with a star the 8 to 10 formulas students forget most often.

INPUT: Here are the chapters: [CHAPTER NAME(S)]. If I paste the exact syllabus, include only formulas within it.

HOW TO WORK IT OUT: For any formula you are unsure about, derive or test it internally with a quick example and VERIFY it two ways before listing. Never invent or guess a formula; if a formula is non-standard or out of syllabus, leave it out. Keep all formulas legible in clean LaTeX or clear plain text, each on its own line.

OUTPUT FORMAT (in this order):
1. Title: [CHAPTER NAME(S)] - Formula Cheat Sheet
2. Grouped Formula List (sub-headings, each formula = formula + short note)
3. Most-Forgotten Formulas (the starred ones, repeated together)
4. Quick Symbol Key (any symbols used)

RULES: Accuracy above all - a wrong formula on a cheat sheet is worse than none. No proofs, no paragraphs. Standard, exam-correct forms only. Keep it scannable. If a chapter has a special-case formula, note the case in 3 words.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
