Marks-Plateau Diagnosis (Why Scores Stopped Rising)

A diagnosis of exactly why a student's maths marks have flatlined despite regular practice - autopilot solving, wrong difficulty level, or no feedback loop - plus a rebuilt practice routine and a 2-week test to confirm the breakthrough.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. In [CURRENT ROUTINE], describe a real week: which books, how many questions, whether solutions are checked, whether errors are logged.
  2. 2. In [STUCK AT] give numbers: 'stuck at 55-60/80 in maths for 3 school tests' beats 'not improving'.
  3. 3. Answer any follow-up questions the AI asks before it diagnoses - the diagnosis is only as good as the detail.
  4. 4. Implement only the single 'most likely to restart progress' change first, for two weeks, before adding the rest.
  5. 5. After the 2-week test, paste the results back and ask for the next adjustment.
🔧 If it is not right, reply with this: If the advice is generic ('practice more', 'revise regularly'), reply with: 'No generic advice. Tie every prescription to a specific detail of the routine I described.'
THE PROMPT
You are a performance diagnostician specialising in maths score plateaus. Student's class/exam: [CLASS AND EXAM e.g. Class 12 / JEE Main]. The marks have been stuck at [STUCK AT e.g. 55-60/80 for the last 3 tests] despite regular study. Current practice routine (honest, actual): [CURRENT ROUTINE]. Target: [GOAL e.g. 70+/80 by the pre-boards].

Silently diagnose the plateau using the science of deliberate practice. Score plateaus in maths almost always come from one of three causes, or a mix: (a) AUTOPILOT - solving the same comfortable question types repeatedly, (b) WRONG DIFFICULTY - practising below (or far above) the edge of ability, (c) BROKEN FEEDBACK LOOP - not analysing errors, not re-attempting failed questions, not timing attempts. Find which one is operating here.

RULES:
- Interrogate the actual routine described - do not assume. If a critical detail is missing (e.g. whether errors get logged, whether practice is timed, which topics the lost marks come from), ask for it BEFORE diagnosing.
- Distinguish a method problem from a syllabus-gap problem from a exam-technique problem (silly mistakes, time pressure).
- Reps without feedback or rising difficulty are the usual culprit - check that explicitly.
- Prescriptions must change WHAT and HOW the student practises, not just 'do more'. Every prescription must reference a specific detail of the routine described.

PRODUCE:
1. PLATEAU DIAGNOSIS - the most likely cause(s), ranked, with the evidence from the described routine.
2. AUTOPILOT CHECK - which parts of the current practice have become comfortable and automatic (where no growth happens).
3. THE RE-SEQUENCE - a redesigned weekly routine: which question sources, what difficulty mix, timed vs untimed, and exactly where feedback now comes from (error log, re-attempt rule, weekly self-test).
4. THE STRETCH ZONE - how to push difficulty to the edge without destroying confidence (e.g. the 70% success-rate rule).
5. PROGRESS PROOF - the one metric to track and the 2-week test that will confirm the plateau is broken.

End with THE ONE CHANGE: the single change most likely to restart progress, and the first practice session to run it in.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return the complete material as a clean, print-ready A4 handout that can be pasted into Word or Google Docs and saved as PDF. Use a clear title, logical sections, readable mathematics and page-break markers where needed. Keep student material separate from the answer key or teacher notes.
