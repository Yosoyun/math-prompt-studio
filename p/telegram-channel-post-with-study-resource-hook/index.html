Telegram Channel Post With Study Resource Hook

A formatted Telegram post that drives clicks and saves.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Open any free AI chat.
  2. 2. Paste the prompt below.
  3. 3. Describe the resource or topic.
  4. 4. Send and read the post.
  5. 5. Copy it into Telegram and publish.
🔧 If it is not right, reply with this: If the hook is weak, reply: "Make the first line stronger and add one clear reason a student must read this now."
THE PROMPT
ROLE: Act as a Telegram channel content writer for an exam-prep audience, skilled at punchy, scannable posts.

CONTEXT: I run a Telegram channel for [CLASS/GRADE] students preparing for [BOARD or EXAM e.g. JEE / NEET / CBSE]. Telegram readers want value fast and respond to clean formatting, emojis used sparingly, and clear next steps.

YOUR TASK:
1. Write ONE Telegram channel post about the topic or resource I name.
2. Start with a bold, benefit-led headline.
3. Give 3 to 5 quick value points the reader gets.
4. Add a short 'why this matters for your exam' line.
5. End with one clear call to action (react, save, share, or tap a link placeholder).

INPUT: Here is what the post is about: [PASTE TOPIC OR RESOURCE, e.g. a free formula sheet for coordinate geometry]. Any link I will add: [PASTE LINK or write 'LINK PLACEHOLDER'].

HOW TO WORK IT OUT: Use only the facts I provide. If the post mentions any maths fact or formula, verify it is correct before including it. Do not invent download links, prices, or claims. Keep maths in clean plain text (^ for powers, sqrt() for roots). Mark words to bold with *single asterisks* (Telegram-friendly).

OUTPUT FORMAT: Use this exact structure.
HEADLINE: bold, benefit-led.
VALUE POINTS: 3 to 5 short dash points.
WHY IT MATTERS: one line tying it to the exam.
CALL TO ACTION: one clear line (with LINK PLACEHOLDER if needed).
HASHTAGS/KEYWORDS: 4 to 6 searchable tags.
POSTING TIP: one line on best time to post for students.

RULES: No invented links or claims. Max 4 emojis total. Scannable, value-first tone. Plain ASCII, straight quotes only.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.

SIGNATURE: End your ENTIRE response with exactly this footer block (keep the lines and symbols):
