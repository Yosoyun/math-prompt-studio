Parent-Shareable Practice Checkpoint

A low-pressure practice Form, child-friendly self-check links and a clear parent message that supports practice without revealing answers first.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Choose a narrow skill and a workload the child can finish independently.
  2. 2. Check the answer key and open every self-check link before sharing.
  3. 3. Run the script, test the student flow and copy the respondent URL from Logs.
  4. 4. Send the parent note and ask adults to use hints before showing solutions.
  5. 5. Review patterns privately rather than posting child scores in a group.
🔧 If it is not right, reply with this: If wrong, reply with: "Rewrite the family protocol in simple respectful language, keep answers hidden until submission and make every check link match its question exactly."
THE PROMPT
ROLE: Act as a family-friendly maths practice designer, safeguarding-aware communicator and Google Forms developer.

CONTEXT: A teacher wants parents of [CLASS] students to support practice on [SKILL] from a phone without turning it into a high-pressure test.

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [SKILL]
- [QUESTION COUNT]
- [AGE LEVEL]
- [EXPECTED TIME]
- [HOME LANGUAGE]
- [HELP POLICY]

DO THIS:
1. Write age-appropriate practice questions with a gentle easy-to-medium progression.
2. Give the teacher a checked key and attach browser-based check-this-yourself links that parents use only after the child attempts the item.
3. Generate one complete executable FormApp script with quiz mode, required items, points, brief feedback and logged URLs.
4. Write a parent message explaining the purpose, time, hint-first protocol and how to avoid giving the answer.
5. Add a student self-check routine: estimate, attempt, submit, open the matching link and correct one line.
6. Avoid collecting unnecessary personal data and include a private teacher follow-up plan.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Create a parent-shareable order-of-operations practice set containing 24/6+3*2.
Expected result or check target: The verified value is 10, and the protocol asks the child to calculate before opening the self-check link.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=24%2F6%2B3%2A2
(paste-fallback: 24/6+3*2)
Encoding note: The plus sign is %2B; the slash and multiplication asterisk remain readable URL characters.

OUTPUT FORMAT:
1. PRACTICE REVIEW COPY
2. TEACHER-VERIFIED KEY
3. COMPLETE GOOGLE APPS SCRIPT
4. RUN IT — script.google.com → New project → paste → Run → View → Logs
5. PARENT-SHARE MESSAGE
6. CHILD SELF-CHECK PROTOCOL
7. PRIVACY NOTE

QUALITY AND TOOL GUARDRAILS:
- Output one COMPLETE executable FormApp code block and print exactly: script.google.com → New project → paste → Run → View → Logs.
- Never claim a URL can create the Form; the script creates it and the teacher shares the logged respondent URL.
- Do not collect email, phone number or other unnecessary child data.
- Label maths links check this yourself and tell families to open them in a browser after attempting.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
