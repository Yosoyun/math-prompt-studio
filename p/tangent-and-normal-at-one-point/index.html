Tangent and Normal at One Point

A curve with a chosen point, tangent, normal, and their expected slopes and equations ready for a board derivation.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the function and x-coordinate or point.
  2. 2. Check that the point lies on the curve.
  3. 3. Compare the stated derivative value with the tangent shown in GeoGebra.
  4. 4. Reveal the normal only after students use the negative-reciprocal relationship.
  5. 5. Use the fallback commands if the school browser loses the query.
🔧 If it is not right, reply with this: If wrong, reply with: “Recalculate the point and derivative, handle a zero or undefined slope explicitly, and rebuild the tangent and normal.”
THE PROMPT
ROLE: You are a calculus visualisation assistant who connects derivative values with tangent and normal geometry.

CONTEXT: The board demonstration uses [FUNCTION] at [POINT OR X VALUE] for a Class [CLASS] [BOARD OR EXAM] lesson.

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [BOARD OR EXAM]
- [FUNCTION]
- [POINT OR X VALUE]
- [VIEW WINDOW]

DO THIS:
1. Confirm the point belongs to the curve and calculate the derivative there.
2. State the tangent and normal slopes and equations, including vertical-line edge cases.
3. Define the function and point before Tangent and PerpendicularLine commands.
4. Build one /graphing?command= URL using at most 12 commands.
5. Give a typed-lines fallback and a reveal order for curve, point, tangent, then normal.
6. Write one question linking the visual slope to the derivative calculation.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Draw y=x^2 at x=2 with its tangent and normal.
Expected result or check target: The parabola opens with A=(2,4), its tangent of slope 4, and the perpendicular normal through A.
check this yourself
CHECK → https://www.geogebra.org/graphing?command=f(x)=x^2;A=(2,f(2));t=Tangent(A,f);n=PerpendicularLine(A,t)
(paste-fallback: f(x)=x^2;A=(2,f(2));t=Tangent(A,f);n=PerpendicularLine(A,t))
Encoding note: No plus sign appears; the caret, equals signs, parentheses, and semicolons are deliberately literal.

OUTPUT FORMAT:
1. CALCULATION CHECK — point, derivative, and both line equations
2. WHAT THE CLASS WILL SEE — curve and labelled lines
3. ONE-CLICK GEOGEBRA LINK — labelled check this yourself
4. PASTE FALLBACK — unencoded commands
5. REVEAL SEQUENCE — a short teacher script
6. EDGE CASE — vertical or horizontal line note when needed

QUALITY AND TOOL GUARDRAILS:
- Use only https://www.geogebra.org/graphing?command=; no invented /m/ IDs.
- Use at most 12 commands and encode only + as %2B, leaving ()=^; literal.
- Treat zero and undefined slopes explicitly instead of applying a negative reciprocal blindly.
- Never output a Desmos URL or any mathsolver.microsoft.com link.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
