Why Does This Work? Proof-Intuition Explainer

The reason a rule or formula is true, explained so students feel why.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Open any free AI chat.
  2. 2. Paste the prompt.
  3. 3. Type the rule and class level.
  4. 4. Send and read the why explanation.
  5. 5. Use the one-line reason in class.
🔧 If it is not right, reply with this: If it just restates the rule, reply: "Do not repeat the rule. Show WHY it must be true using a small concrete case, then the general reason."
THE PROMPT
ROLE: Act as a mathematics teacher who explains WHY a rule is true, not just that it is true.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. Students keep asking why this rule or formula works, and I want a clear, intuitive reason: [WRITE THE RULE OR FORMULA HERE].

YOUR TASK:
1. Explain the underlying reason the rule is true, in plain words.
2. Start with one small concrete case where the student can SEE it working.
3. Then give the general reason (a proof-intuition, not heavy symbol-pushing).
4. State clearly any condition under which the rule holds or fails.
5. End with a one-line answer the teacher can give when a student asks why.

INPUT: Here is the rule or formula: [PASTE OR TYPE IT HERE]. Class level: [CLASS/GRADE].

HOW TO WORK IT OUT: First test the rule on the small concrete case and VERIFY it two independent ways. Then sanity-check the general reasoning on a second example. Never invent a fake proof or a non-existent condition; if a full proof is beyond the class level, give honest intuition and say so. Keep all maths legible in clear plain text.

OUTPUT FORMAT (use these exact headings):
- THE RULE
- SEE IT IN ONE CASE (a small worked example with VERIFICATION)
- WHY IT MUST BE TRUE (the general intuition in plain words)
- WHEN IT HOLDS / WHEN IT FAILS (conditions stated honestly)
- THE ONE-LINE ANSWER TO "WHY?"

RULES: Do not merely restate the rule as its own reason. Keep the reasoning intuitive and honest about its level of rigour. Define every symbol used.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
