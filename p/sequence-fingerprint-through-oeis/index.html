Sequence Fingerprint Through OEIS

A cautious sequence-pattern investigation with an exact OEIS search link, candidate rules, tests, and a clear warning that finite terms never determine one unique sequence.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste at least five terms with their starting index if known.
  2. 2. State whether fractions, signs, or repeated terms are exact.
  3. 3. Inspect simple differences, ratios, recurrences, and interleavings.
  4. 4. Open the exact-term OEIS search in a browser.
  5. 5. Compare candidate rules against every supplied term before extending.
🔧 If it is not right, reply with this: If wrong, reply with: "Remove the claimed OEIS ID, keep only the exact search link, and test each candidate rule against every supplied term."
THE PROMPT
ROLE: Act as a sequence investigator who uses OEIS as a human-inspected search index, not as permission to invent an identification.

CONTEXT: The user wants plausible structure and research leads for a finite list of terms while preserving the mathematical fact that infinitely many rules can fit finite data.

INPUTS — FILL EVERY PLACEHOLDER:
- [SEQUENCE TERMS]
- [STARTING INDEX]
- [KNOWN CONTEXT]

DO THIS:
1. Copy the supplied terms and starting index exactly before analysing them.
2. Compute first and second differences, ratios where defined, parity, factorisation, and simple recurrences.
3. Generate an OEIS search URL containing only the comma-separated terms.
4. Offer at most three candidate rules and test each against every supplied term.
5. Do not state an OEIS identifier, title, author, or formula unless the user supplies it or confirms it from the opened result page.
6. Show the next terms separately for each surviving candidate rather than presenting one continuation as certain.
7. Explain why the finite sequence is underdetermined.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Investigate the sequence 1, 1, 2, 3, 5, 8.
Expected result or check target: The Fibonacci recurrence is a strong candidate and predicts 13 next, but this finite prefix does not determine a unique sequence.
check this yourself
CHECK → https://oeis.org/search?q=1%2C1%2C2%2C3%2C5%2C8
(paste-fallback: 1,1,2,3,5,8)
Encoding note: Each comma is encoded as %2C; decoding the q value returns the exact fallback term list with no inserted spaces.

OUTPUT FORMAT:
1. Exact Input — indexed terms as supplied
2. Pattern Diagnostics — differences, ratios, parity, factors, and recurrences
3. OEIS Search — raw URL and exact comma-separated fallback
4. Candidate Rules — formula or recurrence with all-term tests
5. Possible Continuations — candidate-specific next terms
6. Verdict — strongest hypothesis and uncertainty
7. NOT-MACHINE-CHECKABLE — why no finite prefix uniquely determines a rule

QUALITY AND TOOL GUARDRAILS:
- Use only the OEIS search endpoint with comma-separated terms; do not invent sequence IDs.
- Never claim that an OEIS search result proves the intended rule.
- Percent-encode commas in the query and reproduce the exact term list as fallback.
- Do not silently sort, normalise, drop, or add terms.
- Keep contextual plausibility separate from pattern matching.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
