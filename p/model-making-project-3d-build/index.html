Model-Making Project (3D Build)

A buildable maths model with materials, dimensions and an explanation card.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Name the concept and class in the brackets.
  2. 2. Paste the prompt into any AI chat.
  3. 3. Check the materials and dimensions.
  4. 4. Print the build steps and explanation card.
  5. 5. Grade with the included rubric.
🔧 If it is not right, reply with this: If the model is too costly, reply: "Rebuild it using only cardboard, paper, glue and string. Recalculate the dimensions and re-verify the maths."
THE PROMPT
ROLE: Act as a maths teacher who designs physical model-making projects that make abstract ideas tangible.

CONTEXT: I teach [CLASS/GRADE] under [BOARD e.g. CBSE / ICSE / State Board]. I want a MODEL-MAKING PROJECT where students build a 3D model that demonstrates [CONCEPT e.g. types of solids and their nets / a working clinometer / the Cartesian plane / a geometric dome]. Materials must be cheap and easily available.

YOUR TASK:
1. Choose one clear model that demonstrates the concept.
2. List low-cost materials with rough quantities.
3. Give exact dimensions or measurements students should use.
4. Provide numbered building steps.
5. Write a short 'explanation card' students attach, showing the maths the model illustrates (with one worked calculation).
6. Provide a 20-mark rubric covering accuracy, neatness and the explanation.

INPUT: Here is my concept and any limit on materials/budget: [PASTE CONCEPT AND LIMITS HERE]. If blank, choose a strong model for the class and board above.

HOW TO WORK IT OUT: Plan internally and ensure the stated dimensions actually produce the model (for example, that net measurements fold correctly, or angles sum properly). VERIFY every calculation twice and show both checks. Never invent formulas. Keep all maths legible in clean plain text or simple LaTeX.

OUTPUT FORMAT (use these exact headings in this order):
1. MODEL TITLE
2. WHAT IT DEMONSTRATES
3. MATERIALS (with quantities)
4. DIMENSIONS / MEASUREMENTS (a clear list or table)
5. BUILD STEPS (numbered, student-facing)
6. EXPLANATION CARD (the maths shown, with one worked example and two checks)
7. RUBRIC (20 marks)
8. SAFETY AND TIPS

RULES: Keep it safe (no sharp-tool steps without a caution). Be exact with numbers and units. Short, plain sentences.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return one complete, editable document ready to paste into Word or Google Docs. Use a descriptive title, short section headings, readable paragraphs, numbered actions and tables only where they make the material easier to use. Include every requested section; do not return formatting advice instead of the document.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
