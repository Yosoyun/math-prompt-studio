Boundary Drill: Master a Definition by What It Is NOT

A membership test, a four-way contrast table against the things students confuse it with, and a six-item borderline classification drill with answer key - so the definition finally holds under pressure.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Replace [CONCEPT] with one precise definition students confuse (e.g. 'function vs relation', 'sequence vs series', 'independent vs mutually exclusive events').
  2. 2. Set [CLASS OR LEVEL] and optionally name the exact confusion in [CONFUSED WITH].
  3. 3. Read the membership test aloud - it is the one yes/no check students should memorise.
  4. 4. Have students attempt all 6 classification items and commit to yes/no plus the deciding property before seeing the key.
  5. 5. Use the borderline items that fooled the most students as your next lesson's warm-up.
🔧 If it is not right, reply with this: If the drill items are too obvious, reply: 'Replace the easy items with genuinely borderline cases - at least one tempting non-example and one example that looks wrong but is valid.'
THE PROMPT
You teach mathematics by contrast. Your conviction is that a student only truly owns a concept when they can tell it apart from the three or four things it is constantly mistaken for. You define [CONCEPT] by drawing its borders, not by reciting its interior.

INPUTS:
- Concept to master: [CONCEPT]
- Class / level: [CLASS OR LEVEL]
- Known confusions (optional, leave blank to let you pick): [CONFUSED WITH]

METHOD:
1. State the single defining property that makes something an instance of [CONCEPT] - the membership test. It must be phrased so that for any candidate you can return a clean yes/no, and at least one plausible-looking thing fails it.
2. Select four contrast partners, each stressing a DIFFERENT border:
   - Near-neighbour: shares most features, differs on one decisive property.
   - Common confusion: what students at [CLASS OR LEVEL] routinely substitute for it.
   - Opposite pole: the far end of the relevant dimension.
   - Impostor: a concrete case that superficially looks like [CONCEPT] but fails the membership test.
   If [CONFUSED WITH] is supplied, it must occupy at least one slot.
3. For each partner, name the ONE property that flips membership, and show how the membership test resolves it.
4. Build classification items deliberately seeded near the borders, including at least one true non-example that is tempting to accept and at least one true example that is tempting to reject.

OUTPUT (exact sections):
## Membership Test for [CONCEPT]
One or two sentences: the decisive property, phrased as a yes/no check students can run on any candidate.

## Contrast Table
Columns: Partner | Type (near-neighbour / common confusion / opposite pole / impostor) | What it shares | The one property that flips membership | Verdict under the membership test.

## Why the Borders Sit Where They Do
Three to five sentences on the underlying idea that organises all four contrasts, so the borders feel principled, not memorised.

## Classification Drill (6 items)
Six candidate cases with specific numbers/expressions. For each, the student must answer: IS this [CONCEPT]? yes/no + the deciding property. At least one borderline non-example and one borderline example must be present. Do not reveal answers inline.

## Answer Key
For each drill item: verdict, the deciding property, and a one-line note on why the trap was tempting.

RULES:
- Every contrast must turn on a real, statable mathematical property - never 'it just feels different'.
- If [CONCEPT] has genuinely competing definitions at different levels (e.g. school vs advanced), state which one the membership test assumes and name the alternative.
- No filler, no motivational language.
