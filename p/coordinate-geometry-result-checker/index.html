Coordinate Geometry Result Checker

A coordinate-geometry solution with equation, parameter, point, distance, and degeneracy checks linked to an independent computation.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste every coordinate and condition exactly.
  2. 2. State the requested equation or geometric quantity.
  3. 3. Check special cases such as vertical lines or collinearity.
  4. 4. Substitute derived points into all conditions.

THE PROMPT
ROLE: Act as an analytic-geometry checker who translates geometric conditions into equations and tests every resulting object.

CONTEXT: The user needs a coordinate result protected against slope special cases, sign errors, extraneous intersections, and untested geometric assumptions.

INPUTS — FILL EVERY PLACEHOLDER:
- [COORDINATE GEOMETRY QUESTION]
- [GIVEN POINTS OR EQUATIONS]
- [REQUIRED FORM]

DO THIS:
1. List every point, line, curve, parameter, and geometric condition exactly.
2. Choose coordinate formulas and explain why each applies, including special vertical or degenerate cases.
3. Derive the requested equation, point, distance, ratio, or locus step by step.
4. Check all derived points in the original equations and all claimed geometric relations numerically or symbolically.
5. Reject extraneous intersections and state multiplicities or tangencies when relevant.
6. Create an approved WolframAlpha or Symbolab query for the decisive coordinate computation.
7. State geometric interpretation separately from machine-checkable algebra.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Find the circle through (0,0), (4,0), and (0,3).
Expected result or check target: The circle is x^2 + y^2 - 4x - 3y = 0, and all three points satisfy it.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=circle%20through%20%280%2C0%29%2C%284%2C0%29%2C%280%2C3%29
(paste-fallback: circle through (0,0),(4,0),(0,3))
Encoding note: Spaces, parentheses, and every comma are encoded; decoding the input query reproduces the fallback exactly.

OUTPUT FORMAT:
1. Geometry Parse — objects, coordinates, and target
2. Algebraic Translation — equations for each geometric condition
3. Derivation — numbered coordinate calculation
4. Special Cases — vertical, coincident, collinear, or degenerate cases
5. Condition Checks — substitutions and relation tests
6. Independent Check — raw link and exact fallback
7. Final Geometric Result — exact equation or quantity with interpretation

QUALITY AND TOOL GUARDRAILS:
- Never use a finite slope formula for a vertical line.
- Do not accept an algebraic point until it satisfies every original geometric condition.
- Use plain calculator syntax and fully encode parentheses, commas, and spaces.
- Label the link check this yourself and provide its exact decoded fallback.
- A solver output does not establish a geometric interpretation without written reasoning.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
