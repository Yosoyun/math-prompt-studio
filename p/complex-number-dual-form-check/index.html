Complex Number Dual-Form Check

A complex-number result checked in rectangular and polar forms with magnitude, argument, branch, and back-conversion links.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the exact complex expression.
  2. 2. State the principal-argument interval and angle units.
  3. 3. Follow the rectangular-form computation.
  4. 4. Check magnitude, argument, and polar conversion.
  5. 5. Open the independent link and compare branches.
🔧 If it is not right, reply with this: If wrong, reply with: "Recompute the quadrant and principal argument first, then convert the polar result back to rectangular form."
THE PROMPT
ROLE: Act as a complex-number auditor who tracks quadrant, argument convention, roots, and equivalence of rectangular and polar forms.

CONTEXT: The user needs a complex calculation verified through two representations without losing multivalued solutions or confusing principal and general arguments.

INPUTS — FILL EVERY PLACEHOLDER:
- [COMPLEX NUMBER TASK]
- [ARGUMENT CONVENTION]
- [ANGLE UNITS]
- [REQUIRED FORM]

DO THIS:
1. Compute in rectangular form with real and imaginary parts displayed.
2. Find modulus and argument with an explicit quadrant check.
3. Write polar or exponential form using the requested angle units and branch convention.
4. For powers or roots, list all required branches and verify their spacing and count.
5. Convert the final polar result back to rectangular form as an internal cross-check.
6. Create approved WolframAlpha or Symbolab links for the original computation and form conversion.
7. State principal versus general values explicitly.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Write 1 + i in polar form using principal radians.
Expected result or check target: The modulus is sqrt(2) and the principal argument is pi/4, so the polar form is sqrt(2)e^(i*pi/4).
check this yourself
CHECK → https://www.wolframalpha.com/input?i=polar%20form%201%2Bi
(paste-fallback: polar form 1+i)
Encoding note: The spaces and literal plus sign are encoded as %20 and %2B; decoding the query gives the fallback exactly.

OUTPUT FORMAT:
1. Convention — symbol, argument interval, and angle units
2. Rectangular Work — real and imaginary components
3. Polar Work — modulus, quadrant, and argument
4. Branch Audit — all roots or general arguments if required
5. Back-Conversion — polar result returned to rectangular form
6. Independent Checks — raw links with exact fallbacks
7. Final Answer — both forms with branch conditions

QUALITY AND TOOL GUARDRAILS:
- Never use arctan(y/x) without correcting for quadrant and zero-coordinate cases.
- Do not return only the principal root when the task asks for all roots.
- Use i in plain calculator syntax and fully encode plus signs and spaces.
- Label every link check this yourself and print its exact decoded fallback.
- A decimal angle is not a substitute for an exact angle when one exists.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
