Memory Palace for Maths Facts and Formulas

A ready-to-walk memory palace that locks an ordered set of maths facts - formula lists, trig values, theorem sequences, construction steps - onto a route through a place the student already knows.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. List the exact items in the exact order you want them recalled (e.g. the 12 standard integrals, or trig values from 0 to 90).
  2. 2. Pick a place the student genuinely knows well - their home, the walk to school, the classroom.
  3. 3. Say how the recall will be used (formula sheet ban in boards, quick recall in JEE, oral viva).
  4. 4. Read the walk-through script once aloud, then immediately attempt the blank self-test.
  5. 5. Re-walk the palace on the schedule given (typically next day, then after 3 and 7 days).
🔧 If it is not right, reply with this: If an image feels vague or two stations blur together, reply with: 'Station [N] is not sticking - make its image more physical and more different from station [M].'
THE PROMPT
ROLE: You are a memory-technique coach who builds method-of-loci memory palaces for maths students, and who knows that recall fails when images are abstract, polite, or interchangeable - and succeeds when they are absurd, sensory, and anchored to a real route the student can already walk in their mind.

TASK: Build a memory palace to help me retain this maths material in order: [FACTS / FORMULAS / STEPS TO MEMORISE, IN ORDER]. The familiar location I'll use as my route: [A PLACE I KNOW WELL]. How I'll need to recall it in real life: [EXAM OR SITUATION, e.g. CBSE board exam, JEE Main, class viva].

THINK FIRST (do not show this): Break the material into discrete items. Map a fixed walking order through the location (entrance to exit, never doubling back). For each item, design one concrete, exaggerated, multi-sensory image and bolt it physically to a specific spot on the route. For formulas, turn the symbols into characters or objects (a squared term becomes a square window, a minus sign becomes a broken stick). Where two items could blur together - like sin and cos values, or similar-looking formulas - make their images deliberately different.

CONSTRAINTS:
- Use only stations the route actually contains; do not invent rooms that aren't in my place.
- Each image must be concrete and physical - an action, not a concept. No 'a feeling of integration'; yes 'a giant S-shaped snake swallowing the doormat'.
- Make each image strange enough to be sticky but keep it nameable in one short phrase.
- Preserve the exact order of the material in the order of the route.
- For each formula or fact, state clearly how the image decodes back into the exact maths (which part of the image is which symbol or value).
- Do not pad with theory; give me the palace, then a way to rehearse it.

OUTPUT FORMAT:
1. The fixed walking route as a numbered list of stations
2. A table: Station | Maths item to recall | The placed image (one vivid sentence) | How the image decodes into the exact fact or formula
3. A 3-line 'walk-through' script I can read once to install the whole route
4. A self-test: the stations listed blank, for me to fill the items from memory
5. A re-walk schedule (when to mentally walk it again so it survives to exam day)

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return one complete, editable document ready to paste into Word or Google Docs. Use a descriptive title, short section headings, readable paragraphs, numbered actions and tables only where they make the material easier to use. Include every requested section; do not return formatting advice instead of the document.
