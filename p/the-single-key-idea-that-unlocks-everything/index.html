The Single Key Idea That Unlocks Everything

The one core idea behind a whole chapter, plus how each part flows from it.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Open any free AI chat.
  2. 2. Paste the prompt.
  3. 3. Add the chapter and class level.
  4. 4. Send and read the key idea.
  5. 5. Anchor the chapter on that idea.
🔧 If it is not right, reply with this: If it lists many ideas, reply: "Pick only ONE central idea, not several, and show how every other part of the chapter follows from it."
THE PROMPT
ROLE: Act as a mathematics teacher who can compress a whole chapter into its single most important idea.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. This chapter or concept feels like many unrelated rules to my students: [WRITE THE CHAPTER OR CONCEPT HERE]. I want the ONE central idea that ties it all together.

YOUR TASK:
1. State the single key idea of the whole chapter in one clear sentence.
2. Explain why this one idea is the heart of everything else.
3. Show how three or four of the chapter's main rules or results flow directly from this idea.
4. Give one example where remembering the key idea makes a problem easy.
5. End with the one sentence a student should never forget about this chapter.

INPUT: Here is the chapter or concept: [PASTE OR TYPE IT HERE]. Class level: [CLASS/GRADE].

HOW TO WORK IT OUT: Internally test that the chosen idea really is central by checking that the listed rules genuinely follow from it. Solve the example and VERIFY its answer two independent ways. Never invent a false unifying idea or formula. Keep all maths legible in clear plain text.

OUTPUT FORMAT (use these exact headings):
- CHAPTER OR CONCEPT
- THE ONE KEY IDEA (a single sentence)
- WHY THIS IS THE HEART (2 to 3 lines)
- HOW THE REST FOLLOWS (3 to 4 rules, each shown flowing from the key idea)
- THE IDEA IN ACTION (one example, solved, with VERIFICATION)
- NEVER FORGET THIS (one sentence)

RULES: Exactly ONE central idea, not a list of several. Each derived rule must visibly connect back to that idea. Keep the example short and the language plain.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return one complete, editable document ready to paste into Word or Google Docs. Use a descriptive title, short section headings, readable paragraphs, numbered actions and tables only where they make the material easier to use. Include every requested section; do not return formatting advice instead of the document.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
