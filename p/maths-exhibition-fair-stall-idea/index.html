Maths Exhibition / Fair Stall Idea

A complete exhibition stall plan: the demo, the script, the display and the materials.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Type the exhibition theme and class.
  2. 2. Paste the prompt into any AI chat.
  3. 3. Read the demo and the explainer script.
  4. 4. Gather the listed materials.
  5. 5. Practise the script before the fair.

THE PROMPT
ROLE: Act as a maths teacher who designs eye-catching, interactive stalls for a school maths exhibition or science fair.

CONTEXT: I teach [CLASS/GRADE] under [BOARD e.g. CBSE / ICSE / State Board]. I want a MATHS EXHIBITION STALL on the theme [THEME e.g. patterns in nature / magic of numbers / geometry around us / probability games]. It should have an interactive demo visitors can try, run by my students.

YOUR TASK:
1. Give the stall a catchy title and a one-line hook.
2. Describe the interactive demo or hands-on exhibit visitors will try.
3. List the materials and how to set up the table.
4. Write a short explainer SCRIPT students say to visitors (the maths behind it, in simple words).
5. Include the actual maths or a worked example the demo is based on.
6. Suggest what to display on the backboard (described in words).
7. Add 3 likely visitor questions with crisp answers.

INPUT: Here is my theme and how many students will run the stall: [PASTE THEME AND TEAM SIZE HERE]. If blank, choose a crowd-pleasing theme for the class and board above.

HOW TO WORK IT OUT: Plan internally and ensure the demo reliably works and is safe. VERIFY any maths claim two ways and show both checks. Never overstate a 'trick'; explain the real reason it works. Keep all maths legible in clean plain text or simple LaTeX.

OUTPUT FORMAT (use these exact headings in this order):
1. STALL TITLE AND HOOK
2. THE INTERACTIVE DEMO (what visitors do)
3. MATERIALS AND TABLE SETUP
4. THE MATHS BEHIND IT (with one worked example and two checks)
5. STUDENT EXPLAINER SCRIPT (short, friendly)
6. BACKBOARD DISPLAY (described in words)
7. VISITOR Q&A (3 questions + answers)
8. TEACHER TIPS

RULES: Keep the demo quick, safe and genuinely interactive. Be accurate. Short, plain sentences.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return one complete, editable document ready to paste into Word or Google Docs. Use a descriptive title, short section headings, readable paragraphs, numbered actions and tables only where they make the material easier to use. Include every requested section; do not return formatting advice instead of the document.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
