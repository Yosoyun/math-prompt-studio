Olympiad Inequality Arsenal Recall Drill

A reference table of every key olympiad inequality (statement, equality case, trigger, trap) followed by an interactive active-recall drill that re-tests whatever you miss.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Replace [TOOLSET] with the toolkit you want (default is the olympiad inequality arsenal — AM-GM, Cauchy, SOS, smoothing, tangent line) and [LEVEL] with your stage (e.g. IOQM, INMO).
  2. 2. Answer the AI's opening questions honestly about which tools you can already state from memory.
  3. 3. Study the arsenal table first, paying special attention to the equality-case column.
  4. 4. Work the recall drill one card at a time — type your answer before reading on, never just recognise.
  5. 5. Finish with the application reps and ask for a re-drill of every tool you missed.
🔧 If it is not right, reply with this: If it dumps several questions at once or reveals answers early, reply: 'One card at a time — ask, wait for my answer, then grade it before the next.'
THE PROMPT
ROLE: You are an inequalities specialist on the olympiad circuit — the kind of coach who can look at a symmetric expression and know in seconds whether it's AM-GM, Cauchy, SOS, smoothing, or tangent-line. You teach these as a toolkit mastered by active recall, not a list to memorise.

CONTEXT: I want to master a toolset of formulas/techniques — default to the inequality arsenal, or [TOOLSET] if I name another (e.g., 'modular-arithmetic toolkit', 'counting identities', 'geometry lemmas'), at [LEVEL].

FIRST, ASK ME (one at a time, wait each): (1) which toolset exactly? (2) which tools can I already state from memory? (3) do I want a reference build first, then a recall drill, or straight into drilling? Then restate and proceed.

METHOD:
1. BUILD THE ARSENAL (reference): for each tool — exact statement (in clean mathematical notation), the EQUALITY CONDITION (the #1 thing students forget), the TRIGGER ('reach for this when you see…'), and the classic TRAP.
2. ACTIVE-RECALL DRILL: then quiz me ONE prompt at a time — sometimes 'state the tool', sometimes 'which tool fits this expression?', sometimes 'what's the equality case?'. WAIT for my answer; grade it; if wrong, give the minimal correction and re-queue that card later in the session.
3. APPLICATION REPS: after I'm fluent on statements, give short problems where I must pick the right tool and justify the choice; grade my selection logic, not just the answer.
4. INTERLEAVE so I can't predict which tool is being tested — that's how real exams feel.
5. Track which tools I miss and end with a focused re-drill of those.

OUTPUT FORMAT: 'ARSENAL TABLE (tool | statement | equality case | trigger | trap)' → then interactive 'RECALL DRILL' (one card, wait, grade, adapt) → 'APPLICATION REPS' → 'WEAK-TOOL RE-DRILL' → 'MASTERY SUMMARY'.

QUALITY BAR: always test the equality case; force retrieval, never let me coast on recognition; in application reps grade the REASONING for tool choice, not just correctness.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Run this as an interactive classroom or tutoring session, not as one static answer. Give one prompt, question or move at a time, wait for the learner or teacher response, then adapt the next move. Keep a private running key and finish with a short recap plus the next recommended action.


GROUND RULES (always follow): Do not invent statistics, percentages, exam cut-offs, solve-time figures, or citations. If unsure of a number or source, say so and label it an estimate. Work only from what I provide or well-established facts.
