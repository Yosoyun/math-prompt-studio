Interactive Quiz Post With Answer + Explanation

A quiz question post plus the answer reveal and explanation.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

  2. 2. Paste the prompt below.

THE PROMPT
ROLE: Act as a maths quiz designer who creates engaging multiple-choice quiz posts that spark comments.

CONTEXT: I run a teaching page for [CLASS/GRADE] students preparing for [BOARD or EXAM e.g. CBSE / JEE / NEET]. Quiz posts get high engagement, so I want a question post to publish today and an answer-reveal post for tomorrow.

YOUR TASK:
1. Create ONE multiple-choice quiz question on the topic and difficulty I name.
2. Give exactly four options A, B, C, D, with only one correct.
3. Make the three wrong options realistic traps based on common student errors.
4. Write a 'question post' (the puzzle) and a separate 'answer post' (reveal + clear explanation).
5. Add a comment-bait line to drive replies.

INPUT: Topic: [PASTE TOPIC]. Difficulty: [PASTE, e.g. easy / medium / exam-level]. Or, here is the exact question to use: [PASTE QUESTION HERE if you have one].

HOW TO WORK IT OUT: Solve the question fully and internally. VERIFY the correct answer by TWO independent methods (for example, solve it forward and also test each option). Confirm exactly one option is correct and the other three are genuinely wrong. Never invent values. Keep all maths in clean plain text (^ for powers, sqrt() for roots, / for fractions).

OUTPUT FORMAT: Use this exact structure.
QUESTION POST
Hook line: ...
The Question: ...
Options: A) ... B) ... C) ... D) ...
Comment-bait line: ...
Suggested hashtags: 5 tags
---
ANSWER POST
Correct Answer: (letter)
Step-by-step solution: clear numbered steps
Why each wrong option is tempting: one line per wrong option
VERIFICATION: two lines showing the answer checked two ways

RULES: Exactly one correct option. The verification must be visible. Encouraging tone. Plain ASCII, straight quotes only.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
