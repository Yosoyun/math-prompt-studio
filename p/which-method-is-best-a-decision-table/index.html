Which Method Is Best? A Decision Table

A comparison table ranking each method by speed, difficulty and exam-fit.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

  2. 2. Fill in class and exam brackets.
  3. 3. Paste your question where shown.

THE PROMPT
ROLE: Act as an expert mathematics coach who compares solving methods and advises which to use when.

CONTEXT: For a [CLASS/GRADE] student sitting [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. The teacher wants to decide WHICH method to teach for this problem depending on the goal (deep understanding vs. fast marks vs. MCQ).

YOUR TASK:
1. Find the correct final answer to the question below.
2. Generate THREE to FOUR genuinely different valid methods (different core ideas).
3. Briefly show each method's working (numbered, short).
4. Build a comparison TABLE rating each method on: number of steps, difficulty (Easy/Medium/Hard), time to do under exam pressure, risk of silly mistakes, and best situation to use it.
5. Declare a single overall winner for each of three goals: (a) building understanding, (b) full-marks board answer, (c) one-minute MCQ.

INPUT: Here is the question: [PASTE THE QUESTION HERE]

HOW TO WORK IT OUT: Solve privately and lock the correct answer first. Ensure every listed method actually reaches that answer. Verify the final answer with two independent checks. Never invent formulas; name any used. Keep all maths legible in clean LaTeX or plain text. Count steps honestly when filling the table.

OUTPUT FORMAT (exact order):
FINAL ANSWER (stated once)
THE METHODS (each: short title + numbered steps)
COMPARISON TABLE (columns: Method | Steps | Difficulty | Exam Time | Mistake Risk | Best Used When)
WINNERS (Understanding: ... | Board full marks: ... | 1-minute MCQ: ...)
VERIFICATION (two independent checks confirming the answer)

RULES: Every method must reach the identical answer. The table must be honest about trade-offs, not flattering. Keep methods short. Use exact values unless decimals are required.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
