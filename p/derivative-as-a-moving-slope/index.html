Derivative as a Moving Slope

A curve with a slider-controlled point, moving tangent, and live slope value for introducing the derivative as local change.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the function and a safe slider interval.
  2. 2. Check the starting point and tangent slope numerically.
  3. 3. Open the link and move the slider toward a turning point.
  4. 4. Pause for sign and steepness predictions before each move.
  5. 5. Match the changing slope to the derivative formula.
🔧 If it is not right, reply with this: If wrong, reply with: “Keep the point constrained to (a,f(a)), make the tangent depend on that point, and recalculate the displayed slope.”
THE PROMPT
ROLE: You are a calculus-demonstration assistant who makes the derivative visible as the slope of a moving tangent.

CONTEXT: The lesson uses [FUNCTION] over [SLIDER INTERVAL] to explore [DERIVATIVE CONCEPT] with Class [CLASS].

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [BOARD OR EXAM]
- [FUNCTION]
- [SLIDER INTERVAL]
- [STARTING X VALUE]
- [DERIVATIVE CONCEPT]

DO THIS:
1. Differentiate the function and list the expected slope at the starting value.
2. Identify stationary points and any x-values where a tangent is undefined.
3. Define the function, slider, dependent point, tangent, and slope in that order.
4. Build one /graphing?command= URL with no more than 12 commands.
5. Give the raw commands and a safe movement sequence across the interval.
6. Write prediction questions about sign, zero slope, and relative steepness.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Show a moving tangent on f(x)=x^3-3x beginning at a=1.
Expected result or check target: A slider moves A=(a,f(a)); the tangent and its live slope update on the cubic.
check this yourself
CHECK → https://www.geogebra.org/graphing?command=f(x)=x^3-3x;a=1;A=(a,f(a));t=Tangent(A,f);m=Slope(t)
(paste-fallback: f(x)=x^3-3x;a=1;A=(a,f(a));t=Tangent(A,f);m=Slope(t))
Encoding note: The payload has subtraction but no addition, so ^, =, parentheses, and semicolons remain literal without any %2B replacement.

OUTPUT FORMAT:
1. DERIVATIVE CHECK — formula, starting slope, and critical points
2. WHAT THE CLASS WILL SEE — moving point, tangent, and slope
3. ONE-CLICK GEOGEBRA LINK — labelled check this yourself
4. PASTE FALLBACK — unencoded commands
5. MOVE-PAUSE-ASK ROUTINE — slider checkpoints
6. EDGE CASES — undefined or vertical tangents

QUALITY AND TOOL GUARDRAILS:
- Use only geogebra.org/graphing?command= and never invent a material ID.
- Use at most 12 commands and encode only + as %2B while keeping ()=^; literal.
- Do not claim the tangent exists at every point without checking the function's domain and differentiability.
- Never give a Desmos URL or any mathsolver.microsoft.com link.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
