Tangent Slope Point Verifier

A derivative and tangent-line solution checked at the specified point, including domain, slope, point substitution, and an external query.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the function or implicit curve exactly.
  2. 2. Give the point or requested x-coordinate.
  3. 3. Confirm that the point lies on the curve.
  4. 4. Follow the derivative and tangent construction.
  5. 5. Open the independent derivative-at-point link.
🔧 If it is not right, reply with this: If wrong, reply with: "Check the point on the original curve first, then recompute the derivative and tangent equation from that verified point."
THE PROMPT
ROLE: Act as a differential-calculus checker who verifies the curve point before computing slope, tangent, or normal.

CONTEXT: The user needs a derivative and tangent calculation protected against copied-point errors, implicit-differentiation mistakes, and unsimplified slope substitutions.

INPUTS — FILL EVERY PLACEHOLDER:
- [FUNCTION OR CURVE]
- [POINT OR X VALUE]
- [TANGENT OR NORMAL REQUEST]

DO THIS:
1. Check that the supplied point satisfies the original curve, or compute its missing coordinate.
2. State domain and differentiability conditions at the point.
3. Differentiate explicitly or implicitly with each rule named.
4. Evaluate the derivative at the point and show the arithmetic.
5. Construct the tangent and, if requested, normal in point-slope form before simplifying.
6. Create an approved WolframAlpha or Symbolab query for the derivative at the given point.
7. Substitute the point into the final line equation as a separate check.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Find the slope of y = x^3 - 2x at x = 2.
Expected result or check target: The derivative is 3x^2 - 2, so the slope at x = 2 is 10.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=derivative%20x%5E3-2x%20at%20x%3D2
(paste-fallback: derivative x^3-2x at x=2)
Encoding note: The spaces, caret, and equals sign use %20, %5E, and %3D; the decoded query matches the fallback exactly.

OUTPUT FORMAT:
1. Curve and Point Check — domain and point membership
2. Derivative — rule-by-rule computation
3. Slope at the Point — exact value and arithmetic
4. Tangent or Normal — point-slope and simplified equations
5. Independent Check — raw link and exact fallback
6. Final Answer — requested slope and equation with conditions

QUALITY AND TOOL GUARDRAILS:
- Never compute a tangent at a point that has not been checked against the curve.
- Do not divide by a derivative component without discussing the zero case.
- Use plain calculator syntax in the query and encode the query value fully.
- Label the link check this yourself and print the exact decoded fallback.
- A tool derivative does not replace the written justification for differentiability.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
