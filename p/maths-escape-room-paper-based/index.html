Maths Escape Room (Paper-Based)

A themed 5-station puzzle chain where each answer unlocks the next, plus a master lock, answer key and hints.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. Type your topic, class and board.
  2. Add the time limit you have.
  3. Paste the prompt and send.
  4. Print each station and the answer key.
  5. Give graded hints only when teams stall.
🔧 If it is not right, reply with this: If the chain breaks or a code does not unlock the next step, reply: "Trace the whole chain again, fix any station where the answer does not feed the next clue, and re-verify the final lock."
THE PROMPT
ROLE: Act as a mathematics teacher and escape-room designer who builds a linear puzzle chain where each answer unlocks the next clue.

CONTEXT: My students are in [CLASS/GRADE] preparing for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. I want a paper-based maths escape room on [TOPIC] for teams of 3-4, finishing in about [NUMBER] minutes.

YOUR TASK:
1. Design a themed story (for example a locked treasure vault) with 5 sequential puzzle stations.
2. Each station has ONE maths problem on [TOPIC]; its numeric answer becomes the code or direction to the next station.
3. Make a final 'master lock' whose code is built from the 5 station answers (for example their sum or a chosen-digit code).
4. Provide a teacher answer key and a hint card (2 graded hints) for each station.

INPUT: Topic, class, board and time limit are above. If I add nothing, keep the story age-appropriate and the maths squarely on-topic.

HOW TO WORK IT OUT: Solve every puzzle yourself, then trace the whole chain end to end to prove each answer correctly unlocks the next step and the final lock. Verify each answer twice by independent methods. Never invent formulas or values. Keep all maths in clean LaTeX or clear plain text.

OUTPUT FORMAT (use these exact headings):
STORY AND GOAL (3-4 lines)
SETUP FOR THE TEACHER (numbered)
STATION 1 to STATION 5 (for each: the puzzle text students see, then the unlock instruction)
THE MASTER LOCK (how the final code is formed)
TEACHER ANSWER KEY (every station answer in a box [Answer: ...] plus the final code)
HINT CARDS (2 graded hints per station)
WALKTHROUGH CHECK (confirm the chain solves cleanly)

RULES: The chain must be logically airtight - no dead ends. Answers must be clean enough to use as codes. No two puzzles may test the exact same step. Keep clue text readable for a teenager.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Run this as an interactive classroom or tutoring session, not as one static answer. Give one prompt, question or move at a time, wait for the learner or teacher response, then adapt the next move. Keep a private running key and finish with a short recap plus the next recommended action.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
