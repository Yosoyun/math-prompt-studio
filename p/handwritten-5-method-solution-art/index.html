Handwritten 5-Method Solution Art

One photographed problem becomes five gallery-grade handwritten pages - five genuinely different methods, one per page - in your pick of 18 styles, from Vintage Parchment Masterclass and Dark Academia to Nordic Frost Minimalist and Stained-Glass Cathedral Light. The AI writes out the full worked solution as text for you to check before it draws a single page.

Makes images - needs an image AI  ·  Best tool:  ChatGPT or Gemini (image)

✅ How to use this effectively

  1. Attach a clear photo of ONE question (or paste it where the prompt says).
  2. Open the style menu below and pick one of the 18 styles - it fills into the prompt automatically.
  3. First check the TEXT solution it gives you; only then ask it to draw the pages.
  4. If it makes one page, reply: now generate Page 2, then Page 3, 4, 5.
  5. Download each page and give the maths a final check.
🔧 If it is not right, reply with this: If a page is unclear, reply: 'Redo that page in the same style, make the handwriting larger and re-check the maths.' If it crams several methods onto one canvas, reply: 'One page, one method only - regenerate that page by itself.' If it answers with text after you have already confirmed, say: 'Please generate this as an actual image.'
THE PROMPT
ROLE
Act as an expert mathematics educator, proof-checker, handwriting art director and premium editorial illustrator.

TASK
Transform the mathematics problem in the attached image into a coordinated five-page handwritten solution collection - five genuinely different methods, one full page per method - in the style described under STYLE DIRECTION below.

USE THE ATTACHED MATHEMATICS-PROBLEM IMAGE AS THE SOLE SOURCE OF THE QUESTION.
(No image handy? Then add this line: "Here is the question instead: [PASTE THE FULL QUESTION HERE]".)

STEP 0 - TEXT VERIFICATION FIRST (BEFORE ANY IMAGE)
Before generating any image, reply in plain text only with:
1. Your transcription of the exact question (number, symbols, powers, roots, factorials, limits, inequalities, labels, units, answer choices, restrictions).
2. The complete worked solution for all five methods, step by step.
3. The single verified final answer, confirmed by at least two independent checks. If the problem is computational, also paste a WolframAlpha query link the teacher can click to confirm the answer.
Then say: "Please check this maths. Reply CONFIRM to start Page 1, or point out any error first." Do not draw anything until the teacher confirms.

PAGE-BY-PAGE OUTPUT
- Generate ONE page per response. After confirmation, this response = Page 1 (Method 1) only, as one complete portrait image.
- End every image response with: "Reply 'Page 2' to continue" (then Page 3, Page 4, Page 5).
- Keep the same paper family, handwriting personality, palette and signature across all five pages.

ANTI-COLLAGE RULES (NON-NEGOTIABLE)
- Never create a collage, contact sheet, grid, montage, carousel sheet, split canvas or combined poster.
- Never compress two or more methods onto one image. Never continue one method onto another page.
- Each page shows the SAME complete question at the top and exactly ONE method.

MATHEMATICAL RECONSTRUCTION AND VERIFICATION
- Read the attached image carefully; when handwritten work is visible, treat it only as reference - independently verify it and silently correct errors.
- If several questions appear, select the clearly marked or most prominent one and do not mix problems.
- Choose five genuinely different mathematical viewpoints. Cosmetic rearrangements do not count as different methods.
- If five standard methods are unavailable, use valid alternatives such as direct derivation, structural identity, graphical/geometric interpretation, theorem-based route, reverse verification, invariant, generalisation or computational pattern followed by proof.
- Never invent a theorem, assumption, value or diagram detail.
- Every page must reach the same verified final answer - the one confirmed in STEP 0.

REQUIRED PAGE STRUCTURE - REPEAT ON ALL FIVE PAGES
A. Top question area: exact question number and instruction (e.g. "Q1. Evaluate"), the full question, and a thin hand-drawn divider below it.
B. Method heading: "Method [page number] : [precise method name]" as a large handwritten title with an elegant underline.
C. One complete method only: circled handwritten step numbers (1)(2)(3)..., all essential reasoning, identities, conditions and intermediate steps, aligned and readable, with only mathematically useful mini-sketches/arrows/braces.
D. Final answer: a centred double-line handwritten box with the exact verified final answer (units, solution set, equality case or correct option). Identical on all five pages.
E. Signature: bottom right, an elegant handwritten signature "[YOUR NAME]" with a natural underline flourish. If no name is supplied, leave the signature area blank - add no name at all.

HANDWRITING REALISM
Everything must look genuinely handwritten (headings, mathematics, labels, signature) by one consistent master-teacher personality, with natural stroke-pressure variation and slight baseline irregularity. Mathematics must remain fully legible. Do not use a rigid typed script font.

COMPOSITION AND LEGIBILITY
Portrait full-page composition, approximately A4 ratio. Keep safe margins so nothing is cropped. Use generous spacing; do not shrink writing to cram content. Keep decoration in empty corners. No watermarks, logos, extra names, motivational quotes or unrelated objects.

PRE-OUTPUT CHECK FOR EVERY PAGE
Portrait and readable; full question at top; exactly one method; final answer box matches the STEP 0 verified answer; signature (or blank) bottom right; no collage/grid/combined canvas/cropped content/typed-poster look.

STYLE DIRECTION
[STYLE - pick from the style menu]

STYLE-SPECIFIC NEGATIVE RULES
- Do not substitute a generic white worksheet background (unless the chosen style explicitly calls for a light minimal page).
- Do not use flat digital gradients, stock textures or clip-art decoration.
- Do not make all strokes perfectly uniform.
- Do not let visual styling reduce equation accuracy or readability.
- Do not repeat identical corner decoration on every page; vary it subtly while preserving the same visual family.

FINAL COMMAND
First deliver STEP 0 (the full text solution and the check request). After the teacher replies CONFIRM, generate Page 1 only as one complete portrait image and end with "Reply 'Page 2' to continue." Never combine pages.
