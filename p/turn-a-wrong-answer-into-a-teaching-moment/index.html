Turn a Wrong Answer into a Teaching Moment

A short, ready-to-deliver mini-lesson built around the student's actual mistake.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. Paste the wrong answer, or attach a photo.
  2. Type the question and topic.
  3. Set the class and board or exam.
  4. Press Enter for the mini-lesson.
  5. Ask for a board-friendly shorter version.
🔧 If it is not right, reply with this: If it is too long for class, reply: "Compress this to a 5-minute board talk with one worked example and one quick check question."
THE PROMPT
ROLE: Act as a master teacher who turns a single student error into a memorable class lesson.

CONTEXT: This is for a [CLASS/GRADE] class studying [TOPIC] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE]. One student's mistake is a perfect example many others will share, and I want to teach from it without naming or embarrassing the student.

YOUR TASK:
1. Solve the question correctly yourself.
2. Find the instructive error in the student's attempt.
3. Build a short, lively mini-lesson around that error: hook, the trap, the correct idea, a worked fix, and a quick check.
4. Keep it generic so no student is singled out.

INPUT: The question is: [PASTE THE QUESTION HERE]. The student's wrong attempt (or attached photo): [PASTE THE ATTEMPT HERE].

HOW TO WORK IT OUT: Solve internally first, then VERIFY the answer two independent ways and state both. Frame the error as 'a very tempting trap', not as a failure. Give one fresh practice question that targets the same trap, with its answer for the teacher. Never invent formulas or values. Keep maths legible.

OUTPUT FORMAT (exact headings):
1. Hook - one line that grabs attention ('Spot the trap in this step...').
2. The tempting trap - the quoted wrong step and why it feels right.
3. The correct idea - the concept in plain words, then in symbols.
4. Worked fix - the corrected steps to the final answer.
5. Quick check for the class - one new question on the same trap.
6. Answer key for the teacher - the worked answer plus two-check verification.
7. Board summary - three short bullet points to write up.

RULES: Plain ASCII only, straight quotes. Never name or shame the student. Keep it deliverable in about 8 minutes.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return one complete, editable document ready to paste into Word or Google Docs. Use a descriptive title, short section headings, readable paragraphs, numbered actions and tables only where they make the material easier to use. Include every requested section; do not return formatting advice instead of the document.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
