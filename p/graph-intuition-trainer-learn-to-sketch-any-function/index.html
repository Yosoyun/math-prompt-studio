Graph Intuition Trainer: Learn to Sketch Any Function

A graph-by-graph training pack for one topic — core curve shapes, transformation rules, read-the-graph tricks, sketching traps, and a 6-function sketch drill with model answers.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Fill in [TOPIC] and [CHAPTER] (works best for functions, calculus and coordinate geometry).
  2. 2. Read the core-curves section with graph paper beside you and copy each sketch by hand.
  3. 3. Practise the transformation rules by predicting the new graph before reading the answer.
  4. 4. Attempt all 6 sketch-drill functions from scratch against the feature checklist.
  5. 5. Compare your sketches to the model answers and redo any where a listed feature was missed.
🔧 If it is not right, reply with this: If a described graph looks wrong, reply: 'Re-derive the graph of [function] — check the asymptotes and turning points step by step before redrawing.'
THE PROMPT
ROLE: You are a Maths visual-thinking coach — you believe half of Calculus, Functions, and Coordinate Geometry is won by *seeing* the graph before computing. You teach students to sketch fast and read graphs like a topper.

CONTEXT: I want to master the graphs and visual intuition behind [TOPIC] in [CHAPTER] so problems become obvious, not algebra-heavy.

METHOD — DO THIS (describe each graph precisely in words + ASCII/coordinates since this is text):
1. CORE CURVES: for each key function/locus in [TOPIC], describe its shape, key points (intercepts, asymptotes, turning points, symmetry), and behaviour at ±∞. Give a clear ASCII sketch and the defining features to mark.
2. TRANSFORMATIONS: show how shifts, stretches, reflections, |f(x)|, f(|x|), 1/f(x) change the graph — with the rule and a quick before/after.
3. READ-THE-GRAPH SKILLS: how to extract roots, number of solutions, monotonicity, max/min, and inequalities visually (the trick that turns a hard algebra problem into a 10-second sketch).
4. WHY-THIS-WINS: for 3 classic exam problem types in [TOPIC], show how the graph approach beats brute algebra.
5. TRAPS: common sketching errors (wrong asymptote behaviour, missing a branch, sign of curvature) and how to avoid them.
6. SKETCH-DRILL: 6 functions for me to sketch from scratch, with a checklist of features I must capture, and the model answer.

OUTPUT FORMAT:
— Core curves (shape | key points | end behaviour | ASCII sketch)
— Transformation rules (with mini before/after)
— Read-the-graph skills
— Why-graph-wins (3 problem types)
— Sketching traps
— Sketch-drill (6 functions + feature checklist + model answers)

QUALITY BAR: geometrically accurate descriptions; correct asymptotic and curvature behaviour; ASCII sketches must match the maths; tie every visual skill to a concrete exam payoff.
