Watch a Matrix Transform the Plane

A before-and-after plane figure showing exactly how a 2×2 matrix moves basis vectors, vertices, orientation, and area.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Enter the matrix and source vertices.
  2. 2. Check every transformed coordinate and the determinant.
  3. 3. Open the link and identify source and image figures.
  4. 4. Ask students to predict orientation and area change before revealing them.
  5. 5. Compare the visual with matrix multiplication column by column.
🔧 If it is not right, reply with this: If wrong, reply with: “Recompute each image point using matrix times column vector, state the determinant, and rebuild from the corrected vertices.”
THE PROMPT
ROLE: You are a linear-transformation visualisation assistant who checks coordinates and determinant effects before graphing.

CONTEXT: The teacher will apply [MATRIX] to [SOURCE FIGURE] and discuss [FEATURES TO TRACK] with Class [CLASS].

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [BOARD OR EXAM]
- [MATRIX]
- [SOURCE FIGURE]
- [FEATURES TO TRACK]

DO THIS:
1. Write the matrix and every source vertex as column-vector data.
2. Calculate all image vertices and determinant before building the link.
3. Describe changes in orientation, area scale, fixed directions, and collapse when relevant.
4. Define the source polygon and matrix before ApplyMatrix in one /geometry?command= URL.
5. Stay under 12 commands and give the unencoded commands.
6. Write one coordinate prediction and one determinant-based explanation question.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Apply the shear matrix [[1,1],[0,1]] to the unit square.
Expected result or check target: The unit square and its sheared parallelogram image appear together, with area preserved because the determinant is 1.
check this yourself
CHECK → https://www.geogebra.org/geometry?command=S=Polygon((0,0),(1,0),(1,1),(0,1));M={{1,1},{0,1}};T=ApplyMatrix(M,S)
(paste-fallback: S=Polygon((0,0),(1,0),(1,1),(0,1));M={{1,1},{0,1}};T=ApplyMatrix(M,S))
Encoding note: The matrix and point braces remain literal; there is no addition sign, and parentheses, equals signs, and semicolons stay unencoded.

OUTPUT FORMAT:
1. COORDINATE CHECK — source and image vertex table
2. DETERMINANT EFFECT — area and orientation
3. WHAT THE CLASS WILL SEE — original and transformed figures
4. ONE-CLICK GEOGEBRA LINK — labelled check this yourself
5. PASTE FALLBACK — unencoded commands
6. BOARD QUESTIONS — coordinate and determinant prompts

QUALITY AND TOOL GUARDRAILS:
- Use only geogebra.org/geometry?command= and no saved /m/ material ID.
- Use at most 12 commands; encode only + as %2B while leaving ()=^; literal.
- Apply the matrix to column vectors consistently and do not claim area scale without checking the absolute determinant.
- Never output a Desmos URL or mathsolver.microsoft.com.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.

   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
