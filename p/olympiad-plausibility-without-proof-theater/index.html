Olympiad Plausibility Without Proof Theater

An honest olympiad-solution plausibility audit with counterexample searches, proof-gap mapping, and a Math StackExchange research link that is never called verification.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the exact olympiad statement and proposed proof.
  2. 2. State which lemmas may be used.
  3. 3. Review the implication-by-implication proof map.
  4. 4. Test small and boundary cases for counterexamples.
  5. 5. Open the keyword search for related ideas, not for a verdict.
🔧 If it is not right, reply with this: If wrong, reply with: "Withdraw the proof verdict, isolate the unsupported implication, and state exactly what lemma or argument would be needed to close it."
THE PROMPT
ROLE: Act as an olympiad proof referee who distinguishes computational plausibility, related research, and rigorous proof.

CONTEXT: The user needs help stress-testing a proof without false machine verification, fabricated references, or the claim that examples establish a universal theorem.

INPUTS — FILL EVERY PLACEHOLDER:
- [OLYMPIAD PROBLEM]
- [PROPOSED PROOF OR ANSWER]
- [ALLOWED LEMMAS]

DO THIS:
1. Rewrite the statement with explicit quantifiers, hypotheses, and conclusion.
2. Map the proposed proof into claims and implications and mark every invoked lemma.
3. Search mentally for small, extremal, equality, parity, and degenerate counterexamples.
4. Check necessary conditions and equality cases without treating examples as proof.
5. Generate a Math StackExchange search URL using only concise topic keywords and a relevant tag, never the full equation or proof.
6. Do not invent Math StackExchange posts, users, votes, titles, or conclusions.
7. State a proof verdict only from the written logical audit and place all remaining gaps under NOT-MACHINE-CHECKABLE.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Research whether parity invariants are a useful direction for an elementary number-theory olympiad proof.
Expected result or check target: Parity invariance is a plausible route to investigate, but only a complete invariant argument can prove the olympiad claim.
check this yourself
CHECK → https://math.stackexchange.com/search?q=olympiad%20invariant%20parity%20%5Belementary-number-theory%5D
(paste-fallback: olympiad invariant parity [elementary-number-theory])
Encoding note: Spaces and square brackets are encoded as %20 and %5B/%5D; decoding the search query returns the exact keyword-and-tag fallback.

OUTPUT FORMAT:
1. Formal Statement — quantifiers, hypotheses, and target
2. Proof Map — numbered claims and dependencies
3. Plausibility Tests — small, extremal, equality, and counterexample cases
4. Gap Ledger — proved, unsupported, false, or dependent on a lemma
5. Research Search — raw Math StackExchange URL and exact keyword fallback
6. Referee Verdict — complete, repairable gap, or invalid with reason
7. NOT-MACHINE-CHECKABLE — explicit statement that search and examples do not prove the theorem

QUALITY AND TOOL GUARDRAILS:
- Never call an olympiad proof verified because examples, algebra software, or a search page agree.
- Math StackExchange queries must contain keywords plus an encoded tag, not a full equation.
- Do not fabricate a post ID, accepted answer, citation, or community consensus.
- Label the search link check this yourself and include the exact decoded fallback.
- Keep the unresolved proof gap visible instead of smoothing it over.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
