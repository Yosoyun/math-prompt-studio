JEE-Style Daily DPP (Mains + Advanced)

A daily JEE-pattern sheet with single-correct, multi-correct, integer and assertion-reason items.

THE PROMPT
ROLE: Act as a senior JEE mathematics faculty member and problem-setter.

CONTEXT: I want a daily JEE-style DPP for Class 11/12 students preparing for [JEE Mains / JEE Advanced]. Topic = [TOPIC]. Level = [moderate / hard].

YOUR TASK:
1. Create exactly 10 questions in authentic JEE pattern: about 5 single-correct MCQs, 2 multiple-correct MCQs, 2 integer/numerical-answer questions, and 1 assertion-reason question.
2. Use realistic JEE phrasing and traps (sign errors, domain issues, special cases).
3. State the marking scheme used (for example +4, -1 for single-correct; partial marks where the pattern allows).
4. Provide hints, an answer key, and full solutions explaining the trap in each.

INPUT: Topic = [TOPIC]. Exam = [JEE Mains / JEE Advanced]. Level = [moderate / hard]. If unclear, assume and state it.

HOW TO WORK IT OUT: Solve every question yourself first. For multiple-correct items confirm EXACTLY which options are right. Verify each final answer by two independent checks. Never invent formulas or values - use only correct, JEE-level mathematics. Keep all maths legible in clean LaTeX or clear plain text.

OUTPUT FORMAT, in this exact order:
1. TITLE BLOCK: 'JEE-Style DPP - [TOPIC] - [Mains/Advanced]' with the marking scheme and 'Compiled by [YOUR NAME]'.
2. SECTION A - QUESTIONS: 10 numbered questions grouped by type (Single-correct, Multiple-correct, Integer, Assertion-Reason), printable.
3. SECTION B - HINTS: one one-line hint per question.
4. SECTION C - ANSWER KEY: correct option(s) or value for each.
5. SECTION D - FULL SOLUTIONS: clean working that names the trap each question is testing.

RULES: Match real JEE difficulty and option style. For multiple-correct, the count of correct options must be unambiguous. No out-of-syllabus content.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
