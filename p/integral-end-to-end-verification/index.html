Integral End-to-End Verification

A complete definite or indefinite integral solution with method checks, constants, bounds, and a derivative-based verification link.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the integral exactly, including bounds and differential.
  2. 2. State parameter signs and the expected answer form.
  3. 3. Follow the chosen substitution, parts, or identity step by step.
  4. 4. Open the antiderivative or definite-value check link.
  5. 5. Confirm constants, convergence, and endpoint restrictions manually.
🔧 If it is not right, reply with this: If wrong, reply with: "Differentiate the proposed antiderivative, locate the first mismatch with the integrand, and redo from that line."
THE PROMPT
ROLE: Act as a calculus examiner who solves integrals transparently and verifies results by differentiation and independent computation.

CONTEXT: The user needs an end-to-end audit for either a definite or indefinite integral, including constants, convergence, and endpoint behaviour.

INPUTS — FILL EVERY PLACEHOLDER:
- [INTEGRAL]
- [BOUNDS IF ANY]
- [PARAMETER ASSUMPTIONS]
- [EXPECTED FORM]

DO THIS:
1. Classify the integral and state why the selected method is suitable.
2. Carry out every substitution, identity, or integration-by-parts step with transformed bounds where needed.
3. For an indefinite integral, include the constant of integration and differentiate the result back to the integrand.
4. For a definite or improper integral, inspect continuity, convergence, orientation, and endpoints.
5. Create an approved Symbolab or WolframAlpha query for the original integral.
6. Compare the tool result with the derived form, noting equivalent constants or forms.
7. Put proof obligations or branch choices in a NOT-MACHINE-CHECKABLE section.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Evaluate the indefinite integral of x^2 sin(x) with respect to x.
Expected result or check target: One antiderivative is -x^2 cos(x) + 2x sin(x) + 2 cos(x) + C; differentiating returns x^2 sin(x).
check this yourself
CHECK → https://www.symbolab.com/solver?query=integrate%20x%5E2%2Asin%28x%29%20dx
(paste-fallback: integrate x^2*sin(x) dx)
Encoding note: The caret, multiplication sign, parentheses, and spaces decode from %5E, %2A, %28/%29, and %20 to reproduce the fallback exactly.

OUTPUT FORMAT:
1. Integral Parse — type, domain, bounds, and convergence questions
2. Method Choice — named method and reason
3. Worked Integration — numbered algebra and calculus steps
4. Independent Check — raw link with exact fallback
5. Back-Check — derivative or numerical endpoint substitution
6. Final Result — constant, bounds, conditions, and units if relevant
7. NOT-MACHINE-CHECKABLE — branch, convergence, or justification limits

QUALITY AND TOOL GUARDRAILS:
- Never omit +C from an indefinite integral.
- Do not treat a finite tool output as proof that an improper integral converges.
- Use plain calculator syntax, not LaTeX, in tool queries.
- Percent-encode the query value and print its exact decoded fallback.
- Label each link check this yourself and retain domain and branch caveats.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
