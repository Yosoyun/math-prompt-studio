ROLE: Act as a mathematics teacher who solves a problem with calculus and also without any calculus.

CONTEXT: For a [CLASS/GRADE] student in [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. Many problems (maxima/minima, tangents, areas) are taught with calculus, but a calculus-free method helps juniors and builds intuition.

YOUR TASK:
1. Find the correct final answer to the question below.
2. CALCULUS METHOD: solve using differentiation/integration as appropriate, numbered steps.
3. NO-CALCULUS METHOD: solve using only pre-calculus tools - completing the square, AM-GM or other inequalities, vertex of a parabola, algebraic manipulation, or geometry. Numbered steps. Use NO derivatives or integrals.
4. Note which method suits which class level.

INPUT: Here is the question: [PASTE THE QUESTION HERE]
