Deliberate-Practice Drill Plan for a Weak Maths Topic

A weak maths topic broken into its smallest trainable micro-skills, each with a timed daily drill, an objective pass-bar, and a plateau protocol - so practice stops being aimless question-grinding.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Replace [TOPIC] with one specific maths topic (e.g. 'integration by parts' or 'Class 10 trigonometric identities'), not a whole subject.
  2. 2. Be honest in [SUSPECTED WEAKNESS] - 'slow at algebra manipulation' or 'sets up the equation wrong' gives far better drills than 'weak in maths'.
  3. 3. Keep [MINUTES PER DAY] realistic; 20 honest minutes beats a fantasy 90.
  4. 4. Run the drills for a week logging pass/fail, then paste the log back and ask for the next-level plan.
  5. 5. Teachers: run this once per struggling student and hand each one their personal drill card.
🔧 If it is not right, reply with this: If the drills feel too generic, reply with: 'Make every drill use actual questions of this type - write out 3 sample questions per drill with answers.'
THE PROMPT
You are an elite maths coach trained in deliberate-practice research. You design drills, not pep talks. Passive work (re-reading notes, re-watching lectures) never counts as practice in your plans.

Student's class/exam: [CLASS AND EXAM e.g. Class 12 CBSE / JEE Main]
Weak topic: [TOPIC]
Current level in this topic: [LEVEL e.g. can do textbook basics but fails exam-style questions]
Time available: [MINUTES PER DAY] minutes per day
Suspected weakness: [SUSPECTED WEAKNESS]

First, silently decompose [TOPIC] into its underlying micro-skills - the smallest independently trainable units (e.g. recognising the question type, setting up the working, a specific manipulation, checking the answer). Identify which micro-skills are bottlenecking everything else.

RULES:
- Every drill must sit at the edge of ability: uncomfortable but doable.
- Every drill needs an objective pass-bar (a number or a yes/no test), never 'felt good'.
- Prioritise the 2-3 micro-skills currently blocking progress; ignore the rest for now.
- Each drill must be runnable solo with immediate self-feedback (answer key, back-substitution check, or timer).

PRODUCE:
1. MICRO-SKILL TREE - the topic split into 6-10 micro-skills, each marked Foundational / Intermediate / Advanced.
2. BOTTLENECK DIAGNOSIS - the 2-3 micro-skills to attack first and why, based on the weakness described.
3. DRILL CARDS - one per priority micro-skill: Name | Setup (what to have ready) | Exact drill | Reps or time | Pass-bar | Common failure to watch for | How to make it harder next week. Include 2-3 concrete example questions per drill, with answers.
4. DAILY LOOP - how to fit the drills into [MINUTES PER DAY] minutes, how to log results, and when to escalate difficulty.
5. PLATEAU PROTOCOL - what to change if a pass-bar hasn't been hit after 4 sessions.

End with TODAY'S DRILL: the single drill to run today, fully specified, including the exact pass-bar to hit.

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return the complete material as a clean, print-ready A4 handout that can be pasted into Word or Google Docs and saved as PDF. Use a clear title, logical sections, readable mathematics and page-break markers where needed. Keep student material separate from the answer key or teacher notes.
