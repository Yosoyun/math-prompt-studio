7-Day Weekly DPP Series on One Chapter

Seven connected daily sheets that walk one chapter from basics to mastery across a week.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. 1. Fill the chapter, class and board brackets.
  2. 2. Paste the prompt and send.
  3. 3. When asked, type "Day 1".
  4. 4. After each day, type "Next day".

THE PROMPT
ROLE: Act as a mathematics teacher and curriculum planner who designs week-long practice programmes.

CONTEXT: I want a 7-day Daily Practice Problem (DPP) series that covers ONE chapter from start to mastery for [CLASS/GRADE] students preparing for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET]. Chapter = [CHAPTER NAME].

YOUR TASK:
1. First, show a one-screen PLAN listing what each of the 7 days will cover, moving from easiest sub-topics to the hardest, with Day 7 as a mixed mastery day.
2. Then produce ONE day at a time. Each day has exactly 6 questions of rising difficulty.
3. Do NOT print all 7 days at once. After the plan, ask me to type 'Day 1', and after each day wait for me to type 'Next day'.

INPUT: Chapter = [CHAPTER NAME]. Class = [CLASS/GRADE]. Board/Exam = [BOARD or EXAM]. Daily time budget = [TIME e.g. 25 minutes]. If unclear, assume and state it.

HOW TO WORK IT OUT: Solve every question yourself first. Verify each final answer by two independent checks before showing it. Never reuse the same question across two days. Never invent formulas or values - use only correct mathematics for [CLASS/GRADE]. Keep all maths legible in clean LaTeX or clear plain text.

OUTPUT FORMAT for each day, in this exact order:
1. HEADER: 'DPP Day [n] of 7 - [CHAPTER NAME]' with the day's focus, class, suggested time, and 'Compiled by [YOUR NAME]'.
2. QUESTIONS: 6 numbered questions only.
3. HINTS: one one-line hint per question.
4. ANSWER KEY: final answers.
5. FULL SOLUTIONS: clean step-by-step working.
6. CARRY-FORWARD NOTE: one line on what tomorrow will build on.

RULES: Each day must be harder or broader than the day before. Day 7 must mix all sub-topics. Keep difficulty honest and labelled.

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
