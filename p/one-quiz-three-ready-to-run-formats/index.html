One Quiz, Three Ready-to-Run Formats

One checked quiz delivered as a teacher review copy, a complete Google Forms script and a Wayground paste block with no retyping.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. State the topic, class, question count and marks scheme.
  2. 2. Check the common review copy because it controls all three formats.
  3. 3. Run the Apps Script and test the logged respondent link for the Form version.
  4. 4. Paste the separate block through Wayground’s Create, Import and Paste questions path.
🔧 If it is not right, reply with this: If wrong, reply with: "Regenerate all three formats from one corrected master key and show a parity table proving every question and answer matches across them."
THE PROMPT
ROLE: Act as a cross-platform maths quiz producer and answer-key consistency checker.

CONTEXT: A teacher needs one [TOPIC] quiz in three usable formats for review, an auto-marked Google Form and a Wayground game.

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [BOARD OR EXAM]
- [TOPIC]
- [QUESTION COUNT, DEFAULT 10]
- [MARKS SCHEME]
- [DIFFICULTY MIX]
- [OPTIONAL PREFILLED FORM LINK WITH ENTRY IDS]

DO THIS:
1. Create one master set of multiple-choice questions in plain ASCII maths.
2. Give a review copy with correct answers, short solutions and check-this-yourself links for calculations.
3. Generate one complete executable FormApp script from that exact master set with quiz mode, correct choices, points and logged URLs.
4. Generate a Wayground paste block from the same master set and keep it under 10,000 characters.
5. If an existing prefilled Form link with entry IDs is supplied, encode only those supplied IDs and values; otherwise omit prefilled links.
6. Finish with a parity table comparing item count and answer letter across all three formats.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Make an eight-question Class 8 quiz on linear equations in three formats.
Expected result or check target: All formats mark x=3 for x^2-9=0 only when the intended item asks for the positive root and state that restriction explicitly.
check this yourself
CHECK → https://www.symbolab.com/solver?query=solve%20x%5E2-9%3D0
(paste-fallback: solve x^2-9=0)
Encoding note: The space is %20, ^ is %5E and = is %3D.

OUTPUT FORMAT:
1. FORMAT 1 — LINK-VERIFIED REVIEW COPY
2. FORMAT 2 — COMPLETE GOOGLE APPS SCRIPT
3. RUN IT — script.google.com → New project → paste → Run → View → Logs
4. FORMAT 3 — WAYGROUND PASTE BLOCK
5. IMPORT — Create → Import → Paste questions
6. THREE-FORMAT PARITY CHECK

QUALITY AND TOOL GUARDRAILS:
- The Form must be created only by a COMPLETE executable FormApp code block; no URL can create it.
- After the code, print exactly: script.google.com → New project → paste → Run → View → Logs.
- Wayground is paste-import only through Create → Import → Paste questions, and its block must stay below 10,000 characters.
- Use an existing Google Forms prefill URL only when the teacher supplies its real entry IDs; never invent an entry ID.
- Keep question text, options and answer keys identical across the three formats.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
