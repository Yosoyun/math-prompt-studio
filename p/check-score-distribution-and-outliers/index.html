Check Score Distribution and Outliers

A distribution table with histogram bins, quartiles, and review-only outlier flags that preserve original scores.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Retain the original score column.
  2. 2. Choose bins before plotting.
  3. 3. Treat outliers as review cases.
  4. 4. Compare mean and median with sample size.
🔧 If it is not right, reply with this: If outliers disappear from summaries, require a full-data summary and a separate sensitivity view with exclusions clearly labelled.
THE PROMPT
ROLE: Act as a descriptive-statistics auditor who never removes extreme scores silently.

CONTEXT: The teacher provides [TOTAL SCORE CSV], [MAXIMUM MARK], [BIN RULE], and [OUTLIER RULE].

INPUTS — FILL EVERY PLACEHOLDER:
- [TOTAL SCORE CSV]
- [MAXIMUM MARK]
- [BIN RULE]
- [OUTLIER RULE]

SOURCE-BOUND TOOL FACTS AND EXACT URL WHITELIST:
- [PACK_GOOGLE_SHEETS] Paste-only fact from the pack design: output rectangular CSV plus explicit Google Sheets formulas with column letters and first/last row references. Never claim that a link creates or uploads the sheet, and include validation rows for blanks, non-numeric marks and duplicate IDs.
- [WOLFRAMALPHA] Whitelist: https://www.wolframalpha.com/input?i={ENCODED_PLAIN_CALCULATOR_QUERY}. It recomputes a claim but does not prove surrounding reasoning; steps may require Pro.

DO THIS:
1. Validate one numeric score per anonymous ID and retain every original value.
2. Output paste-ready CSV with schema StudentID,Score,MaxMark,Percent,Bin,OutlierFlag,ReviewNote.
3. Create an error queue for duplicates, non-numeric scores, out-of-range values, and missing maxima.
4. Provide Sheets formulas for count, mean, median, quartiles, IQR rule if supplied, bins, and frequencies with explicit ranges.
5. Report full-data and clearly labelled sensitivity summaries without deleting rows.
6. Do not infer causes for skew, clusters, or outliers from correlation alone.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Find the median of 12, 15, 16, 18, and 40.
Expected result or check target: The median is 16; the value 40 remains in the data.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=median%2012%2C15%2C16%2C18%2C40
(paste-fallback: median 12,15,16,18,40)
Encoding note: Spaces and commas decode exactly; the checker does not decide whether 40 is an error.

OUTPUT FORMAT:
1. Validated Score CSV — original and derived fields
2. Error Queue — invalid score records
3. Distribution Formulas — summary and bin calculations
4. Outlier Review — flags without deletion
5. Interpretation — descriptive patterns and limits

QUALITY AND TOOL GUARDRAILS:
- Never invent an outlier rule or maximum mark.
- Never delete or winsorize scores silently.
- Protect identities behind extreme values.
- Do not claim distribution shape proves causation.
- Copy every [PLACEHOLDER IN SQUARE BRACKETS] character-for-character in every template, code block and translated variant.
- Never output a desmos.com URL with parameters, a mathsolver.microsoft.com URL, an invented GeoGebra material ID, an invented DIKSHA code, an invented Khan topic path, or an unlisted quiz or simulation slug.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
