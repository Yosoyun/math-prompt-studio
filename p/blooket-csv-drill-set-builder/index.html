Blooket CSV Drill Set Builder

A clean Blooket-compatible CSV drill set with every correct answer recorded as an option number from 1 to 4.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Choose a narrow skill that benefits from repeated multiple-choice practice.
  2. 2. Review the key and check the worked verification links.
  3. 3. Save only the labelled CSV block with UTF-8 encoding and a .csv extension.
  4. 4. Use Blooket’s CSV Import, preview all options and confirm the numbered key before hosting.
🔧 If it is not right, reply with this: If wrong, reply with: "Rebuild valid Blooket CSV with one header row, no blanks, safely quoted fields and Correct Answer(s) as a number from 1 to 4 only."
THE PROMPT
ROLE: Act as a maths retrieval-practice designer and strict Blooket CSV formatter.

CONTEXT: A teacher wants a replayable phone drill for [CLASS] on [SKILL] using Blooket’s file importer.

INPUTS — FILL EVERY PLACEHOLDER:
- [CLASS]
- [SKILL OR TOPIC]
- [QUESTION COUNT]
- [DIFFICULTY MIX]
- [TIME LIMIT PER QUESTION]
- [COMMON ERRORS TO TARGET]

DO THIS:
1. Create multiple-choice drill items with four plausible options and one correct answer.
2. Use plain ASCII maths and avoid commas inside fields unless the CSV field is correctly quoted.
3. Give a review table with answer text, answer position and check-this-yourself links.
4. Output one CSV code block with the Blooket columns Question, Answer 1 through Answer 4, Time Limit and Correct Answer(s).
5. Put only the correct option number 1, 2, 3 or 4 in Correct Answer(s), never the answer text.
6. Audit header count, row width, blank rows and numbered keys before the import steps.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Build a ten-item fractions drill for Class 6.
Expected result or check target: For 3/4+5/6, the verified answer is 19/12 and its CSV key stores the position of 19/12 as a number from 1 to 4.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=3%2F4%2B5%2F6
(paste-fallback: 3/4+5/6)
Encoding note: The plus sign is %2B; slashes remain readable URL characters in this query.

OUTPUT FORMAT:
1. DRILL BLUEPRINT
2. LINK-VERIFIED KEY REVIEW
3. BLOOKET CSV CODE BLOCK
4. CSV STRUCTURE AUDIT
5. FILE-IMPORT STEPS

QUALITY AND TOOL GUARDRAILS:
- Blooket receives this set only through CSV file import; never claim URL import.
- Correct Answer(s) must contain the option NUMBER 1–4, never answer text.
- Use one header row, no merged cells, no blank rows and no extra columns; quote CSV fields correctly.
- Blooket supports multiple choice here, so do not create typed-answer items or LaTeX content.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.

=== TOOL-LINK OUTPUT CONTRACT — follow every rule exactly ===
1. You may output clickable links ONLY to: wolframalpha.com/input?i= · symbolab.com/solver?query= ·
   geogebra.org/graphing|geometry|3d|cas?command= · math.stackexchange.com/search?q= · oeis.org/search?q= ·
   artofproblemsolving.com/community/q1_ · khanacademy.org/search?page_search_query= ·
   overleaf.com/docs?encoded_snip= · latex.codecogs.com/png.image? · docs.google.com/forms/...viewform?usp=pp_url
   (Forms only with entry.N IDs I paste in) · plus any URL I give you or that appears in this prompt's whitelist table.
2. NEVER output: desmos.com links with query strings (they load blank), invented geogebra.org/m/ IDs, Khan topic
   URLs, DIKSHA dial codes, Wolfram quiz/demo slugs not in my table, or mathsolver.microsoft.com (dead site).
3. Write queries in plain calculator syntax (x^2, sqrt(x), pi, 3/4) — never LaTeX — EXCEPT Overleaf and CodeCogs
   payloads, which are LaTeX.
4. Percent-encode the query part: space→%20, +→%2B, ^→%5E, =→%3D, [→%5B, ]→%5D; in LaTeX payloads also
   \→%5C, {→%7B, }→%7D, %→%25, #→%23, &→%26, newline→%0A. GeoGebra ?command= exception: encode ONLY + as %2B;
   leave ( ) = ^ ; as typed.
5. One link per line, formatted exactly:  CHECK → <full raw URL>   (no markdown brackets, nothing after the URL).
6. Directly below every link, print:  (paste-fallback: <the un-encoded query or commands>)
7. Before printing any link, silently decode your own URL and confirm it reproduces the query character-for-character;
   rebuild it if not. If a URL would exceed 1,800 characters (Overleaf: 6,000), print only the paste-fallback.
8. Label every link "check this yourself" — never claim the link proves your answer is correct.
9. On phones these links must be opened in a browser, not an installed app — say this once at the end.
