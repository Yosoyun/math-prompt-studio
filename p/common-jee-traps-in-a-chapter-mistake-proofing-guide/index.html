Common JEE Traps in a Chapter (Mistake-Proofing Guide)

A guide to the exact traps a chapter hides, with the wrong vs right working side by side.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT/Gemini/Claude/Copilot)

✅ How to use this effectively

  1. Open any AI chat.
  2. Type the chapter name.
  3. Paste the prompt and send.
  4. Use the wrong-vs-right pairs in class.
  5. Give the trap-checklist before tests.
  6. For a trustworthy answer key: paste the finished paper into a FRESH chat and ask it to solve and grade it as an unseen exam (it catches its own slips).
🔧 If it is not right, reply with this: If a 'trap' is not really a common mistake, reply: "Trap 2 is rare in practice - replace it with a genuinely frequent JEE mistake in this chapter and show the wrong-vs-right working."
THE PROMPT
ROLE: Act as a JEE error-analysis expert who knows exactly where students lose marks.

CONTEXT: My [EXAM e.g. JEE Main / JEE Advanced] students keep making avoidable mistakes in [CHAPTER e.g. Limits / Probability / Coordinate Geometry]. I want a clear trap-by-trap guide so they stop repeating them.

YOUR TASK:
1. List EXACTLY [NUMBER e.g. 10] of the most COMMON traps and silent mistakes students make in [CHAPTER] in JEE.
2. For each trap: name it, explain why students fall for it, show a short example with the WRONG working a student does, then the CORRECT working, and a one-line 'safety check' to avoid it.
3. Rank the traps from most to least dangerous (by how often they cost marks).
4. Finish with a 10-point pre-exam checklist students tick before answering this chapter.

INPUT: Here is the chapter and any sub-topics students struggle with: [PASTE DETAILS HERE]. If number is blank, use 10. Stay inside this chapter.

HOW TO WORK IT OUT: For each trap, work the correct solution internally and VERIFY it by a second independent method, so the 'right' answer is trustworthy. Make sure the 'wrong working' is a realistic student error, not a strawman. Never invent formulas or values. Keep maths legible in clean LaTeX or clear plain text.

OUTPUT FORMAT, in this exact order:

OUTPUT FILE FORMAT: present the complete result as a clean, ready-to-use document I can paste straight into Microsoft Word or Google Docs - a clear bold title, section headings, neatly numbered items, comfortable spacing, and simple tables only where helpful (avoid heavy formatting that breaks on paste). It must also print cleanly to PDF on A4 (File > Print > Save as PDF). Keep all mathematics fully readable (fractions as a/b, powers as x^2, roots as sqrt(x)).

FORMAT THE OUTPUT — PRIMARY DELIVERABLE:
Return the complete material as a clean, print-ready A4 handout that can be pasted into Word or Google Docs and saved as PDF. Use a clear title, logical sections, readable mathematics and page-break markers where needed. Keep student material separate from the answer key or teacher notes.


MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
A. Title block: 'Chapter: [CHAPTER]', 'Common JEE Traps', 'Compiled by [YOUR NAME]'.
B. SECTION 1 - TRAP RANKING: a table Rank | Trap name | How often it costs marks.
C. SECTION 2 - TRAP DETAILS: for each trap, the five parts (Name / Why students fall for it / Wrong working / Correct working with the second-method check / Safety check).
D. SECTION 3 - PRE-EXAM CHECKLIST: 10 short tick-points.

RULES: Traps must be genuinely common. Wrong working must be realistic. Correct answer survives a second-method check. No invented values.

At the very end add a footer line: 'Prepared by [YOUR NAME]', and put 'Compiled by [YOUR NAME]' in the title block.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
