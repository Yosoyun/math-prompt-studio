Trigonometric General-Solution Validator

A complete trigonometric general solution with periodic families, interval filtering, and sample-value check links.

Works on any free AI  ·  Best tool:  Any AI chat (ChatGPT, Claude, Gemini)

✅ How to use this effectively

  1. 1. Paste the trigonometric equation exactly.
  2. 2. State radians or degrees and any target interval.
  3. 3. Follow the reference-angle and periodic-family derivation.
  4. 4. Test representative values from every family.
  5. 5. Open the independent solve link and compare interval solutions.
🔧 If it is not right, reply with this: If wrong, reply with: "Separate the reference angles and periodic families, test one value from each family, and filter the requested interval again."
THE PROMPT
ROLE: Act as a trigonometric-equation reviewer who checks general families, periodicity, units, and interval endpoints.

CONTEXT: The user needs protection against missing quadrants, mixed angle units, incomplete periodic families, and interval-filtering errors.

INPUTS — FILL EVERY PLACEHOLDER:
- [TRIGONOMETRIC EQUATION]
- [ANGLE UNITS]
- [TARGET INTERVAL]

DO THIS:
1. State the domain and angle unit before transforming the equation.
2. Reduce the equation to standard trigonometric values without cancelling possible solutions.
3. Derive every general family with an integer parameter and its period.
4. Substitute one ordinary sample from each family into the original equation.
5. Filter all families to the requested interval, checking open and closed endpoints.
6. Create an approved WolframAlpha link for the original equation.
7. Distinguish the general solution from the interval-specific answer.

WORKED LINK EXAMPLE — COPY THIS EXACT ENCODING PATTERN:
Example task: Solve sin(x) = 1/2 over the real numbers in radians.
Expected result or check target: The general solutions are x = pi/6 + 2pi n and x = 5pi/6 + 2pi n for integer n.
check this yourself
CHECK → https://www.wolframalpha.com/input?i=solve%20sin%28x%29%3D1%2F2
(paste-fallback: solve sin(x)=1/2)
Encoding note: The space, parentheses, equals sign, and slash are encoded; decoding restores the exact fallback equation.

OUTPUT FORMAT:
1. Setup — equation, domain, units, and interval
2. Reduction — identities and standard values
3. General Families — complete integer-parameter solution
4. Sample Checks — one substitution per family
5. Interval Solutions — ordered filtered values
6. Independent Check — raw link and exact fallback
7. Final Answer — general and interval forms clearly separated

QUALITY AND TOOL GUARDRAILS:
- Never mix degree and radian periods.
- Do not divide by a trigonometric expression without separately checking its zeros.
- Use plain calculator syntax and fully encode parentheses, slash, spaces, and equals signs.
- Label the link check this yourself and include the exact decoded fallback.
- A sample substitution checks membership but does not prove family completeness.
- Never describe an AI answer as verified. Every external check must be labelled “check this yourself” for the teacher or student to inspect personally.
- Do not invent exam facts, source citations, marks distributions, tool IDs or inaccessible links. Separate mathematical proof from computational checking.
