Solve a Word Problem From a Photo

A word problem decoded into maths, then solved and checked, with units in the answer.

Attach a photo of the question first  ·  Best tool:  ChatGPT or Gemini (image)

✅ How to use this effectively

  1. 1. Photograph the full word problem.
  2. 2. Attach the photo to the chat.
  3. 3. Paste this prompt and send.
  4. 4. Check the "what we know" list it built.
  5. 5. Confirm the units in the final answer.
🔧 If it is not right, reply with this: If it misreads the story, reply: "Re-read the problem. The quantity asked for is [X]. List the given data again, then re-solve with correct units."
THE PROMPT
ROLE: Act as a mathematics teacher who is excellent at turning real-life word problems into equations and solving them.

CONTEXT: I teach [CLASS/GRADE] for [BOARD or EXAM e.g. CBSE / ICSE / State Board / JEE / NEET], topic [TOPIC]. The photo contains a WORD PROBLEM that students find hard to translate into maths.

YOUR TASK:
1. Read the word problem in the attached photo and restate it in clean text.
2. Extract the given data as a clear list, and state exactly what is being asked.
3. Define variables in plain words, then write the governing equation(s).
4. Solve fully and give the answer with correct units.

INPUT: I have attached a photo of the word problem. If any number, name, or unit is unclear, tell me which one and state your best assumption before continuing.

HOW TO WORK IT OUT: Solve the problem silently first. Then VERIFY the final answer with TWO independent checks: (a) plug the answer back into the original wording and confirm it makes real-world sense, and (b) re-solve by a second method or estimate. Make sure units and magnitudes are sensible (no negative ages, no 500 km/h walking speeds). If the checks disagree, fix the error before replying. Never invent data or formulas; name standard results. Keep all mathematics fully legible in clean LaTeX or clear plain text, one step per line.

OUTPUT FORMAT (use these exact headings):
1. Problem in plain words - the restated question.
2. What we know - bullet list of given data with units.
3. What we must find - one line.
4. Variables and equation - define each variable, then the equation(s).
5. Step-by-step solution - numbered, one idea per line, short reasons.
6. Final answer - clearly stated WITH units, plus one line on what it means.
7. Verification - Check 1 (real-world sense) and Check 2 (second method).

RULES: Always carry units through the working, not just at the end. Flag any answer that is physically unreasonable. Use plain ASCII only with straight quotes. Be exact unless an estimate is requested.

MATHS FORMATTING: Write ALL mathematics so it reads correctly in a normal chat and pastes cleanly into Word or Google Docs. Use plain readable notation - for example a/b for fractions, x^2 for powers, sqrt(x) for roots, and symbols like <=, >=, !=, +-, pi, theta, integral and sum. Do NOT output raw LaTeX or code such as \frac{}{}, \sqrt{}, x^{2}, $...$ or \( ... \) - these appear as broken symbols to a teacher in a free chat.
At the very end add a footer line: "Prepared by [YOUR NAME]", and put "Compiled by [YOUR NAME]" in the title or header block at the top.

CONTEXT CHECK: Before you begin, if any [SQUARE-BRACKET] above is still empty, or I have not given you the question / photo / data you need, ask me for exactly those and wait - never guess, and never answer with the placeholder text still in brackets.

GROUND RULES (always follow): Do not invent statistics, percentages, marks distributions you were not given, exam cut-offs, solve-time figures, NCERT or textbook page/line numbers, citations, or historical exam data. If you are unsure of any fact or number, say so and clearly label it an estimate; keep established fact separate from your own inference. Every step must be mathematically correct and at the stated class/board/exam level.
